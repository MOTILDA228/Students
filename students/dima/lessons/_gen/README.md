# Генератор уроков-фундамента Димы (08–27)

- `tasks.py` — генераторы однотипных задач (условие, пошаговое решение, ответ, `@check`).
- `build.py` — теория и план каждого урока + состав «лесенки», разминки, мини-среза и ДЗ.
- Запуск (нужен Python 3.12+): `python3.12 students/dima/lessons/_gen/build.py`, затем `python3 tools/build_lessons.py dima`.
- Генерация детерминированная (seed = номер урока): повторный запуск даёт те же задачи.
  **Если урок поправили руками в `_src/`, не перезапускайте генератор для этого урока** — изменения затрутся.
- Новый урок: добавить генераторы в `tasks.py`, вызов `lesson(...)` в `build.py`, ключевые генераторы — в `CORE`.

- Уроки 28–70: `python3.12 students/dima/lessons/_gen/build2.py` (`tasks2.py` — генераторы; сюжеты №1–5, пробники и стратегия берутся из `lessons/_archive/_src`).
