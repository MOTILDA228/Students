Шпаргалка

1. Порядок действий

Скобки → умножение и деление (слева направо) → сложение и вычитание (слева направо).
Перед решением расставь над знаками номера действий: 1, 2, 3…
\(5 - 2{,}4\cdot1{,}5\): сначала умножение! \(2{,}4\cdot1{,}5 = 3{,}6\), потом \(5 - 3{,}6 = 1{,}4\). Если начать с \(5 - 2{,}4\), ответ будет неправильный.

2. В примере есть и обыкновенная, и десятичная дробь — что делать?

Посмотри на знаменатель обыкновенной дроби:
• 2, 4, 5, 8, 10, 20, 25, 50 — переводи в десятичную (делится ровно).
• 3, 6, 7, 9, 12… — переводи десятичную в обыкновенную: \(0{,}3 = \frac{3}{10}\), \(0{,}25 = \frac{25}{100} = \frac{1}{4}\).
Выучи наизусть: \(\frac{1}{2} = 0{,}5\) · \(\frac{1}{4} = 0{,}25\) · \(\frac{3}{4} = 0{,}75\) · \(\frac{1}{5} = 0{,}2\) · \(\frac{2}{5} = 0{,}4\) · \(\frac{3}{5} = 0{,}6\) · \(\frac{1}{8} = 0{,}125\) · \(\frac{1}{20} = 0{,}05\)

3. Дробь «1 на дробь»

\( \frac{1}{\frac{a}{b}} = \frac{b}{a} \): единица, делённая на дробь, — это та же дробь, перевёрнутая. Сначала посчитай знаменатель, потом переверни.

4. Ответ ОГЭ

Ответ — целое число или конечная десятичная дробь. Если получилась «некрасивая» дробь вроде \(\frac{7}{3}\), скорее всего, где-то ошибка — перепроверь.

Практика на уроке

1. Вычислите \(2{,}4 + \frac{3}{5}\).
РешениеЗнаменатель 5 — переводим в десятичную: \(\frac{3}{5} = 0{,}6\). \(2{,}4 + 0{,}6 = 3\).

Ответ: 3

2. Вычислите \(\frac{1}{4}\cdot3{,}6\).
РешениеУмножить на \(\frac{1}{4}\) — значит поделить на 4: \(3{,}6 : 4 = 0{,}9\).

Ответ: 0,9

3. Вычислите \(5 - 2{,}4\cdot1{,}5\).
РешениеСначала умножение: \(24\cdot15 = 360\) → \(3{,}60 = 3{,}6\). Потом \(5 - 3{,}6 = 1{,}4\).

Ответ: 1,4

4. Вычислите \(\left(\frac{1}{2} + 0{,}3\right)\cdot5\).
РешениеСкобка: \(0{,}5 + 0{,}3 = 0{,}8\). Потом \(0{,}8\cdot5 = 4\).

Ответ: 4

5. Вычислите \(\frac{3}{4} : 0{,}25\).
Решение\(\frac{3}{4} = 0{,}75\). \(0{,}75 : 0{,}25 = 75 : 25 = 3\).

Ответ: 3

6. Прототип ОГЭ №6 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \((3{,}2 - 1{,}7)\cdot2{,}4\).
РешениеСкобка: \(3{,}2 - 1{,}7 = 1{,}5\). \(1{,}5\cdot2{,}4\): \(15\cdot24 = 360\) → \(3{,}60 = 3{,}6\).

Ответ: 3,6

7. Прототип ОГЭ №6 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \( \frac{1}{\frac{1}{6} - \frac{1}{14}} \).
РешениеЗнаменатель: общий знаменатель 42. \(\frac{7}{42} - \frac{3}{42} = \frac{4}{42} = \frac{2}{21}\). Единица на дробь — переворачиваем: \(\frac{21}{2} = 10{,}5\).

Ответ: 10,5

Домашнее задание

1. Вычислите \(\frac{2}{5}\cdot4{,}5\).
Решение\(\frac{2}{5} = 0{,}4\). \(0{,}4\cdot4{,}5\): \(4\cdot45 = 180\) → \(1{,}80 = 1{,}8\).

Ответ: 1,8

2. Вычислите \(8 - 1{,}2\cdot3{,}5\).
РешениеУмножение: \(12\cdot35 = 420\) → 4,2. \(8 - 4{,}2 = 3{,}8\).

Ответ: 3,8

3. Вычислите \(\left(0{,}6 + \frac{1}{5}\right)\cdot2{,}5\).
Решение\(\frac{1}{5} = 0{,}2\). Скобка: 0,8. \(0{,}8\cdot2{,}5 = 2\).

Ответ: 2

4. Прототип ОГЭ №6 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \((6{,}7 - 3{,}2)\cdot2{,}4\).
РешениеСкобка: 3,5. \(35\cdot24 = 840\) → 8,40 = 8,4.

Ответ: 8,4

5. Прототип ОГЭ №6 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \( \frac{1}{\frac{1}{10} - \frac{1}{15}} \).
РешениеОбщий знаменатель 30: \(\frac{3}{30} - \frac{2}{30} = \frac{1}{30}\). Переворачиваем: 30.

Ответ: 30

6. Повторение (урок 4) Вычислите в столбик \(2968 : 7\).
Решение29 : 7 = 4 (28, остаток 1). Сносим 6: 16 : 7 = 2 (14, остаток 2). Сносим 8: 28 : 7 = 4. Ответ: 424. Проверка: \(424\cdot7 = 2968\) ✓.

Ответ: 424

7. Повторение (урок 5) Два угла треугольника равны 38° и 101°. Найдите третий угол.
Решение\(180 - 38 - 101 = 41^\circ\).

Ответ: 41

8. Повторение (урок 2) Вычислите \(4{,}5\cdot0{,}2\).
Решение\(45\cdot2 = 90\), после запятой всего 2 знака → 0,90 = 0,9.

Ответ: 0,9
