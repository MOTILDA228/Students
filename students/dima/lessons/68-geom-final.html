Для репетитора: план урока

Цель: собрать всю геометрию первой части в одну шпаргалку и решить задачи, где нужно соединить два факта (равнобедренный + Пифагор, трапеция + площадь треугольника, середина отрезка на клетках).

  1. 5–10 мин — проверка ДЗ урока 67 (или короткий разбор пробника №3).
  2. 15 мин — шпаргалка: прочитать вслух, каждый факт — «где он встречался».
  3. 30 мин — практика.
  4. 5 мин — итог. Шпаргалку распечатать и перечитывать каждый день до экзамена.

Вся геометрия ОГЭ на одной странице

№15. Треугольник. Сумма углов 180°; внешний угол = сумма двух не смежных; равнобедренный — углы при основании равны, высота к основанию = медиана = биссектриса; Пифагор \(c^2 = a^2 + b^2\); катет против 30° = половина гипотенузы; \(\sin = \frac{\text{прот.}}{\text{гип.}}\), \(\cos = \frac{\text{прил.}}{\text{гип.}}\), \(\operatorname{tg} = \frac{\text{прот.}}{\text{прил.}}\); средняя линия = половина стороны; подобие — отношение сторон \(k\), площадей \(k^2\); \(S = \frac{1}{2}ah\); высота равностороннего \(\frac{a\sqrt{3}}{2}\).
№16. Окружность. Вписанный угол = половина центрального (половина дуги); на диаметр — 90°; на одну дугу — равны; радиус ⟂ касательной; отрезки касательных равны; вписанный четырёхугольник — сумма противоположных углов 180°; описанный — суммы противоположных сторон равны; хорда: \(R^2 = \left(\frac{a}{2}\right)^2 + d^2\); около прямоугольного треугольника \(R = \frac{c}{2}\); правильный треугольник \(h = R + r = 3r\).
№17. Четырёхугольники. Параллелограмм: углы \(x\) и \(180 - x\), диагонали делятся пополам, \(S = ah\), биссектриса отсекает равнобедренный треугольник; прямоугольник — диагонали равны; ромб — диагонали ⟂, \(S = \frac{d_1d_2}{2}\); квадрат \(d = a\sqrt{2}\); трапеция — углы при боковой стороне 180°, средняя линия \(\frac{a + b}{2}\), \(S = \frac{a + b}{2}h\), «уголок» \(\frac{a - b}{2}\).
№18. Клетки. Формула или «достроить и вычесть»; длина — Пифагор; тангенс — противолежащий на прилежащий; середина отрезка — среднее арифметическое координат.
№19. Утверждения. Справочники уроков 44 и 47; искать ловушку в одном слове.

Практика на уроке

1. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) \(AC = BC = 5\), \(AB = 8\). Найдите площадь треугольника.
РешениеВысота \(CH\) к основанию — медиана: \(AH = 4\). \(CH = \sqrt{25 - 16} = 3\). \(S = \frac{8\cdot3}{2} = 12\).

Ответ: 12

2. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В прямоугольном треугольнике гипотенуза равна 10, а один из острых углов равен \(45^\circ\). Найдите площадь треугольника.
РешениеТреугольник равнобедренный: катеты \(a = b\), \(a^2 + a^2 = 100\) → \(a^2 = 50\). \(S = \frac{a\cdot a}{2} = \frac{50}{2} = 25\).

Ответ: 25

3. Прототип ОГЭ №16 (ФИПИ / Решу ОГЭ)
Треугольник \(ABC\) вписан в окружность с центром \(O\), \(\angle BAC = 32^\circ\). Найдите \(\angle BOC\).
РешениеЦентральный угол вдвое больше вписанного на ту же дугу: \(64^\circ\).

Ответ: 64

4. Прототип ОГЭ №17 (ФИПИ / Решу ОГЭ)
Периметр ромба равен 40, а один из его углов равен \(60^\circ\). Найдите меньшую диагональ ромба.
РешениеСторона 10. Меньшая диагональ с двумя сторонами образует равносторонний треугольник: диагональ 10.

Ответ: 10

5. Прототип ОГЭ №17 (ФИПИ / Решу ОГЭ)
В трапеции \(ABCD\) основания \(AD = 5\) и \(BC = 2\), а её площадь равна 28. Найдите площадь треугольника \(ACD\).
РешениеВысота трапеции: \(28 = \frac{5 + 2}{2}\cdot h\) → \(h = 8\). У треугольника \(ACD\) основание \(AD = 5\) и та же высота: \(S = \frac{5\cdot8}{2} = 20\).

Ответ: 20

6. Прототип ОГЭ №18 (ФИПИ / Решу ОГЭ)
На клетчатой бумаге отмечены точки \(A\), \(B\) и \(C\). Найдите расстояние от точки \(A\) до середины отрезка \(BC\).
РешениеСередина \(BC\): \(M\left(\frac{2 + 6}{2}; \frac{8 + 2}{2}\right) = (4; 5)\). От \(A(1; 1)\): 3 по горизонтали, 4 по вертикали. \(AM = 5\).

Ответ: 5

7. Прототип ОГЭ №19 (ФИПИ / Решу ОГЭ)
Какие утверждения верны? 1) В равнобедренном треугольнике медиана, проведённая к основанию, является высотой. 2) Около любого ромба можно описать окружность. 3) Площадь трапеции равна произведению средней линии на высоту.
Решение1 — верно. 2 — неверно (только около квадрата — у ромба противоположные углы в сумме не 180°, если он не квадрат). 3 — верно.

Ответ: 13

Домашнее задание

1. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) \(AC = BC = 13\), \(AB = 10\). Найдите площадь треугольника.
РешениеПоловина основания 5, высота \(\sqrt{169 - 25} = 12\). \(S = \frac{10\cdot12}{2} = 60\).

Ответ: 60

2. Прототип ОГЭ №16 (ФИПИ / Решу ОГЭ)
Треугольник \(ABC\) вписан в окружность с центром \(O\), \(\angle BOC = 130^\circ\) (точки \(O\) и \(A\) по одну сторону от \(BC\)). Найдите \(\angle BAC\).
Решение\(130 : 2 = 65^\circ\).

Ответ: 65

3. Прототип ОГЭ №17 (ФИПИ / Решу ОГЭ)
В трапеции \(ABCD\) основания \(AD = 7\) и \(BC = 3\), площадь трапеции 40. Найдите площадь треугольника \(ACD\).
Решение\(40 = 5h\) → \(h = 8\). \(S_{ACD} = \frac{7\cdot8}{2} = 28\).

Ответ: 28

4. Прототип ОГЭ №18 (ФИПИ / Решу ОГЭ)
На клетчатой бумаге изображён треугольник. Найдите его площадь.
РешениеПрямоугольник \(7\times5 = 35\). Треугольники: \(\frac{7\cdot2}{2} = 7\), \(\frac{4\cdot3}{2} = 6\), \(\frac{3\cdot5}{2} = 7{,}5\). \(S = 35 - 20{,}5 = 14{,}5\).

Ответ: 14,5

5. Прототип ОГЭ №19 (ФИПИ / Решу ОГЭ)
Какие утверждения верны? 1) Вписанные углы, опирающиеся на одну дугу, равны. 2) Если две стороны треугольника равны, то равны и углы, лежащие напротив них. 3) Средняя линия трапеции равна сумме оснований.
Решение1 — верно. 2 — верно (углы при основании равнобедренного треугольника). 3 — неверно (полусумме).

Ответ: 12

6. Повторение (урок 66) Полис стоил 6 000 рублей. Коэффициент КБМ уменьшился с 1 до 0,85, остальные множители не изменились. Сколько рублей стоит полис теперь?
Решение\(6000\cdot0{,}85 = 5100\) руб.

Ответ: 5100

7. Повторение (урок 64) Решите уравнение \(x^2 - 64 = 0\). В ответ запишите меньший корень.
Решение\(\pm8\), меньший \(-8\).

Ответ: \(-8\)

8. Повторение (урок 60) По формуле \(P = I^2R\) найдите силу тока \(I\), если \(P = 405\) Вт, \(R = 5\) Ом.
Решение\(I^2 = 81\) → \(I = 9\) А.

Ответ: 9
