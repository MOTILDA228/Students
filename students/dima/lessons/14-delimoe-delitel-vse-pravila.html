Для репетитора: план урока

Новая идея урока: последние два правила (делимое = частное · делитель; делитель = делимое : частное) и таблица всех шести правил — её Дима должен уметь написать по памяти.

  1. 0–12 мин — разминка-повторение (8 задач на время; две — таблица/деление). Ошибки — сразу разобрать.
  2. 12–22 мин — новое: шпаргалка, проговорить алгоритм вслух, 2 примера у доски.
  3. 22–50 мин — «лесенка»: ступень 1 вместе (вы подсказываете), ступень 2 сам, ступень 3 сам на время. Кто быстро — дальше, не дожидаясь.
  4. 50–60 мин — мини-срез из 5 задач без подсказок. Результат: 5 → 10 баллов, 4 → 8, 3 → 6, 2 → 4 — в журнал.

Ошибки, которые ждём: в срезе \(x : 4 = 12\) разделил вместо умножения; \(84 : x = 7\) — не решил. Путает делимое и делитель.

Правило «проверь себя»: после каждого ответа — подставить обратно (умножением, сложением). Требовать это всегда, вслух.

ДЗ короткое (15 мин) и только на то, что получалось на уроке. Не сделал ДЗ — первые 10 минут следующего урока решает его при вас.

Разминка-повторение (12 минут)

1. Повторение (урок 13) В треугольнике два угла \(35^\circ\) и \(36^\circ\). Найдите третий.
Решение\(180 - 35 - 36 = 109^\circ\).

Ответ: 109

2. Повторение (урок 13) Один из смежных углов равен \(28^\circ\). Найдите другой.
РешениеСмежные в сумме \(180^\circ\): \(180 - 28 = 152^\circ\).

Ответ: 152

3. Повторение (урок 12) 8 одинаковых пачек тетрадей содержат 248 тетрадей. Сколько тетрадей в одной пачке? (Уравнение \(8\cdot x = 248\).)
РешениеНеизвестный множитель: \(x = 248 : 8 = 31\).

Ответ: 31

4. Повторение (урок 12) Решите уравнение \(x\cdot4 = 100\).
РешениеНеизвестный множитель = произведение : известный множитель: \(x = 100 : 4 = 25\). Проверка: \(4\cdot25 = 100\) ✓.

Ответ: 25

5. Повторение (урок 10) На клетчатой бумаге с клеткой \(1\times1\) изображён прямоугольник. Найдите его площадь.
РешениеСчитаем клетки: длина 7, ширина 5. \(S = 7\cdot5 = 35\).

Ответ: 35

6. Повторение (урок 10) Стороны прямоугольника 15 см и 5 см. Найдите площадь.
Решение\(S = 15\cdot5 = 75\) см².

Ответ: 75

7. Повторение (урок 8) Вычислите \(20 : 5\).
РешениеВспоминаем «семейство»: \(5\cdot4 = 20\), значит \(20 : 5 = 4\).

Ответ: 4

8. Повторение (урок 8) Какое число пропущено: \(4\cdot\square = 12\)?
РешениеПропущенный множитель: \(12 : 4 = 3\).

Ответ: 3

Шпаргалка

1. Названия

\(\underbrace{48}_{\text{делимое}} : \underbrace{4}_{\text{делитель}} = \underbrace{12}_{\text{частное}}\)

2. Два новых правила

Где \(x\)ПравилоПример
\(x : 4 = 12\)Делимое = частное · делитель\(x = 12\cdot4 = 48\)
\(84 : x = 7\)Делитель = делимое : частное\(x = 84 : 7 = 12\)
На пальцах. Конфеты разделили на 4 человека, каждому по 12. Сколько было? — \(12\cdot4 = 48\).
84 конфеты раздали, каждому по 7. Сколько было людей? — \(84 : 7 = 12\).

3. Все шесть правил (выучить таблицу!)

НеизвестноеКак найти
слагаемоесумма − другое слагаемое
уменьшаемоеразность + вычитаемое
вычитаемоеуменьшаемое − разность
множительпроизведение : другой множитель

Простое правило-подсказка: если \(x\) — «самое большое» число в примере (сумма, уменьшаемое, делимое), делаем обратное действие с двумя другими. Иначе — то же действие, «большое минус/делить на малое».
