Шпаргалка

1. Что такое угол

Угол — это два луча, которые выходят из одной точки, как стрелки часов. Точка — вершина, лучи — стороны. Угол измеряют в градусах (°).

Острый — меньше 90° (уже прямого).
Прямой — ровно 90° (как уголок тетради).
Тупой — больше 90°, но меньше 180°.
Развёрнутый — 180° (прямая линия).

2. Смежные углы

Прямую разрезали лучом → получились два соседних угла. Вместе они — прямая, то есть 180°. \[ \angle 1 + \angle 2 = 180^\circ \] Знаешь один — второй: 180 минус известный.

3. Вертикальные углы

Две прямые пересеклись → углы напротив друг друга (как ножницы) равны: \( \angle 1 = \angle 2 \).

4. Сумма углов треугольника

В любом треугольнике: \( \angle A + \angle B + \angle C = 180^\circ \).
Нашли два угла → третий: 180 − первый − второй.
Углы 50° и 60°. Третий: \(180 - 50 - 60 = 70^\circ\).
Прямоугольный треугольник: один угол 90°, значит два других острых вместе дают 90°.

5. Внешний угол треугольника

Продлили сторону — снаружи получился внешний угол. Он смежный с углом треугольника и равен сумме двух других углов треугольника (не соседних с ним).

6. Задачи вида «один больше другого»

Меньший угол обозначаем \(x\), больший записываем через него, складываем, приравниваем к 180, решаем.

Практика на уроке

1. Один из смежных углов равен 47°. Найдите другой.
РешениеСмежные вместе дают 180°: \(180 - 47 = 133^\circ\).

Ответ: 133

2. Сумма двух вертикальных углов равна 140°. Найдите каждый угол.
РешениеВертикальные углы равны, значит сумму делим пополам: \(140 : 2 = 70^\circ\).

Ответ: 70

3. Два угла треугольника равны 48° и 67°. Найдите третий.
Решение\(180 - 48 - 67 = 180 - 115 = 65^\circ\).

Ответ: 65

4. Один из смежных углов на 30° больше другого. Найдите больший угол.
РешениеМеньший \(x\), больший \(x + 30\). Вместе: \(x + x + 30 = 180\), \(2x = 150\), \(x = 75\). Больший: \(75 + 30 = 105^\circ\). Проверка: \(75 + 105 = 180\) ✓.

Ответ: 105

5. Один из острых углов прямоугольного треугольника равен 34°. Найдите другой острый угол.
РешениеДва острых угла вместе дают 90°: \(90 - 34 = 56^\circ\).

Ответ: 56

6. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) внешний угол при вершине \(C\) равен 115°, угол \(A\) равен 47°. Найдите угол \(B\).
РешениеВнешний угол = сумма двух углов, не соседних с ним: \(\angle A + \angle B = 115^\circ\). \(\angle B = 115 - 47 = 68^\circ\).

Ответ: 68

7. Прототип ОГЭ №19 (ФИПИ / Решу ОГЭ)
Какие из утверждений верны? В ответ запишите их номера без пробелов.
1) Сумма смежных углов равна 180°.
2) Вертикальные углы равны.
3) Сумма углов любого треугольника равна 360°.
Решение1 — верно. 2 — верно. 3 — неверно, сумма равна 180°.

Ответ: 12

Домашнее задание

1. Один из смежных углов равен 118°. Найдите другой.
Решение\(180 - 118 = 62^\circ\).

Ответ: 62

2. В прямоугольном треугольнике один из острых углов равен 25°. Найдите другой острый угол.
Решение\(180 - 90 - 25 = 65^\circ\) (или \(90 - 25\)).

Ответ: 65

3. Один из смежных углов в 4 раза больше другого. Найдите меньший угол.
РешениеМеньший \(x\), больший \(4x\). \(x + 4x = 180\), \(5x = 180\), \(x = 36^\circ\). Проверка: \(36 + 144 = 180\) ✓.

Ответ: 36

4. Сумма двух вертикальных углов равна 250°. Найдите один из них.
РешениеВертикальные равны: \(250 : 2 = 125^\circ\).

Ответ: 125

5. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) внешний угол при вершине \(B\) равен 132°, угол \(A\) равен 57°. Найдите угол \(C\).
Решение\(\angle A + \angle C = 132^\circ\), \(\angle C = 132 - 57 = 75^\circ\).

Ответ: 75

6. Прототип ОГЭ №19 (ФИПИ / Решу ОГЭ)
Какие утверждения верны?
1) Если угол острый, то смежный с ним угол тупой.
2) Если два угла треугольника равны по 60°, то третий угол тоже 60°.
3) Существует треугольник с двумя тупыми углами.
Решение1 — верно: \(180 - \text{(меньше 90)}\) даёт больше 90. 2 — верно: \(180 - 60 - 60 = 60\). 3 — неверно: два тупых угла вместе уже больше 180°.

Ответ: 12

7. Повторение (урок 3) Вычислите \(3\frac{1}{2} - 1\frac{3}{4}\). Ответ — десятичной дробью.
Решение\(\frac{7}{2} - \frac{7}{4} = \frac{14}{4} - \frac{7}{4} = \frac{7}{4} = 1{,}75\).

Ответ: 1,75

8. Повторение (урок 4) Вычислите \(3{,}6 : 0{,}12\).
РешениеДвигаем запятую на 2: \(360 : 12 = 30\). Проверка: \(30\cdot0{,}12 = 3{,}6\) ✓.

Ответ: 30
