Для репетитора: план урока

Цель: Дима подставляет числа (особенно отрицательные) в выражения без ошибок в знаках, раскрывает скобки и приводит подобные.

  1. 5–10 мин — проверка ДЗ урока 11 (Пифагор).
  2. 15 мин — шпаргалка. Правило знаков проговорить на примерах с деньгами: «долг умножить на долг…» не работает, лучше просто таблица знаков.
  3. 25–30 мин — практика. Приучать: отрицательное число подставляем в скобках.
  4. 5 мин — итог: «сначала упрости — потом подставь».

Типичные ошибки: \((-3)^2 = -9\); после минуса перед скобкой меняет знак только у первого слагаемого; умножает число перед скобкой только на первое слагаемое.

Шпаргалка

1. Подстановка

Вместо буквы пишем число. Отрицательное число — всегда в скобках.
При \(x = -3\):
\(2x = 2\cdot(-3) = -6\) · \(x^2 = (-3)^2 = 9\) · \(-x^2 = -(-3)^2 = -9\) · \(5 - x = 5 - (-3) = 5 + 3 = 8\)

2. Знаки при умножении и делении

\(+\cdot+ = +\)\(-\cdot- = +\)\(+\cdot- = -\)\(-\cdot+ = -\)
Одинаковые знаки → плюс, разные → минус. Вычитание минуса — это плюс: \(5 - (-3) = 5 + 3\).

3. Подобные слагаемые

Подобные — с одинаковой буквенной частью. Складываем числа перед буквами, буква остаётся.
\(3a + 5a = 8a\) · \(7x - 10x = -3x\) · \(x + x = 2x\) · \(4a + 3b\) — не складываются (буквы разные)

4. Раскрытие скобок

Плюс перед скобкой — просто убираем скобки: \(+(a - 3) = a - 3\).
Минус перед скобкой — меняем знак у каждого слагаемого: \(-(a - 3) = -a + 3\).
Число перед скобкой — умножаем на каждое слагаемое: \(3(a - 2) = 3a - 6\), \(-2(x - 5) = -2x + 10\).
\(-2(x - 5) \ne -2x - 10\)! Минус на минус даёт плюс: \((-2)\cdot(-5) = +10\).

5. Алгоритм «Найдите значение выражения при…»

  1. Раскрой скобки.
  2. Приведи подобные — выражение станет коротким.
  3. Только теперь подставь число.
\(5(x - 2) - 3x\) при \(x = 4\): \(5x - 10 - 3x = 2x - 10\). Подставляем: \(2\cdot4 - 10 = -2\).

6. Формулы в ОГЭ №12

В задании №12 дают формулу из физики или геометрии и числа. Подставляем числа вместо букв и считаем. Так же, как в пункте 1.

Практика на уроке

1. Найдите значение выражения \(3x - 7\) при \(x = -2\).
Решение\(3\cdot(-2) - 7 = -6 - 7 = -13\).

Ответ: \(-13\)

2. Найдите значение выражения \(a^2 - 2a\) при \(a = -3\).
Решение\((-3)^2 - 2\cdot(-3) = 9 - (-6) = 9 + 6 = 15\).

Ответ: 15

3. Упростите выражение \(4(x - 3) - 2x\) и найдите его значение при \(x = 7\).
РешениеРаскрываем: \(4x - 12 - 2x = 2x - 12\). Подставляем: \(2\cdot7 - 12 = 14 - 12 = 2\).

Ответ: 2

4. Упростите выражение \(7 - (3 - 2a) + 4a\) и найдите его значение при \(a = 0{,}5\).
РешениеМинус перед скобкой меняет оба знака: \(7 - 3 + 2a + 4a = 4 + 6a\). Подставляем: \(4 + 6\cdot0{,}5 = 4 + 3 = 7\).

Ответ: 7

5. По мотивам ОГЭ №8
Найдите значение выражения \(7(a + 3) - 4(a - 1)\) при \(a = 1{,}5\).
РешениеРаскрываем: \(7a + 21 - 4a + 4\) (минус на минус — плюс). Подобные: \(3a + 25\). Подставляем: \(3\cdot1{,}5 + 25 = 4{,}5 + 25 = 29{,}5\).

Ответ: 29,5

6. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Площадь четырёхугольника можно вычислить по формуле \(S = \frac{d_1 d_2\sin\alpha}{2}\), где \(d_1\) и \(d_2\) — длины диагоналей, \(\alpha\) — угол между ними. Пользуясь этой формулой, найдите площадь \(S\), если \(d_1 = 7\), \(d_2 = 15\), \(\sin\alpha = \frac{2}{5}\).
РешениеПодставляем: \(S = \frac{7\cdot15\cdot\frac{2}{5}}{2}\). Считаем числитель: \(7\cdot15 = 105\), \(105\cdot\frac{2}{5} = 42\). Делим на 2: \(S = 21\).

Ответ: 21

7. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Мощность постоянного тока (в ваттах) вычисляется по формуле \(P = I^2R\), где \(I\) — сила тока (в амперах), \(R\) — сопротивление (в омах). Пользуясь этой формулой, найдите мощность \(P\), если \(R = 6\) Ом и \(I = 1{,}5\) А.
Решение\(I^2 = 1{,}5^2 = 2{,}25\). \(P = 2{,}25\cdot6 = 13{,}5\) Вт.

Ответ: 13,5

Домашнее задание

1. Найдите значение выражения \(5 - 2x\) при \(x = -4\).
Решение\(5 - 2\cdot(-4) = 5 - (-8) = 5 + 8 = 13\).

Ответ: 13

2. Найдите значение выражения \(x^2 + 3x\) при \(x = -5\).
Решение\((-5)^2 + 3\cdot(-5) = 25 - 15 = 10\).

Ответ: 10

3. Упростите выражение \(4(2 - y) + 6y\) и найдите его значение при \(y = 3\).
Решение\(8 - 4y + 6y = 8 + 2y\). При \(y = 3\): \(8 + 6 = 14\).

Ответ: 14

4. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Площадь треугольника можно вычислить по формуле \(S = \frac{bc\sin\alpha}{2}\), где \(b\) и \(c\) — две стороны, \(\alpha\) — угол между ними. Найдите площадь \(S\), если \(b = 16\), \(c = 9\), \(\sin\alpha = \frac{1}{3}\).
Решение\(16\cdot9 = 144\); \(144\cdot\frac{1}{3} = 48\); \(48 : 2 = 24\).

Ответ: 24

5. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Кинетическая энергия тела (в джоулях) вычисляется по формуле \(E = \frac{mv^2}{2}\), где \(m\) — масса (в кг), \(v\) — скорость (в м/с). Найдите \(E\), если \(m = 4\) кг, \(v = 3\) м/с.
Решение\(v^2 = 9\). \(E = \frac{4\cdot9}{2} = \frac{36}{2} = 18\) Дж.

Ответ: 18

6. Повторение (урок 10) Вычислите \(\sqrt{3}\cdot\sqrt{27}\).
Решение\(\sqrt{3\cdot27} = \sqrt{81} = 9\).

Ответ: 9

7. Повторение (урок 8) В треугольнике \(ABC\) проведена биссектриса \(AD\), \(\angle BAC = 58^\circ\). Найдите \(\angle BAD\).
РешениеБиссектриса делит угол пополам: \(58 : 2 = 29^\circ\).

Ответ: 29

8. Повторение (урок 4) Вычислите \(13{,}2 : 0{,}4\).
РешениеДвигаем запятую на 1 знак: \(132 : 4 = 33\). Проверка: \(33\cdot0{,}4 = 13{,}2\) ✓.

Ответ: 33
