Для репетитора: план урока

Новая идея урока: тангенс угла по клеткам: достроить прямоугольный треугольник, \(\operatorname{tg} = \frac{\text{противолежащий}}{\text{прилежащий}}\). Средняя линия: треугольника — половина стороны, трапеции — полусумма оснований.

  1. 0–12 мин — разминка-повторение (8 задач на время; две — таблица/деление). Ошибки — сразу разобрать.
  2. 12–22 мин — новое: шпаргалка, проговорить алгоритм вслух, 2 примера у доски.
  3. 22–50 мин — «лесенка»: ступень 1 вместе (вы подсказываете), ступень 2 сам, ступень 3 сам на время. Кто быстро — дальше, не дожидаясь.
  4. 50–60 мин — мини-срез из 5 задач без подсказок. Результат: 5 → 10 баллов, 4 → 8, 3 → 6, 2 → 4 — в журнал.

Ошибки, которые ждём: переворачивает дробь в тангенсе; путает, какой катет «прилежащий» (тот, что у угла).

Правило «проверь себя»: после каждого ответа — подставить обратно (умножением, сложением). Требовать это всегда, вслух.

ДЗ короткое (15 мин) и только на то, что получалось на уроке. Не сделал ДЗ — первые 10 минут следующего урока решает его при вас.

Разминка-повторение (12 минут)

1. Повторение (урок 42) Найдите значение выражения \(3a^2 - b^3\) при \(a = 4\), \(b = 3\).
Решение\(3\cdot16 - 3^3 = 48 - 27 = 21\).

Ответ: 21

2. Повторение (урок 42) Вычислите \(\frac{2^{5}}{2^{3}}\).
РешениеПри делении показатели вычитаются: \(2^{5-3} = 2^2 = 4\).

Ответ: 4

3. Повторение (урок 41) Катеты прямоугольного треугольника равны 12 и 35. Найдите гипотенузу.
Решение\(c^2 = 12^2 + 35^2 = 144 + 1225 = 1369\), \(c = \sqrt{1369} = 37\).

Ответ: 37

4. Повторение (урок 41) Найдите значение выражения \(\frac{11{,}2}{0{,}8}\).
РешениеПереносим запятую: \(112 : 8 = 14\).

Ответ: 14

5. Повторение (урок 39) Вписанный угол равен \(99^\circ\). Найдите центральный угол, опирающийся на ту же дугу.
РешениеЦентральный — в 2 раза больше: \(198^\circ\).

Ответ: 198

6. Повторение (урок 39) В равнобедренном треугольнике угол при вершине \(94^\circ\). Найдите угол при основании.
РешениеУглы при основании равны: \((180 - 94) : 2 = 43^\circ\).

Ответ: 43

7. Повторение (урок 8) Вычислите \(40 : 5\).
РешениеВспоминаем «семейство»: \(5\cdot8 = 40\), значит \(40 : 5 = 8\).

Ответ: 8

8. Повторение (урок 8) Какое число пропущено: \(8\cdot\square = 24\)?
РешениеПропущенный множитель: \(24 : 8 = 3\).

Ответ: 3

Шпаргалка

1. Тангенс по клеткам

Из точки на одной стороне опускаем перпендикуляр на другую. Противолежащий катет — напротив угла (здесь 3), прилежащий — у угла (здесь 4). \(\operatorname{tg} = \frac{3}{4} = 0{,}75\).

2. Средняя линия

Треугольника: соединяет середины двух сторон, равна половине третьей. Трапеции: \(\frac{a + b}{2}\).
