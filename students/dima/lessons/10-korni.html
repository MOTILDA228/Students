Для репетитора: план урока

Цель: Дима извлекает корни по таблице квадратов, умножает и делит корни, решает прототипы №8 с корнями.

  1. 5–10 мин — проверка ДЗ урока 9. Быстрый устный опрос по таблице квадратов 11–20.
  2. 15 мин — шпаргалка: «корень — это вопрос: какое число в квадрате даёт…?»
  3. 25–30 мин — практика. В задачах 3–5 и 7 сначала объединить всё под один корень, потом считать.
  4. 5 мин — итог + предупреждение: корни нельзя складывать «под одним корнем».

Типичные ошибки: \(\sqrt{0{,}49} = 0{,}07\); \(\sqrt{9+16} = 3 + 4\); \(\sqrt{16} = 8\) (делит на 2).

Шпаргалка

1. Что такое корень

\(\sqrt{a}\) — это число, которое в квадрате даёт \(a\). Корень — всегда число \(\ge 0\).
Спрашиваем себя: «какое число, умноженное само на себя, даёт \(a\)?»
\(\sqrt{49} = 7\), потому что \(7^2 = 49\) · \(\sqrt{144} = 12\), потому что \(12^2 = 144\) · \(\sqrt{0} = 0\) · \(\sqrt{1} = 1\)
\(\sqrt{16} = 4\), а не 8! Корень — это не «разделить на 2». Из отрицательного числа корень не извлекается: \(\sqrt{-9}\) не существует.

2. Корень из десятичной дроби и из обыкновенной

Десятичная: знаков после запятой под корнем вдвое больше, чем в ответе.
\(\sqrt{0{,}49} = 0{,}7\) (проверка: \(0{,}7\cdot0{,}7 = 0{,}49\)) · \(\sqrt{0{,}0016} = 0{,}04\) · \(\sqrt{1{,}21} = 1{,}1\)
Обыкновенная: корень отдельно из числителя и из знаменателя: \(\sqrt{\frac{9}{25}} = \frac{3}{5}\).

3. Корень и квадрат «уничтожают» друг друга

\((\sqrt{a})^2 = a\): \((\sqrt{7})^2 = 7\) · \((\sqrt{13})^2 = 13\)
\(\sqrt{a^2} = a\), если \(a \ge 0\), и минус теряется, если \(a < 0\): \(\sqrt{(-5)^2} = \sqrt{25} = 5\).

4. Умножение и деление корней

\(\sqrt{a}\cdot\sqrt{b} = \sqrt{a\cdot b}\) · \(\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}}\) — собираем всё под один корень, считаем, извлекаем.
\(\sqrt{2}\cdot\sqrt{8} = \sqrt{16} = 4\) · \(\frac{\sqrt{50}}{\sqrt{2}} = \sqrt{25} = 5\)
И наоборот, корень из произведения — произведение корней: \(\sqrt{16\cdot25} = 4\cdot5 = 20\).
Корень из степени — показатель пополам: \(\sqrt{2^4} = 2^2 = 4\), \(\sqrt{3^6} = 3^3 = 27\).
Складывать нельзя! \(\sqrt{9 + 16} = \sqrt{25} = 5\), а \(\sqrt{9} + \sqrt{16} = 3 + 4 = 7\). Это разные числа.

5. Между какими целыми числами корень

  1. Найди ближайший квадрат меньше числа и ближайший квадрат больше.
  2. Корень лежит между корнями из этих квадратов.
\(\sqrt{30}\): \(25 < 30 < 36\), значит, \(5 < \sqrt{30} < 6\). Число 30 ближе к 25, чем к 36, поэтому \(\sqrt{30}\) ближе к 5 (примерно 5,5).

Практика на уроке

1. Вычислите: а) \(\sqrt{81}\); б) \(\sqrt{0{,}49}\); в) \(\sqrt{144}\).
Решениеа) \(9^2 = 81\) → 9. б) \(0{,}7^2 = 0{,}49\) → 0,7 (под корнем 2 знака после запятой — в ответе 1). в) \(12^2 = 144\) → 12.

Ответ: а) 9; б) 0,7; в) 12

2. Вычислите \((\sqrt{7})^2 + \sqrt{36}\).
Решение\((\sqrt{7})^2 = 7\) — корень и квадрат уничтожились. \(\sqrt{36} = 6\). \(7 + 6 = 13\).

Ответ: 13

3. Вычислите \(\sqrt{2}\cdot\sqrt{32}\).
РешениеСобираем под один корень: \(\sqrt{2\cdot32} = \sqrt{64} = 8\).

Ответ: 8

4. Вычислите \(\sqrt{16\cdot25}\).
РешениеКорень из каждого множителя: \(\sqrt{16}\cdot\sqrt{25} = 4\cdot5 = 20\).

Ответ: 20

5. Вычислите \(\frac{\sqrt{75}}{\sqrt{3}}\).
РешениеСобираем под один корень: \(\sqrt{\frac{75}{3}} = \sqrt{25} = 5\).

Ответ: 5

6. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\sqrt{3^4\cdot2^6}\).
РешениеКорень из степени — показатель пополам: \(\sqrt{3^4} = 3^2 = 9\), \(\sqrt{2^6} = 2^3 = 8\). \(9\cdot8 = 72\).

Ответ: 72

7. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{\sqrt{12}\cdot\sqrt{6}}{\sqrt{8}}\).
РешениеВсё под один корень: \(\sqrt{\frac{12\cdot6}{8}} = \sqrt{\frac{72}{8}} = \sqrt{9} = 3\).

Ответ: 3

Домашнее задание

1. Вычислите: а) \(\sqrt{64}\); б) \(\sqrt{1{,}21}\); в) \(\sqrt{400}\); г) \((\sqrt{11})^2\).
Решениеа) 8 (\(8^2 = 64\)). б) 1,1 (\(1{,}1\cdot1{,}1 = 1{,}21\)). в) 20 (\(20^2 = 400\)). г) Корень и квадрат уничтожаются: 11.

Ответ: а) 8; б) 1,1; в) 20; г) 11

2. Вычислите \(\sqrt{5}\cdot\sqrt{20}\).
Решение\(\sqrt{5\cdot20} = \sqrt{100} = 10\).

Ответ: 10

3. Вычислите \(\frac{\sqrt{98}}{\sqrt{2}}\).
Решение\(\sqrt{98 : 2} = \sqrt{49} = 7\).

Ответ: 7

4. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\sqrt{7^2\cdot3^4}\).
Решение\(\sqrt{7^2} = 7\), \(\sqrt{3^4} = 3^2 = 9\). \(7\cdot9 = 63\).

Ответ: 63

5. Между какими двумя соседними целыми числами находится \(\sqrt{50}\)? В ответ запишите оба числа через точку с запятой.
РешениеКвадраты рядом с 50: \(49 = 7^2\) и \(64 = 8^2\). \(49 < 50 < 64\), значит, \(7 < \sqrt{50} < 8\).

Ответ: 7; 8

6. Повторение (урок 8) В равнобедренном треугольнике угол при вершине равен \(80^\circ\). Найдите угол при основании.
Решение\((180 - 80) : 2 = 50^\circ\).

Ответ: 50

7. Повторение (урок 6) Найдите значение выражения \(\frac{1}{\frac{1}{3} - \frac{1}{4}}\).
РешениеЗнаменатель: \(\frac{4}{12} - \frac{3}{12} = \frac{1}{12}\). Единицу делим на дробь — переворачиваем: 12.

Ответ: 12

8. Повторение (урок 2) Вычислите \(0{,}36 : 0{,}4\).
РешениеДвигаем запятую на 1 знак: \(3{,}6 : 4 = 0{,}9\). Проверка: \(0{,}9\cdot0{,}4 = 0{,}36\) ✓.

Ответ: 0,9
