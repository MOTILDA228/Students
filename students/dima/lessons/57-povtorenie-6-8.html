Для репетитора: план урока

Цель: довести до автоматизма три «числовых» задания первой части. Здесь нельзя терять баллы из-за счёта.

  1. 5–10 мин — проверка ДЗ урока 56.
  2. 10 мин — три шпаргалки ниже, проговорить алгоритмы.
  3. 35 мин — практика вперемешку. Засекать время: на каждое задание не больше 3–4 минут.
  4. 5 мин — итог: какое из трёх заданий самое «опасное» — его повторить дома ещё раз.

Типичные ошибки: \((-10)^3\) считает как 1000; в №7 не проверяет все варианты; в №8 подставляет число до упрощения.

Шпаргалка

№6 — вычисления

• Порядок действий: скобки → степени → умножение и деление → сложение и вычитание.
• Есть и обыкновенные, и десятичные дроби → переводи в тот вид, где считать удобнее (урок 6).
• Степени десятки со знаком: \((-10)^2 = 100\), \((-10)^3 = -1000\), \((-10)^4 = 10\,000\).
• Ответ — конечная десятичная дробь или целое число.
\(-0{,}6\cdot(-10)^4 + 4\cdot(-10)^2 - 59 = -0{,}6\cdot10000 + 4\cdot100 - 59 = -6000 + 400 - 59 = -5659\).

№7 — числа на прямой

• Корень: найди соседние квадраты (урок 15).
• Дроби: переведи в десятичные и сравни.
• Буквы на прямой: подставь конкретные числа по рисунку и проверь каждый вариант.
• «\(a < b\), какое неравенство верно?»: прибавлять и вычитать одно число можно — знак сохраняется; умножать на отрицательное — знак меняется.

№8 — степени, корни, выражения

• Степени с одним основанием: складываем/вычитаем показатели, потом подставляем (урок 9).
• Корни: \(\sqrt{a}\cdot\sqrt{b} = \sqrt{ab}\); \((k\sqrt{a})^2 = k^2a\) (урок 10).
• Формулы: \((a - b)(a + b) = a^2 - b^2\) (урок 21).
• Дроби с буквами: разложить, сократить, потом подставить (урок 43).
\(\frac{(2\sqrt{7})^2}{14} = \frac{4\cdot7}{14} = 2\).

Практика на уроке

1. Прототип ОГЭ №6 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{1{,}6}{0{,}2\cdot0{,}8}\).
РешениеЗнаменатель: \(0{,}2\cdot0{,}8 = 0{,}16\). \(1{,}6 : 0{,}16 = 160 : 16 = 10\).

Ответ: 10

2. Прототип ОГЭ №6 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(-0{,}6\cdot(-10)^4 + 4\cdot(-10)^2 - 59\).
Решение\((-10)^4 = 10000\), \((-10)^2 = 100\). \(-6000 + 400 - 59 = -5659\).

Ответ: \(-5659\)

3. Прототип ОГЭ №6 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{17}{20} - \frac{3}{4}\).
Решение\(\frac{17}{20} - \frac{15}{20} = \frac{2}{20} = 0{,}1\).

Ответ: 0,1

4. Прототип ОГЭ №7 (ФИПИ / Решу ОГЭ)
Какое из чисел отмечено на координатной прямой точкой \(A\)?
1) \(\frac{2}{9}\)2) \(\frac{3}{5}\)3) \(0{,}85\)4) \(\frac{9}{10}\)
Решение\(A\) чуть правее 0,5. \(\frac{2}{9} \approx 0{,}22\); \(\frac{3}{5} = 0{,}6\) — подходит; 0,85 и 0,9 — ближе к 1.

Ответ: 2

5. Прототип ОГЭ №7 (ФИПИ / Решу ОГЭ)
О числах \(a\) и \(b\) известно, что \(a < b\). Какое из неравенств верно?
1) \(a - b > 0\)2) \(b - a < 0\)3) \(a + 5 < b + 5\)4) \(-a < -b\)
РешениеПусть \(a = 1\), \(b = 2\). 1) \(-1 > 0\) — нет. 2) \(1 < 0\) — нет. 3) \(6 < 7\) — да. 4) \(-1 < -2\) — нет.

Ответ: 3

6. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{a^{-4}\cdot a^{6}}{a^{-1}}\) при \(a = 2\).
РешениеПоказатель: \(-4 + 6 - (-1) = 3\). \(2^3 = 8\).

Ответ: 8

7. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{(2\sqrt{7})^2}{14}\).
Решение\((2\sqrt{7})^2 = 4\cdot7 = 28\). \(28 : 14 = 2\).

Ответ: 2

Домашнее задание

1. Прототип ОГЭ №6 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{2{,}7}{0{,}3\cdot0{,}9}\).
Решение\(0{,}3\cdot0{,}9 = 0{,}27\). \(2{,}7 : 0{,}27 = 10\).

Ответ: 10

2. Прототип ОГЭ №6 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(0{,}5\cdot(-10)^3 + 3\cdot(-10)^2 + 8\).
Решение\(0{,}5\cdot(-1000) + 300 + 8 = -500 + 308 = -192\).

Ответ: \(-192\)

3. Прототип ОГЭ №7 (ФИПИ / Решу ОГЭ)
О числах \(a\) и \(b\) известно, что \(a < b\). Какое из неравенств верно?
1) \(a - 3 > b - 3\)2) \(-2a < -2b\)3) \(\frac{a}{2} < \frac{b}{2}\)4) \(b - a < 0\)
РешениеДелить на положительное число можно, знак сохраняется: вариант 3. Проверка на \(a = 1\), \(b = 2\): \(0{,}5 < 1\) ✓.

Ответ: 3

4. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{(3\sqrt{5})^2}{15}\).
Решение\(9\cdot5 = 45\), \(45 : 15 = 3\).

Ответ: 3

5. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{a^{8}\cdot a^{-2}}{a^{4}}\) при \(a = 7\).
РешениеПоказатель \(8 - 2 - 4 = 2\). \(7^2 = 49\).

Ответ: 49

6. Повторение (урок 55) На тарелке 30 пирожков, 12 из них с капустой. Найдите вероятность того, что случайно выбранный пирожок окажется с капустой.
Решение\(\frac{12}{30} = 0{,}4\).

Ответ: 0,4

7. Повторение (урок 53) В треугольнике \(ABC\) известно, что \(AB = BC\), внешний угол при вершине \(C\) равен \(140^\circ\). Найдите угол \(B\).
Решение\(\angle C = 40^\circ = \angle A\). \(\angle B = 180 - 80 = 100^\circ\).

Ответ: 100

8. Повторение (урок 49) Найдите объём парного отделения размером \(3\times2\times2{,}2\) м (в м³).
Решение\(3\cdot2\cdot2{,}2 = 13{,}2\) м³.

Ответ: 13,2
