Для репетитора: план урока

Цель: графики и формулы — ещё два балла, которые берутся по алгоритму. Добавляем формулы, где нужно извлечь корень или решить уравнение.

  1. 5–10 мин — проверка ДЗ урока 59.
  2. 10 мин — две шпаргалки ниже.
  3. 35 мин — практика: сначала три №11, потом четыре №12.
  4. 5 мин — итог.

Типичные ошибки: в №11 путает графики \(\frac{k}{x}\) с \(k > 0\) и \(k < 0\); в №12 не извлекает корень в конце (\(I^2 = 49\) → пишет 49).

Шпаргалка

№11 — как узнать график

ВидФормулаЧто смотреть
прямая\(y = kx + b\)\(b\) — пересечение с осью \(y\); \(k > 0\) — вверх, \(k < 0\) — вниз
парабола\(y = ax^2 + c\)\(a > 0\) — ветви вверх; \(c\) — пересечение с осью \(y\)
гипербола\(y = \frac{k}{x}\)\(k > 0\) — I и III четверти; \(k < 0\) — II и IV
Сомневаешься — подставь \(x = 1\) в формулу и проверь, проходит ли график через эту точку.

№12 — формулы

  1. Выпиши известные буквы и искомую.
  2. Подставь, посчитай всё числовое.
  3. Реши уравнение. Если получилось \(I^2 = 49\) — извлеки корень: \(I = 7\) (величины в физике положительные).
\(PV = \nu RT\), \(R = 8{,}31\): \(\nu = 10\), \(P = 20\,775\), \(V = 4\) → \(83\,100 = 83{,}1\,T\) → \(T = 1000\).

Практика на уроке

1. Прототип ОГЭ №11 (ФИПИ / Решу ОГЭ)
Установите соответствие между графиками функций и формулами, которые их задают.
1) \(y = 3x - 1\)2) \(y = -0{,}5x + 2\)3) \(y = x + 3\)
РешениеА: круто вверх, ось \(y\) в \(-1\) → 1. Б: полого вниз, в 2 → 2. В: вверх, в 3 → 3.

Ответ: 123

2. Прототип ОГЭ №11 (ФИПИ / Решу ОГЭ)
Установите соответствие между графиками функций и формулами, которые их задают.
1) \(y = -\frac{4}{x}\)2) \(y = \frac{4}{x}\)3) \(y = -x^2 + 3\)
РешениеА — парабола → 3. Б — гипербола в I и III четвертях (\(k > 0\)) → 2. В — во II и IV (\(k < 0\)) → 1.

Ответ: 321

3. Прототип ОГЭ №11 (ФИПИ / Решу ОГЭ)
Установите соответствие между графиками функций \(y = kx + b\) и знаками коэффициентов.
1) \(k > 0,\ b > 0\)2) \(k < 0,\ b > 0\)3) \(k < 0,\ b < 0\)
РешениеА: вниз, ниже нуля → 3. Б: вверх, выше нуля → 1. В: вниз, выше нуля → 2.

Ответ: 312

4. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Площадь поверхности прямоугольного параллелепипеда с рёбрами \(a\), \(b\) и \(c\) вычисляется по формуле \(S = 2(ab + ac + bc)\). Найдите \(c\), если \(a = 3\), \(b = 4\), \(S = 94\).
Решение\(94 = 2(12 + 3c + 4c)\) → \(47 = 12 + 7c\) → \(7c = 35\) → \(c = 5\).

Ответ: 5

5. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Мощность постоянного тока (в ваттах) вычисляется по формуле \(P = I^2R\). Найдите силу тока \(I\) (в амперах), если \(P = 245\) Вт, \(R = 5\) Ом.
Решение\(245 = 5I^2\) → \(I^2 = 49\) → \(I = 7\) А.

Ответ: 7

6. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Закон Менделеева–Клапейрона можно записать в виде \(PV = \nu RT\), где \(R = 8{,}31\). Найдите температуру \(T\) (в кельвинах), если \(\nu = 10\) моль, \(P = 20\,775\) Па, \(V = 4\) м³.
Решение\(20775\cdot4 = 83100\); \(10\cdot8{,}31 = 83{,}1\). \(T = 83100 : 83{,}1 = 1000\) К.

Ответ: 1000

7. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Длина окружности \(C = 2\pi R\). Считая \(\pi \approx 3{,}14\), найдите радиус \(R\), если \(C = 31{,}4\).
Решение\(31{,}4 = 6{,}28R\) → \(R = 5\).

Ответ: 5

2. Прототип ОГЭ №11 (ФИПИ / Решу ОГЭ)

1) \(y = -x^2\)2) \(y = x^2 - 2\)3) \(y = \frac{1}{x}\)
РешениеА — гипербола → 3. Б — ветви вниз, вершина в начале координат → 1. В — ветви вверх, ось \(y\) в \(-2\) → 2.

Ответ: 312

3. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
По формуле \(S = 2(ab + ac + bc)\) найдите \(c\), если \(a = 2\), \(b = 5\), \(S = 104\).
Решение\(52 = 10 + 2c + 5c\) → \(7c = 42\) → \(c = 6\).

Ответ: 6

4. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)

Решение\(I^2 = 36\) → \(I = 6\) А.

Ответ: 6

5. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Длина окружности \(C = 2\pi R\). Считая \(\pi \approx 3{,}14\), найдите \(C\), если \(R = 4{,}5\).
Решение\(2\cdot3{,}14\cdot4{,}5 = 6{,}28\cdot4{,}5 = 28{,}26\).

Ответ: 28,26

6. Повторение (урок 58) Решите уравнение \(x^2 - 9x = 0\). Запишите корни в порядке возрастания.
Решение\(x(x - 9) = 0\): 0 и 9.

Ответ: 0; 9
