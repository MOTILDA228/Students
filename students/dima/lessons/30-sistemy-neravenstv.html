Цель: Дима решает системы линейных неравенств: решает каждое, рисует оба на одной прямой и находит общую часть.

  1. 5–10 мин — проверка ДЗ урока 29.
  2. 15 мин — шпаргалка. Аналогия: «прийти на урок можно после 14:00 и до 16:00» — подходит только время между.
  3. 25–30 мин — практика. Две штриховки рисовать разным наклоном или цветом.
  4. 5 мин — итог: «система — это И: нужна общая часть».

Типичные ошибки: объединяет вместо пересечения; не замечает случай «нет решений»; забывает перевернуть знак при делении на минус.

Шпаргалка

1. Что такое система

\(\begin{cases} x > -1 \\ x \le 3 \end{cases}\) — фигурная скобка значит «И»: нужны числа, для которых верны оба неравенства сразу.

2. Алгоритм

  1. Реши каждое неравенство отдельно (урок 27).
  2. Нарисуй оба решения на одной прямой.
  3. Ответ — там, где штриховки перекрываются.
Ответ: \(-1 < x \le 3\), то есть \((-1;\ 3]\). Концы: \(-1\) выколота (знак строгий), 3 закрашена.

3. Когда решений нет

\(\begin{cases} x > 5 \\ x < -1 \end{cases}\): числа больше 5 и одновременно меньше \(-1\) не бывает. Штриховки не пересекаются → нет решений.

4. Как считать целые решения

Выпиши целые числа от левого конца до правого. Выколотый конец не считаем, закрашенный — считаем. \((-1;\ 3]\): 0, 1, 2, 3 — четыре числа.

Практика на уроке

1. Решите систему \(\begin{cases} x > 2 \\ x < 7 \end{cases}\). Сколько целых чисел являются её решениями?
РешениеОбщая часть: \(2 < x < 7\). Целые: 3, 4, 5, 6 — четыре.

Ответ: 4

2. Решите систему \(\begin{cases} 2x - 4 \ge 0 \\ x - 6 < 0 \end{cases}\). Найдите наибольшее целое решение.
Решение\(x \ge 2\) и \(x < 6\) → \([2;\ 6)\). 6 не входит, наибольшее целое: 5.

Ответ: 5

3. Решите систему \(\begin{cases} 3x + 1 > 7 \\ 2x - 3 \le 9 \end{cases}\). Найдите сумму всех целых решений.
Решение\(3x > 6\) → \(x > 2\); \(2x \le 12\) → \(x \le 6\). Общая часть \((2;\ 6]\): 3, 4, 5, 6. Сумма: 18.

Ответ: 18

4. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Укажите решение системы неравенств \(\begin{cases} x + 3 \ge 0 \\ x - 2 < 0 \end{cases}\).
Решение\(x \ge -3\) и \(x < 2\) → \([-3;\ 2)\): \(-3\) закрашена, 2 выколота — вариант 2.

Ответ: 2

5. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Укажите решение системы неравенств \(\begin{cases} x - 5 > 0 \\ x + 1 < 0 \end{cases}\).
1) \((-1;\ 5)\)2) \((-\infty;\ -1)\)3) \((5;\ +\infty)\)4) нет решений
Решение\(x > 5\) и \(x < -1\) — таких чисел нет. Вариант 4.

Ответ: 4

6. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Укажите решение системы неравенств \(\begin{cases} -2x > -8 \\ x + 3 > 0 \end{cases}\).
1) \((-3;\ +\infty)\)2) \((-\infty;\ 4)\)3) \((-3;\ 4)\)4) \((4;\ +\infty)\)
Решение\(-2x > -8\) → делим на \(-2\), знак переворачивается: \(x < 4\). \(x > -3\). Общая часть: \((-3;\ 4)\) — вариант 3.

Ответ: 3

7. При каких \(x\) оба выражения \(2x - 1\) и \(10 - x\) положительны? Сколько таких целых \(x\)?
РешениеСистема \(\begin{cases} 2x - 1 > 0 \\ 10 - x > 0 \end{cases}\) → \(x > 0{,}5\) и \(x < 10\). Целые: 1, 2, …, 9 — девять.

Ответ: 9

Домашнее задание

1. Решите систему \(\begin{cases} x \ge -2 \\ x < 3 \end{cases}\). Сколько целых чисел являются её решениями?
Решение\([-2;\ 3)\): \(-2, -1, 0, 1, 2\) — пять.

Ответ: 5

2. Решите систему \(\begin{cases} 4x - 8 > 0 \\ x - 7 \le 0 \end{cases}\). Найдите наименьшее целое решение.
Решение\(x > 2\) и \(x \le 7\) → \((2;\ 7]\). Наименьшее целое: 3.

Ответ: 3

3. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Укажите решение системы неравенств \(\begin{cases} x - 4 \le 0 \\ x + 1 > 0 \end{cases}\).
Решение\(x \le 4\) и \(x > -1\) → \((-1;\ 4]\): \(-1\) выколота, 4 закрашена — вариант 3.

Ответ: 3

4. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Укажите решение системы неравенств \(\begin{cases} x + 2 > 0 \\ 3 - x > 0 \end{cases}\).
1) \((-2;\ 3)\)2) \((-\infty;\ -2)\cup(3;\ +\infty)\)3) \((3;\ +\infty)\)4) нет решений
Решение\(x > -2\); \(3 - x > 0\) → \(x < 3\). Общая часть \((-2;\ 3)\) — вариант 1.

Ответ: 1

5. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Укажите решение системы неравенств \(\begin{cases} 2x + 1 > 5 \\ x - 1 < 0 \end{cases}\).
1) \((1;\ 2)\)2) \((2;\ +\infty)\)3) \((-\infty;\ 1)\)4) нет решений
Решение\(2x > 4\) → \(x > 2\); \(x < 1\). Больше 2 и меньше 1 одновременно не бывает — нет решений, вариант 4.

Ответ: 4

6. Повторение (урок 28) Решите неравенство \(x^2 - 25 < 0\). Сколько целых чисел являются его решениями?
Решение\(-5 < x < 5\): от \(-4\) до 4 — девять чисел.

Ответ: 9

7. Повторение (урок 26) Сумма двух углов равнобедренной трапеции равна \(140^\circ\). Найдите больший угол трапеции.
РешениеДва острых угла по \(70^\circ\). Больший: \(180 - 70 = 110^\circ\).

Ответ: 110

8. Повторение (урок 22) Решите уравнение \(3x^2 - 48 = 0\). Запишите корни в порядке возрастания.
Решение\(x^2 = 16\) → \(-4\) и 4.

Ответ: \(-4\); 4
