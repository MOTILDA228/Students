Для репетитора: план урока

Новая идея урока: сюжетные задачи №1–5. Сначала две «подготовительные» ступени на нужные навыки, потом сам сюжет ОГЭ (ступень 3). Сюжет читать вслух вместе, подписать на рисунке/в таблице всё известное.

  1. 0–12 мин — разминка-повторение (8 задач на время; две — таблица/деление). Ошибки — сразу разобрать.
  2. 12–22 мин — новое: шпаргалка, проговорить алгоритм вслух, 2 примера у доски.
  3. 22–50 мин — «лесенка»: ступень 1 вместе (вы подсказываете), ступень 2 сам, ступень 3 сам на время. Кто быстро — дальше, не дожидаясь.
  4. 50–60 мин — мини-срез из 5 задач без подсказок. Результат: 5 → 10 баллов, 4 → 8, 3 → 6, 2 → 4 — в журнал.

Ошибки, которые ждём: бросает сюжет, увидев длинный текст. Правило: задачи 1–5 независимы — не получилась одна, переходи к следующей. Мини-срез здесь — сам сюжет: сколько из 5 верно → ×2 в журнал.

Правило «проверь себя»: после каждого ответа — подставить обратно (умножением, сложением). Требовать это всегда, вслух.

ДЗ короткое (15 мин) и только на то, что получалось на уроке. Не сделал ДЗ — первые 10 минут следующего урока решает его при вас.

Разминка-повторение (12 минут)

1. Повторение (урок 37) Найдите значение выражения \(\left(\frac{3}{25} + \frac{2}{5}\right)\cdot5\).
РешениеСкобка: \(0{,}52\); умножаем на 5: \(2{,}6\).

Ответ: 2,6

2. Повторение (урок 37) Найдите значение выражения \(-0{,}9\cdot(-10)^3 + 2\cdot(-10)^2 - 45\).
Решение\((-10)^3 = -1000\), \((-10)^2 = 100\): \(900 + 200 - 45 = 1055\).

Ответ: 1055

3. Повторение (урок 36) Сумма двух углов параллелограмма \(136^\circ\). Найдите один из оставшихся углов.
РешениеРавные углы по 68°, оставшиеся по 112°.

Ответ: 112

4. Повторение (урок 36) Найдите площадь трапеции на клетчатой бумаге (клетка \(1\times1\)).
РешениеОснования 5 и 3, высота 4: \(S = \frac{5+3}{2}\cdot4 = 16\).

Ответ: 16

5. Повторение (урок 34) В лотерее 40 билетов, выигрышных 24. Найдите вероятность того, что билет выигрышный.
Решение\(P = \frac{24}{40} = 0{,}6\).

Ответ: 0,6

6. Повторение (урок 34) Бросают игральный кубик. Найдите вероятность того, что выпадет число меньше 4.
РешениеПодходят: 1, 2, 3 — 3 из 6: \(0{,}5\).

Ответ: 0,5

7. Повторение (урок 8) Вычислите \(18 : 2\).
РешениеВспоминаем «семейство»: \(2\cdot9 = 18\), значит \(18 : 2 = 9\).

Ответ: 9

8. Повторение (урок 14) Решите уравнение \(x : 8 = 13\).
РешениеНеизвестное делимое = частное · делитель: \(x = 13\cdot8 = 104\). Проверка: \(104 : 8 = 13\) ✓.

Ответ: 104

Как решать сюжет №1–5

  1. Прочитать весь текст, не решая. Подчеркнуть числа.
  2. Подписать на рисунке или в таблице, что есть что.
  3. Каждую задачу 1–5 решать отдельно; не вышло — пропустить.
  4. Перед ответом — проверить единицы (м, см, руб., мин).
Обычно задачи 1–2 самые лёгкие (найти в таблице, посчитать по рисунку) — их нельзя терять.

Ступень 1. Проценты и стоимость

1. Сколько процентов составляет 40 от 200?
Решение\(\frac{40}{200}\cdot100\% = 20\%\).

Ответ: 20

2. Сколько процентов составляет 2 от 20?
Решение\(\frac{2}{20}\cdot100\% = 10\%\).

Ответ: 10

3. Цена 2300 руб. повысилась на 20%. Какой стала цена?
РешениеСтало 120%: \(2300\cdot1{,}2 = 2760\) руб.

Ответ: 2760

4. Сколько процентов составляет 10 от 40?
Решение\(\frac{10}{40}\cdot100\% = 25\%\).

Ответ: 25

5. Товар стоит 5100 руб. Сколько он будет стоить со скидкой 20%?
РешениеОстаётся 80%: \(5100\cdot0{,}8 = 4080\) руб.

Ответ: 4080

6. 5% числа равны 10. Найдите это число.
Решение1% — это \(10 : 5 = 2\); 100% — \(2\cdot100 = 200\).

Ответ: 200

Ступень 2. Формулы-тарифы

1. Формула \(S = vt\) — путь \(S\) (км), скорость \(v\) (км/ч), время \(t\) (ч). Найдите \(S\), если \(v = 7\), \(t = 27\).
РешениеПодставляем: \(v = 7\), \(t = 27\) → \(S = 189\).

Ответ: 189

2. Формула \(C = 150 + 11(t - 5)\) — стоимость поездки на такси \(C\) (руб.) длительностью \(t\) мин. Найдите \(C\), если \(t = 34\).
РешениеПодставляем: \(t = 34\) → \(C = 469\).

Ответ: 469

3. Формула \(F = 1{,}8C + 32\) — температура по Фаренгейту через Цельсий. Найдите \(F\), если \(C = 32\).
РешениеПодставляем: \(C = 32\) → \(F = 89{,}6\).

Ответ: 89,6

4. Формула \(S = vt\) — путь \(S\) (км), скорость \(v\) (км/ч), время \(t\) (ч). Найдите \(S\), если \(v = 13\), \(t = 25\).
РешениеПодставляем: \(v = 13\), \(t = 25\) → \(S = 325\).

Ответ: 325

5. Стоимость заказа считают по формуле \(C = 15 + 5n\), где \(n\) — число предметов. Сколько предметов заказали, если \(C = 55\)?
Решение\(55 = 15 + 5n\) → \(5n = 40\) → \(n = 8\).

Ответ: 8

6. Стоимость заказа считают по формуле \(C = 24 + 4n\), где \(n\) — число предметов. Сколько предметов заказали, если \(C = 156\)?
Решение\(156 = 24 + 4n\) → \(4n = 132\) → \(n = 33\).

Ответ: 33

7. Стоимость заказа считают по формуле \(C = 76 + 5n\), где \(n\) — число предметов. Сколько предметов заказали, если \(C = 266\)?
Решение\(266 = 76 + 5n\) → \(5n = 190\) → \(n = 38\).

Ответ: 38

Условие сюжета и подсказки

1. Как устроены задания 1–5

Сначала идёт общий текст (про квартиру, участок, тарифы, шины…), часто с таблицей или схемой. Потом 5 вопросов по этому тексту. Каждый вопрос — 1–3 действия, но всё нужное спрятано в тексте.
  1. Прочитай общий текст целиком. Подчеркни числа и единицы (рубли, кВт·ч, ГБ, метры).
  2. Разберись в таблице: что в строках, что в столбцах.
  3. В каждом вопросе найди: что спрашивают, какие числа нужны, какое действие.
  4. Ответ — только число, без единиц измерения.

2. Три главных действия

Расход по счётчику = показание в конце − показание в начале.
Стоимость = количество × цена за единицу.
Сравнение: «на сколько больше» — вычитание; «во сколько раз» — деление; «на сколько процентов» — разность : старое значение · 100 (урок 7).
Счётчик показывал 2340, через месяц — 2490. Израсходовано \(2490 - 2340 = 150\) кВт·ч. При цене 5 руб. за кВт·ч платим \(150\cdot5 = 750\) руб.

3. Скидки и наценки (повторение урока 7)

Скидка \(p\%\) → умножить на \(1 - \frac{p}{100}\): скидка 20% → \(\cdot0{,}8\).
Наценка \(p\%\) → умножить на \(1 + \frac{p}{100}\): наценка 15% → \(\cdot1{,}15\).

Ступень 3. Сюжет ОГЭ

1. Показания счётчика электроэнергии 1 марта — 3518 кВт·ч, а 1 апреля — 3732 кВт·ч. Сколько киловатт-часов израсходовано за март?
РешениеРасход = конец − начало: \(3732 - 3518 = 214\) кВт·ч.

Ответ: 214

2. 1 кВт·ч электроэнергии стоит 5,6 руб. За месяц израсходовано 150 кВт·ч. Сколько рублей нужно заплатить?
Решение\(150\cdot5{,}6 = 840\) руб.

Ответ: 840

3. Сюжет в формате ОГЭ №1–5 «Электроэнергия»

Прочитайте текст и выполните задания 3–7.

Семья Смирновых живёт в квартире, где установлен двухтарифный счётчик электроэнергии. Днём (с 7:00 до 23:00) электроэнергия стоит 6,4 руб. за 1 кВт·ч, ночью (с 23:00 до 7:00) — 3,2 руб. за 1 кВт·ч. Раньше у семьи был однотарифный счётчик, по которому 1 кВт·ч стоил 5,8 руб. в любое время суток. Показания счётчика приведены в таблице.

Показания, кВт·ч1 марта1 апреля
День (Т1)42134413
Ночь (Т2)16501750

Сколько киловатт-часов электроэнергии семья израсходовала днём за март?

РешениеСтрока «День»: \(4413 - 4213 = 200\) кВт·ч.

Ответ: 200

4. Сколько рублей семья заплатит за дневную электроэнергию за март?
РешениеДневной расход 200 кВт·ч по 6,4 руб.: \(200\cdot6{,}4 = 1280\) руб.

Ответ: 1280

5. Сколько рублей семья заплатит за всю электроэнергию за март?
РешениеНочной расход: \(1750 - 1650 = 100\) кВт·ч, стоимость \(100\cdot3{,}2 = 320\) руб. Всего: \(1280 + 320 = 1600\) руб.

Ответ: 1600

6. Сколько рублей сэкономила семья за март, если сравнить с оплатой по однотарифному счётчику?
РешениеВсего израсходовано \(200 + 100 = 300\) кВт·ч. По однотарифному: \(300\cdot5{,}8 = 1740\) руб. Экономия: \(1740 - 1600 = 140\) руб.

Ответ: 140

7. На сколько процентов ночной тариф дешевле дневного?
РешениеРазница: \(6{,}4 - 3{,}2 = 3{,}2\) руб. Делим на дневной тариф (с ним сравниваем): \(\frac{3{,}2}{6{,}4} = 0{,}5\) → 50%.

Ответ: 50
