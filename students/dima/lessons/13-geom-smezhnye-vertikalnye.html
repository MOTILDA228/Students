Для репетитора: план урока

Новая идея урока: три факта, на которых держится половина геометрии ОГЭ: смежные — \(180^\circ\), вертикальные равны, сумма углов треугольника \(180^\circ\).

  1. 0–12 мин — разминка-повторение (8 задач на время; две — таблица/деление). Ошибки — сразу разобрать.
  2. 12–22 мин — новое: шпаргалка, проговорить алгоритм вслух, 2 примера у доски.
  3. 22–50 мин — «лесенка»: ступень 1 вместе (вы подсказываете), ступень 2 сам, ступень 3 сам на время. Кто быстро — дальше, не дожидаясь.
  4. 50–60 мин — мини-срез из 5 задач без подсказок. Результат: 5 → 10 баллов, 4 → 8, 3 → 6, 2 → 4 — в журнал.

Ошибки, которые ждём: путает смежные и вертикальные; в треугольнике складывает углы, а не вычитает из 180.

Правило «проверь себя»: после каждого ответа — подставить обратно (умножением, сложением). Требовать это всегда, вслух.

ДЗ короткое (15 мин) и только на то, что получалось на уроке. Не сделал ДЗ — первые 10 минут следующего урока решает его при вас.

Разминка-повторение (12 минут)

1. Повторение (урок 12) 8 одинаковых пачек тетрадей содержат 304 тетрадей. Сколько тетрадей в одной пачке? (Уравнение \(8\cdot x = 304\).)
РешениеНеизвестный множитель: \(x = 304 : 8 = 38\).

Ответ: 38

2. Повторение (урок 12) Решите уравнение \(4\cdot x = 116\).
РешениеНеизвестный множитель = произведение : известный множитель: \(x = 116 : 4 = 29\). Проверка: \(4\cdot29 = 116\) ✓.

Ответ: 29

3. Повторение (урок 11) Решите уравнение \(90 - x = 54\).
РешениеНеизвестное вычитаемое = уменьшаемое − разность: \(x = 90 - 54 = 36\). Проверка: \(90 - 36 = 54\) ✓.

Ответ: 36

4. Повторение (урок 11) Решите уравнение \(x - 119 = 38\).
РешениеНеизвестное уменьшаемое = разность + вычитаемое: \(x = 38 + 119 = 157\). Проверка: \(157 - 119 = 38\) ✓.

Ответ: 157

5. Повторение (урок 9) Решите уравнение \(14 + x = 133\).
РешениеНеизвестное слагаемое = сумма − известное слагаемое: \(x = 133 - 14 = 119\). Проверка: \(119 + 14 = 133\) ✓.

Ответ: 119

6. Повторение (урок 9) Задумали число, прибавили к нему 16 и получили 37. Какое число задумали? (Составьте уравнение \(x + 16 = 37\).)
Решение\(x = 37 - 16 = 21\).

Ответ: 21

7. Повторение (урок 8) Вычислите \(15 : 5\).
РешениеВспоминаем «семейство»: \(5\cdot3 = 15\), значит \(15 : 5 = 3\).

Ответ: 3

8. Повторение (урок 8) Какое число пропущено: \(8\cdot\square = 32\)?
РешениеПропущенный множитель: \(32 : 8 = 4\).

Ответ: 4

Шпаргалка

1. Смежные углы

Общая сторона, две другие — продолжение друг друга. Сумма \(180^\circ\).

2. Вертикальные углы

Две прямые пересеклись — углы «напротив» друг друга равны.

3. Сумма углов треугольника

\(\angle A + \angle B + \angle C = 180^\circ\). Неизвестный угол: \(180 - \) (сумма двух известных).
Углы 47° и 68°: третий \(180 - 47 - 68 = 65^\circ\).
В прямоугольном треугольнике один угол \(90^\circ\), значит два острых в сумме \(90^\circ\).
