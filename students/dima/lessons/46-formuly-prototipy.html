Для репетитора: план урока

Цель: Дима уверенно решает №12 с любыми формулами: со степенями, корнем, отрицательными числами, дробями.

  1. 5–10 мин — проверка ДЗ урока 45.
  2. 10 мин — повторить алгоритм урока 13 и «копилку» формул ниже.
  3. 30 мин — практика. Проговаривать: «что известно, что ищем, получилось уравнение…».
  4. 5 мин — итог.

Типичные ошибки: в формуле с корнем забывает возвести в квадрат; путает порядок действий в \(150 + 11(t - 5)\); неверно считает \(10^{-4}\).

Шпаргалка

1. Алгоритм (урок 13)

  1. Выпиши, чему равна каждая буква, и какую букву ищем.
  2. Подставь числа, посчитай всё, что считается.
  3. Если искомая буква внутри — реши уравнение обратными действиями.
  4. Проверь подстановкой.

2. Корень в формуле

Если \(\sqrt{l} = 2{,}5\), то \(l = 2{,}5^2 = 6{,}25\): чтобы «снять» корень, возводим в квадрат.
\(T = 2\sqrt{l}\), \(T = 5\): \(5 = 2\sqrt{l}\) → \(\sqrt{l} = 2{,}5\) → \(l = 6{,}25\).

Практика на уроке

1. Сумму углов выпуклого \(n\)-угольника можно вычислить по формуле \(S = 180^\circ(n - 2)\). Найдите сумму углов выпуклого семиугольника.
Решение\(n = 7\): \(180\cdot5 = 900^\circ\).

Ответ: 900

2. По той же формуле \(S = 180^\circ(n - 2)\) найдите число сторон выпуклого многоугольника, если сумма его углов равна \(1080^\circ\).
Решение\(1080 = 180(n - 2)\) → \(n - 2 = 6\) → \(n = 8\).

Ответ: 8

3. Радиус окружности, вписанной в прямоугольный треугольник, можно найти по формуле \(r = \frac{a + b - c}{2}\), где \(a\) и \(b\) — катеты, \(c\) — гипотенуза. Найдите \(r\), если \(a = 6\), \(b = 8\), \(c = 10\).
Решение\(r = \frac{6 + 8 - 10}{2} = \frac{4}{2} = 2\).

Ответ: 2

4. Стоимость поездки на такси длительностью больше 5 минут вычисляется по формуле \(C = 150 + 11(t - 5)\), где \(t\) — длительность поездки в минутах. Найдите стоимость 12-минутной поездки (в рублях).
Решение\(C = 150 + 11\cdot(12 - 5) = 150 + 77 = 227\) руб.

Ответ: 227

5. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Период колебания математического маятника \(T\) (в секундах) приближённо можно вычислить по формуле \(T = 2\sqrt{l}\), где \(l\) — длина нити (в метрах). Пользуясь этой формулой, найдите длину нити маятника, период колебаний которого составляет 5 секунд.
Решение\(5 = 2\sqrt{l}\) → \(\sqrt{l} = 2{,}5\) → \(l = 6{,}25\) м.

Ответ: 6,25

6. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Энергия заряженного конденсатора \(W\) (в джоулях) вычисляется по формуле \(W = \frac{CU^2}{2}\), где \(C\) — ёмкость конденсатора (в фарадах), а \(U\) — разность потенциалов на обкладках (в вольтах). Найдите энергию \(W\), если \(C = 10^{-4}\) Ф и \(U = 20\) В.
Решение\(U^2 = 400\). \(W = \frac{10^{-4}\cdot400}{2} = \frac{0{,}04}{2} = 0{,}02\) Дж.

Ответ: 0,02

7. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
В фирме «Родник» стоимость (в рублях) колодца из железобетонных колец рассчитывается по формуле \(C = 6000 + 4100n\), где \(n\) — число колец, установленных в колодце. Пользуясь этой формулой, рассчитайте стоимость колодца из 5 колец.
Решение\(C = 6000 + 4100\cdot5 = 6000 + 20500 = 26500\) руб.

Ответ: 26500

Домашнее задание

1. По формуле \(S = 180^\circ(n - 2)\) найдите сумму углов выпуклого десятиугольника.
Решение\(180\cdot8 = 1440^\circ\).

Ответ: 1440

2. По формуле \(r = \frac{a + b - c}{2}\) найдите радиус вписанной окружности прямоугольного треугольника с катетами 5 и 12 и гипотенузой 13.
Решение\(\frac{5 + 12 - 13}{2} = 2\).

Ответ: 2

3. По формуле \(C = 150 + 11(t - 5)\) найдите стоимость 20-минутной поездки на такси (в рублях).
Решение\(150 + 11\cdot15 = 150 + 165 = 315\) руб.

Ответ: 315

4. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
По формуле \(T = 2\sqrt{l}\) найдите длину нити маятника (в метрах), период колебаний которого составляет 6 секунд.
Решение\(\sqrt{l} = 3\) → \(l = 9\) м.

Ответ: 9

5. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Стоимость колодца \(C = 6000 + 4100n\) (в рублях), где \(n\) — число колец. Сколько колец в колодце, если он стоит 38 800 рублей?
Решение\(38800 = 6000 + 4100n\) → \(4100n = 32800\) → \(n = 8\).

Ответ: 8

6. Повторение (урок 44) Какие из утверждений верны? 1) Сумма углов треугольника равна \(180^\circ\). 2) Треугольник со сторонами 2, 3, 6 существует. 3) Медиана, проведённая к гипотенузе, равна половине гипотенузы.
Решение1 — верно. 2 — неверно: \(2 + 3 < 6\). 3 — верно.

Ответ: 13

7. Повторение (урок 42) Найдите значение функции \(y = \frac{8}{x}\) при \(x = -4\).
Решение\(8 : (-4) = -2\).

Ответ: \(-2\)

8. Повторение (урок 38) Из точки \(A\) проведены касательные \(AB\) и \(AC\) к окружности с центром \(O\), \(\angle BAC = 64^\circ\). Найдите \(\angle BOC\).
Решение\(360 - 90 - 90 - 64 = 116^\circ\).

Ответ: 116
