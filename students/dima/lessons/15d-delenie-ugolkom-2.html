Для репетитора: план урока

Новая идея урока: главная ловушка деления — ноль в частном: снесли цифру, а число меньше делителя — пишем 0 и сносим следующую. Каждый ответ проверяем умножением. Метод для Димы: всё — на клетчатой бумаге, одна цифра — одна клетка, единицы строго под единицами. Первые 3 примера он проговаривает вслух каждый шаг, вы только задаёте вопросы («что делим? сколько раз помещается? что пишем?»). Карточку-алгоритм держать перед ним весь урок. Ошибку не исправлять за него — спросить «проверь умножением».

  1. 0–12 мин — разминка-повторение (8 задач на время; две — таблица/деление). Ошибки — сразу разобрать.
  2. 12–22 мин — новое: шпаргалка, проговорить алгоритм вслух, 2 примера у доски.
  3. 22–50 мин — «лесенка»: ступень 1 вместе (вы подсказываете), ступень 2 сам, ступень 3 сам на время. Кто быстро — дальше, не дожидаясь.
  4. 50–60 мин — мини-срез из 5 задач без подсказок. Результат: 5 → 10 баллов, 4 → 8, 3 → 6, 2 → 4 — в журнал.

Ошибки, которые ждём: в срезе знаменитое «824 : 4 = 26» вместо 206 — потерян ноль. Помогает прикидка числа цифр (урок 15c) и проверка умножением.

Правило «проверь себя»: после каждого ответа — подставить обратно (умножением, сложением). Требовать это всегда, вслух.

ДЗ короткое (15 мин) и только на то, что получалось на уроке. Не сделал ДЗ — первые 10 минут следующего урока решает его при вас.

3. Повторение (урок 14) Решите уравнение \(x - 115 = 95\).
РешениеНеизвестное уменьшаемое = разность + вычитаемое: \(x = 95 + 115 = 210\). Проверка: \(210 - 115 = 95\) ✓.

Ответ: 210

4. Повторение (урок 14) Решите уравнение \(x : 4 = 23\).
РешениеНеизвестное делимое = частное · делитель: \(x = 23\cdot4 = 92\). Проверка: \(92 : 4 = 23\) ✓.

Ответ: 92

5. Повторение (урок 12) 9 одинаковых пачек тетрадей содержат 243 тетрадей. Сколько тетрадей в одной пачке? (Уравнение \(9\cdot x = 243\).)
РешениеНеизвестный множитель: \(x = 243 : 9 = 27\).

Ответ: 27

6. Повторение (урок 12) Решите уравнение \(8\cdot x = 192\).
РешениеНеизвестный множитель = произведение : известный множитель: \(x = 192 : 8 = 24\). Проверка: \(8\cdot24 = 192\) ✓.

Ответ: 24

7. Повторение (урок 8) Вычислите \(21 : 7\).
РешениеВспоминаем «семейство»: \(7\cdot3 = 21\), значит \(21 : 7 = 3\).

Ответ: 3

8. Повторение (урок 8) Какое число пропущено: \(9\cdot\square = 63\)?
РешениеПропущенный множитель: \(63 : 9 = 7\).

Ответ: 7

  1. \(8 : 4 = 2\), \(2\cdot4 = 8\), \(8 - 8 = 0\).
  2. Сносим 2. 2 меньше 4 — в частное пишем 0, сносим следующую цифру 4 → 24.
