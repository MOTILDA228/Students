Для репетитора: план урока

Цель: №18 и №19 — самые надёжные геометрические баллы. Вместе с №15 они обеспечивают обязательный минимум по геометрии. Цель — решать их без ошибок за 3–4 минуты каждое.

  1. 5–10 мин — проверка ДЗ урока 61.
  2. 5 мин — повторить таблицу видов №18 (урок 50) и оба справочника №19 (уроки 44, 47).
  3. 40 мин — практика: четыре №18 и три №19, с засечкой времени.
  4. 5 мин — итог.

Типичные ошибки: в №18 не дорисовывает высоту/катеты; в №19 торопится и не видит ловушку в одном слове.

Шпаргалка

1. Памятка по №18

Площадь — формула или «достроить и вычесть». Длина — Пифагор по клеткам. Средняя линия — полусумма оснований (у треугольника — половина стороны). Тангенс — противолежащий катет на прилежащий. Радиус — от центра до точки окружности.

2. Памятка по №19

Читай каждое утверждение до конца. Проверь «опасные» слова: квадратов, половине, любой, всегда, перпендикулярны / равны (диагонали), биссектрис / серединных перпендикуляров (центры окружностей). Не уверен — нарисуй пример.

Практика на уроке

1. Прототип ОГЭ №18 (ФИПИ / Решу ОГЭ)
На клетчатой бумаге с размером клетки \(1\times1\) изображена трапеция. Найдите её площадь.
РешениеОснования 7 и 4, высота 3. \(S = \frac{7 + 4}{2}\cdot3 = 16{,}5\).

Ответ: 16,5

2. Прототип ОГЭ №18 (ФИПИ / Решу ОГЭ)
На клетчатой бумаге изображён угол. Найдите тангенс этого угла.
РешениеПротиволежащий катет 2, прилежащий 4. \(\operatorname{tg} = \frac{2}{4} = 0{,}5\).

Ответ: 0,5

3. Прототип ОГЭ №18 (ФИПИ / Решу ОГЭ)
На клетчатой бумаге с размером клетки \(1\times1\) изображена окружность с центром \(O\), проходящая через точку \(A\). Найдите её радиус.
РешениеОт \(O\) до \(A\): 4 клетки по горизонтали, 3 по вертикали. \(R = 5\).

Ответ: 5

4. Прототип ОГЭ №18 (ФИПИ / Решу ОГЭ)
На клетчатой бумаге с размером клетки \(1\times1\) изображён треугольник \(ABC\). Найдите длину его средней линии, параллельной стороне \(AC\).
Решение\(AC = 8\), средняя линия — половина: 4.

Ответ: 4

5. Прототип ОГЭ №19 (ФИПИ / Решу ОГЭ)
Какие из утверждений верны?
1) Сумма острых углов прямоугольного треугольника равна \(90^\circ\).
2) Средняя линия треугольника равна половине любой его стороны.
3) Если два угла одного треугольника равны двум углам другого, то треугольники подобны.
Решение1 — верно. 2 — неверно: половине той стороны, которой она параллельна. 3 — верно.

Ответ: 13

6. Прототип ОГЭ №19 (ФИПИ / Решу ОГЭ)
Какие из утверждений верны?
1) Диагонали ромба равны.
2) Сумма углов выпуклого четырёхугольника равна \(360^\circ\).
3) Площадь трапеции равна произведению полусуммы оснований на высоту.
Решение1 — неверно. 2 — верно. 3 — верно.

Ответ: 23

7. Прототип ОГЭ №19 (ФИПИ / Решу ОГЭ)
Какие из утверждений верны?
1) Центр окружности, описанной около прямоугольного треугольника, — середина гипотенузы.
2) Вписанный угол, опирающийся на диаметр, равен \(180^\circ\).
3) Касательная к окружности имеет с ней ровно одну общую точку.
Решение1 — верно. 2 — неверно (\(90^\circ\)). 3 — верно.

Ответ: 13

Домашнее задание

1. Прототип ОГЭ №18 (ФИПИ / Решу ОГЭ)
На клетчатой бумаге изображена трапеция. Найдите её площадь.
РешениеОснования 6 и 2, высота 3: \(\frac{6 + 2}{2}\cdot3 = 12\).

Ответ: 12

2. Прототип ОГЭ №18 (ФИПИ / Решу ОГЭ)
На клетчатой бумаге изображён угол. Найдите его тангенс.
РешениеПротиволежащий катет 4, прилежащий 2: \(\operatorname{tg} = 2\).

Ответ: 2

3. Прототип ОГЭ №18 (ФИПИ / Решу ОГЭ)
На клетчатой бумаге изображён треугольник. Найдите его площадь.
РешениеПрямоугольник \(6\times4 = 24\). Треугольники: \(\frac{6\cdot1}{2} = 3\), \(\frac{3\cdot4}{2} = 6\), \(\frac{3\cdot3}{2} = 4{,}5\). \(S = 24 - 13{,}5 = 10{,}5\).

Ответ: 10,5

4. Прототип ОГЭ №19 (ФИПИ / Решу ОГЭ)
Какие из утверждений верны? 1) Любой прямоугольник можно вписать в окружность. 2) Диагонали трапеции точкой пересечения делятся пополам. 3) Каждая сторона треугольника меньше суммы двух других сторон.
Решение1 — верно (центр — точка пересечения диагоналей). 2 — неверно (это свойство параллелограмма). 3 — верно.

Ответ: 13

5. Прототип ОГЭ №19 (ФИПИ / Решу ОГЭ)
Какие из утверждений верны? 1) Катет прямоугольного треугольника, лежащий против угла \(30^\circ\), равен половине гипотенузы. 2) Если диагонали параллелограмма равны, то он является ромбом. 3) Отрезки касательных, проведённых из одной точки к окружности, равны.
Решение1 — верно. 2 — неверно: параллелограмм с равными диагоналями — прямоугольник. 3 — верно.

Ответ: 13

6. Повторение (урок 60) Длина окружности \(C = 2\pi R\). Считая \(\pi \approx 3{,}14\), найдите \(C\), если \(R = 2{,}5\).
Решение\(6{,}28\cdot2{,}5 = 15{,}7\).

Ответ: 15,7

7. Повторение (урок 58) В сборнике 20 билетов, в трёх из них есть вопрос о векторах. Найдите вероятность того, что в случайно выбранном билете этого вопроса не будет.
Решение\(\frac{17}{20} = 0{,}85\).

Ответ: 0,85

8. Повторение (урок 55) Найдите значение выражения \(\left(\frac{3}{20} + \frac{1}{4}\right)\cdot5\).
Решение\(\frac{3}{20} + \frac{5}{20} = \frac{8}{20} = 0{,}4\). \(0{,}4\cdot5 = 2\).

Ответ: 2
