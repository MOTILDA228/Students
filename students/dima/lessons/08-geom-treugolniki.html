Для репетитора: план урока

Цель: Дима различает виды треугольников и три главные линии в треугольнике, решает задачи на равнобедренный треугольник по двум шаблонам.

  1. 5–10 мин — проверка ДЗ урока 7, особенно задачи на повторение (урок 5: углы).
  2. 15 мин — шпаргалка. Рисовать вместе: пусть Дима сам проведёт высоту, медиану и биссектрису в одном треугольнике тремя цветами.
  3. 25–30 мин — практика 1–7. Задачи 6–7 — настоящие прототипы ОГЭ №15.
  4. 5 мин — итог: «высота — 90°, медиана — в середину, биссектриса — угол пополам».

Типичные ошибки: путает угол при вершине и угол при основании; забывает делить на 2; считает, что медиана делит угол пополам.

Шпаргалка

1. Как устроен треугольник

У треугольника 3 вершины (точки \(A, B, C\)), 3 стороны (\(AB, BC, AC\)) и 3 угла. Угол при вершине \(B\) пишут \(\angle B\) или \(\angle ABC\): буква вершины всегда в середине.

Сумма углов любого треугольника — \(180^\circ\) (урок 5).

2. Виды треугольников по углам

3. Равнобедренный и равносторонний

Равнобедренный треугольник: две равные стороны — боковые, третья — основание.
Углы при основании равны. (Чёрточки на рисунке показывают равные стороны, дужки — равные углы.)
Шаблон 1. Дан угол при вершине → угол при основании \(= (180 - \text{вершина}) : 2\).
Вершина \(40^\circ\): \((180 - 40) : 2 = 70^\circ\).

Шаблон 2. Дан угол при основании → угол при вершине \(= 180 - 2\cdot\text{основание}\).
Основание \(65^\circ\): \(180 - 2\cdot 65 = 50^\circ\).
Где вершина, а где основание? Вершина — между двумя равными сторонами. Если \(AB = BC\), то вершина — \(B\) (общая буква), основание — \(AC\).
Равносторонний треугольник: все углы по \(180 : 3 = 60^\circ\).

4. Три главные линии

Высота — из вершины перпендикулярно к противоположной стороне (угол 90°).
Медиана — из вершины в середину противоположной стороны: \(AM = MB\).
Биссектриса — делит угол пополам: \(\angle ACD = \angle DCB\).
Запоминалка: «Биссектриса — это крыса, которая бегает по углам и делит угол пополам». «Медиана — это обезьяна, которая прыгает на сторону и делит её пополам». «Высота — это кот: прыгает на сторону строго под прямым углом».

5. Главный секрет равнобедренного треугольника

В равнобедренном треугольнике высота, проведённая к основанию, одновременно и медиана, и биссектриса. Она делит основание пополам, а угол при вершине — пополам.

Практика на уроке

1. В равнобедренном треугольнике угол при вершине равен \(40^\circ\). Найдите угол при основании.
РешениеРаботает шаблон 1: \((180 - 40) : 2 = 140 : 2 = 70^\circ\). Проверка: \(70 + 70 + 40 = 180\) ✓.

Ответ: 70

2. В равнобедренном треугольнике угол при основании равен \(65^\circ\). Найдите угол при вершине.
РешениеШаблон 2: при основании два равных угла по \(65^\circ\). \(180 - 2\cdot 65 = 180 - 130 = 50^\circ\).

Ответ: 50

3. В треугольнике \(ABC\) проведена биссектриса \(AD\), \(\angle BAC = 64^\circ\). Найдите \(\angle BAD\).
РешениеБиссектриса делит угол пополам: \(64 : 2 = 32^\circ\).

Ответ: 32

4. В треугольнике \(ABC\) проведена медиана \(BM\), \(AC = 18\). Найдите \(AM\).
РешениеМедиана ведёт в середину стороны \(AC\), значит, \(AM = MC = 18 : 2 = 9\).

Ответ: 9

5. В треугольнике \(ABC\) проведена высота \(BH\), \(\angle A = 35^\circ\). Найдите \(\angle ABH\).
РешениеВысота даёт прямой угол: \(\angle AHB = 90^\circ\). Смотрим на маленький треугольник \(ABH\): в нём \(35^\circ\) и \(90^\circ\). Третий угол: \(180 - 90 - 35 = 55^\circ\).

Ответ: 55

6. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) известно, что \(AB = BC\), \(\angle ABC = 108^\circ\). Найдите угол \(BCA\).
Решение\(AB = BC\) — общая буква \(B\), значит, \(B\) — вершина, \(AC\) — основание, а \(\angle BCA\) — угол при основании. Шаблон 1: \((180 - 108) : 2 = 72 : 2 = 36^\circ\).

Ответ: 36

7. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) известно, что \(AC = BC\). Внешний угол при вершине \(B\) равен \(146^\circ\). Найдите угол \(C\).
РешениеШаг 1. Внешний угол и угол \(B\) треугольника — смежные: \(\angle B = 180 - 146 = 34^\circ\).
Шаг 2. \(AC = BC\) — общая буква \(C\), значит, \(C\) — вершина, \(AB\) — основание. Углы при основании равны: \(\angle A = \angle B = 34^\circ\).
Шаг 3. \(\angle C = 180 - 34 - 34 = 112^\circ\).

Ответ: 112

Домашнее задание

1. В равнобедренном треугольнике угол при вершине равен \(120^\circ\). Найдите угол при основании.
Решение\((180 - 120) : 2 = 60 : 2 = 30^\circ\).

Ответ: 30

2. В равнобедренном треугольнике угол при основании равен \(48^\circ\). Найдите угол при вершине.
Решение\(180 - 2\cdot 48 = 180 - 96 = 84^\circ\).

Ответ: 84

3. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) известно, что \(AB = BC\), \(\angle ABC = 106^\circ\). Найдите угол \(BCA\).
РешениеВершина — \(B\) (общая буква у равных сторон). \(\angle BCA\) — угол при основании: \((180 - 106) : 2 = 74 : 2 = 37^\circ\).

Ответ: 37

4. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) известно, что \(AC = BC\). Внешний угол при вершине \(B\) равен \(122^\circ\). Найдите угол \(C\).
Решение\(\angle B = 180 - 122 = 58^\circ\). \(AC = BC\) → вершина \(C\), углы при основании \(A\) и \(B\) равны, \(\angle A = 58^\circ\). \(\angle C = 180 - 58 - 58 = 64^\circ\).

Ответ: 64

5. Прототип ОГЭ №19 (ФИПИ / Решу ОГЭ)
Какие из утверждений верны? В ответ запишите их номера без пробелов.
1) В равнобедренном треугольнике углы при основании равны.
2) Медиана треугольника делит угол пополам.
3) Все углы равностороннего треугольника равны \(60^\circ\).
Решение1 — верно (главное свойство равнобедренного треугольника).
2 — неверно: угол пополам делит биссектриса, а медиана ведёт в середину стороны.
3 — верно: \(180 : 3 = 60^\circ\).

Ответ: 13

6. Повторение (урок 6) Найдите значение выражения \((4{,}3 - 1{,}8)\cdot 1{,}6\).
РешениеСкобка: \(4{,}3 - 1{,}8 = 2{,}5\). Умножаем: \(25\cdot16 = 400\), отделяем 2 знака: \(4{,}00 = 4\).

Ответ: 4

7. Повторение (урок 4) Вычислите \(3{,}72 : 1{,}2\).
РешениеДвигаем запятую на 1 знак в обоих числах: \(37{,}2 : 12\). \(37 : 12 = 3\) (36, остаток 1). Сносим 2, ставим запятую: \(12 : 12 = 1\). Ответ: 3,1. Проверка: \(3{,}1\cdot 1{,}2 = 3{,}72\) ✓.

Ответ: 3,1

8. Повторение (урок 5) Один из смежных углов в 2 раза больше другого. Найдите больший угол.
РешениеМеньший \(x\), больший \(2x\). \(x + 2x = 180\), \(3x = 180\), \(x = 60\). Больший: \(2\cdot 60 = 120^\circ\).

Ответ: 120
