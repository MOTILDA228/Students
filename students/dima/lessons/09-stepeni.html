Для репетитора: план урока

Цель: Дима считает степени без ошибки «\(2^3 = 6\)», не путается со знаком минус и решает прототипы №8 по правилу «сначала сложи и вычти показатели, потом подставь».

  1. 5–10 мин — проверка ДЗ урока 8 (углы равнобедренного треугольника).
  2. 15 мин — шпаргалка: определение, таблица (пусть сам заполнит пропуски), знаки, три свойства.
  3. 25–30 мин — практика. На задаче 1 проговаривать вслух: «два в кубе — это два умножить на два умножить на два».
  4. 5 мин — итог: «умножаем степени — показатели складываем, делим — вычитаем».

Типичные ошибки: \(2^3 = 6\); \(-2^4 = 16\); \(2^3\cdot2^4 = 2^{12}\) (перемножает показатели); \(10^{-2} = -100\).

Шпаргалка

1. Что такое степень

\[ a^n = \underbrace{a\cdot a\cdot\ldots\cdot a}_{n\ \text{раз}} \] \(a\) — основание (что умножаем), \(n\) — показатель (сколько раз).
\(2^3 = 2\cdot2\cdot2 = 8\) · \(5^2 = 5\cdot5 = 25\) · \(10^4 = 10\,000\) (единица и 4 нуля)
Главная ошибка: \(2^3\) — это не \(2\cdot3 = 6\)! Это \(2\cdot2\cdot2 = 8\).

2. Таблица, которую нужно знать

\(n\)1112131415161718192025
\(n^2\)121144169196225256289324361400625
\(n\)12345678910
\(2^n\)2481632641282565121024
\(n^3\)1827641252163435127291000

3. Степень и знак минус

Минус в скобках:
• чётная степень (2, 4, 6…) → ответ с плюсом: \((-2)^2 = (-2)\cdot(-2) = 4\);
• нечётная степень (1, 3, 5…) → ответ с минусом: \((-2)^3 = (-2)\cdot(-2)\cdot(-2) = -8\).
Минус без скобок в степень не возводится: \(-2^4 = -(2\cdot2\cdot2\cdot2) = -16\), а \((-2)^4 = 16\).
\(a^1 = a\) · \(a^0 = 1\) (любое число, кроме нуля, в нулевой степени — единица).

4. Три правила для действий со степенями

Одинаковые основания умножаем → показатели складываем: \(a^m\cdot a^n = a^{m+n}\).
Одинаковые основания делим → показатели вычитаем: \(a^m : a^n = a^{m-n}\).
Степень в степени → показатели умножаем: \((a^m)^n = a^{m\cdot n}\).
\(3^5\cdot3^2 = 3^7\) · \(7^9 : 7^7 = 7^2 = 49\) · \((2^3)^2 = 2^6 = 64\)
Складывать степени по этим правилам нельзя: \(2^3 + 2^2 = 8 + 4 = 12\), а вовсе не \(2^5 = 32\).

5. Отрицательный показатель и степени десятки

\(a^{-n} = \frac{1}{a^n}\). Для десятки: \(10^{-1} = 0{,}1\) · \(10^{-2} = 0{,}01\) · \(10^{-3} = 0{,}001\).
Сколько в показателе, столько знаков после запятой, последняя цифра — единица.
\(6\cdot10^{-2} = 6\cdot0{,}01 = 0{,}06\) · \(3\cdot10^{-3} = 0{,}003\) · \(2^{-3} = \frac{1}{2^3} = \frac{1}{8} = 0{,}125\)

6. Как решать №8 со степенями и буквой

  1. Все основания одинаковые — работаем только с показателями.
  2. Умножение → складываем, деление (дробная черта) → вычитаем.
  3. Получили одну степень — только теперь подставляем число.
\(\frac{a^{9}\cdot a^{11}}{a^{17}}\) при \(a = 2\): показатель \(9 + 11 - 17 = 3\), значит, \(a^3 = 2^3 = 8\).

Практика на уроке

1. Вычислите: а) \(3^4\); б) \(2^5\); в) \((-2)^3\); г) \(-2^4\).
Решениеа) \(3\cdot3\cdot3\cdot3 = 9\cdot9 = 81\).
б) \(2\cdot2\cdot2\cdot2\cdot2 = 32\).
в) Минус в скобках, степень нечётная → ответ с минусом: \(-8\).
г) Минус без скобок: сначала \(2^4 = 16\), потом ставим минус: \(-16\).

Ответ: а) 81; б) 32; в) \(-8\); г) \(-16\)

2. Вычислите \(5^3 - 4^3\).
Решение\(5^3 = 125\), \(4^3 = 64\). \(125 - 64 = 61\).

Ответ: 61

3. Вычислите \(2^7\cdot2^3 : 2^8\).
РешениеОснования одинаковые. Показатель: \(7 + 3 - 8 = 2\). \(2^2 = 4\).

Ответ: 4

4. Вычислите \((3^2)^3 : 3^5\).
РешениеСтепень в степени — умножаем: \((3^2)^3 = 3^6\). Делим: \(3^{6-5} = 3^1 = 3\).

Ответ: 3

5. Запишите десятичной дробью число \(7\cdot10^{-2}\).
Решение\(10^{-2} = 0{,}01\) (два знака после запятой). \(7\cdot0{,}01 = 0{,}07\).

Ответ: 0,07

6. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{a^{12}\cdot a^{5}}{a^{15}}\) при \(a = 6\).
РешениеПоказатель: \(12 + 5 - 15 = 2\). Остаётся \(a^2 = 6^2 = 36\).

Ответ: 36

7. Прототип ОГЭ №6 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(4\cdot10^{-1} + 6\cdot10^{-3} + 8\cdot10^{-4}\).
Решение\(4\cdot10^{-1} = 0{,}4\); \(6\cdot10^{-3} = 0{,}006\); \(8\cdot10^{-4} = 0{,}0008\). Складываем столбиком, запятая под запятой: 0,4000 + 0,0060 + 0,0008 ------ 0,4068

Ответ: 0,4068

Домашнее задание

1. Вычислите: а) \(4^3\); б) \((-3)^2\); в) \(-3^2\); г) \(10^4\).
Решениеа) \(4\cdot4\cdot4 = 64\). б) Минус в скобках, степень чётная → плюс: \(9\). в) Минус без скобок: \(-9\). г) Единица и 4 нуля: \(10\,000\).

Ответ: а) 64; б) 9; в) \(-9\); г) 10000

2. Вычислите \(2^6 - 6^2\).
Решение\(2^6 = 64\), \(6^2 = 36\). \(64 - 36 = 28\).

Ответ: 28

3. Вычислите \(3^5\cdot3^4 : 3^7\).
РешениеПоказатель: \(5 + 4 - 7 = 2\). \(3^2 = 9\).

Ответ: 9

4. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{a^{21}\cdot a^{-8}}{a^{11}}\) при \(a = 5\).
РешениеПоказатель: \(21 + (-8) - 11 = 13 - 11 = 2\). \(a^2 = 5^2 = 25\).

Ответ: 25

5. Прототип ОГЭ №6 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(6\cdot10^{-1} + 2\cdot10^{-2} + 5\cdot10^{-3}\).
Решение\(0{,}6 + 0{,}02 + 0{,}005 = 0{,}625\).

Ответ: 0,625

6. Повторение (урок 7) Найдите 20% от числа 350.
Решение20% — это пятая часть: \(350 : 5 = 70\). Или \(350\cdot0{,}2 = 70\).

Ответ: 70

7. Повторение (урок 5) Два угла треугольника равны \(72^\circ\) и \(35^\circ\). Найдите третий угол.
Решение\(180 - 72 - 35 = 73^\circ\).

Ответ: 73

8. Повторение (урок 1) Вычислите \(\frac{2}{3} + \frac{1}{6}\).
РешениеОбщий знаменатель 6: \(\frac{4}{6} + \frac{1}{6} = \frac{5}{6}\).

Ответ: \(\frac{5}{6}\)
