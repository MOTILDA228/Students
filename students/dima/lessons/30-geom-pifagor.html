Для репетитора: план урока

Новая идея урока: \(c^2 = a^2 + b^2\): гипотенуза — против прямого угла. Ищем гипотенузу — складываем квадраты, катет — вычитаем. Таблица квадратов до 20 и тройки 3–4–5, 5–12–13, 8–15–17.

  1. 0–12 мин — разминка-повторение (8 задач на время; две — таблица/деление). Ошибки — сразу разобрать.
  2. 12–22 мин — новое: шпаргалка, проговорить алгоритм вслух, 2 примера у доски.
  3. 22–50 мин — «лесенка»: ступень 1 вместе (вы подсказываете), ступень 2 сам, ступень 3 сам на время. Кто быстро — дальше, не дожидаясь.
  4. 50–60 мин — мини-срез из 5 задач без подсказок. Результат: 5 → 10 баллов, 4 → 8, 3 → 6, 2 → 4 — в журнал.

Ошибки, которые ждём: складывает квадраты, когда ищет катет; забывает извлечь корень; не знает квадратов чисел.

Правило «проверь себя»: после каждого ответа — подставить обратно (умножением, сложением). Требовать это всегда, вслух.

Разминка-повторение (12 минут)

1. Повторение (урок 29) Вычислите \(-12\cdot7\).
РешениеЗнаки разные → результат «−»: \(-12\cdot7 = -84\).

Ответ: -84

2. Повторение (урок 29) Вычислите \(-32 : (-4)\).
РешениеЗнаки одинаковые → «+»: \(-32 : (-4) = 8\).

Ответ: 8

3. Повторение (урок 28) Вычислите \(-17 + 25\).
РешениеЗнаки разные: из большего модуля вычитаем меньший, знак — как у числа с большим модулем: \(-17 + 25 = 8\).

Ответ: 8

4. Повторение (урок 28) Вычислите \(30 - (-26)\).
РешениеВычитание — это прибавление противоположного: \(30 - (-26) = 30 + 26 = 56\).

Ответ: 56

5. Повторение (урок 26) Решите уравнение \(92 : x = 23\).
РешениеНеизвестный делитель = делимое : частное: \(x = 92 : 23 = 4\). Проверка: \(92 : 4 = 23\) ✓.

Ответ: 4

6. Повторение (урок 26) Решите уравнение \(2x - 5 = 17\).
РешениеШаг 1 — неизвестное уменьшаемое: \(2x = 17 + 5 = 22\). Шаг 2 — неизвестный множитель: \(x = 22 : 2 = 11\). Проверка: \(2\cdot11 - 5 = 17\) ✓.

Ответ: 11

7. Повторение (урок 8) Вычислите \(15 : 5\).
РешениеВспоминаем «семейство»: \(5\cdot3 = 15\), значит \(15 : 5 = 3\).

Ответ: 3

8. Повторение (урок 8) Какое число пропущено: \(9\cdot\square = 36\)?
РешениеПропущенный множитель: \(36 : 9 = 4\).

Ответ: 4

Шпаргалка

1. Названия

\(a\), \(b\) — катеты (стороны у прямого угла), \(c\) — гипотенуза. Теорема Пифагора: \(c^2 = a^2 + b^2\). Гипотенуза — самая длинная сторона, против прямого угла.
ИщемКакПример
гипотенузу\(c = \sqrt{a^2 + b^2}\)\(\sqrt{36 + 64} = 10\)
катет\(b = \sqrt{c^2 - a^2}\)\(\sqrt{169 - 25} = 12\)

2. Квадраты — выучить

\(11^2 = 121\), \(12^2 = 144\), \(13^2 = 169\), \(14^2 = 196\), \(15^2 = 225\), \(16^2 = 256\), \(17^2 = 289\), \(20^2 = 400\), \(24^2 = 576\), \(25^2 = 625\).
Тройки: 3–4–5, 6–8–10, 5–12–13, 8–15–17, 7–24–25. Узнал тройку — ответ сразу.
