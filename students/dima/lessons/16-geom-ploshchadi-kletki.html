Для репетитора: план урока

Новая идея урока: три приёма для №18: прямоугольник (\(a\cdot b\)), прямоугольный треугольник (половина прямоугольника), любой треугольник с основанием по линии сетки (\(\frac{a\cdot h}{2}\)). Фигуру «буквой Г» режем на прямоугольники.

  1. 0–12 мин — разминка-повторение (8 задач на время; две — таблица/деление). Ошибки — сразу разобрать.
  2. 12–22 мин — новое: шпаргалка, проговорить алгоритм вслух, 2 примера у доски.
  3. 22–50 мин — «лесенка»: ступень 1 вместе (вы подсказываете), ступень 2 сам, ступень 3 сам на время. Кто быстро — дальше, не дожидаясь.
  4. 50–60 мин — мини-срез из 5 задач без подсказок. Результат: 5 → 10 баллов, 4 → 8, 3 → 6, 2 → 4 — в журнал.

Ошибки, которые ждём: в треугольнике забывает делить на 2; высоту считает «по косой» стороне, а не по вертикали.

Правило «проверь себя»: после каждого ответа — подставить обратно (умножением, сложением). Требовать это всегда, вслух.

ДЗ короткое (15 мин) и только на то, что получалось на уроке. Не сделал ДЗ — первые 10 минут следующего урока решает его при вас.

3. Повторение (урок 14) Решите уравнение \(x : 7 = 26\).
РешениеНеизвестное делимое = частное · делитель: \(x = 26\cdot7 = 182\). Проверка: \(182 : 7 = 26\) ✓.

Ответ: 182

4. Повторение (урок 14) Решите уравнение \(64 + x = 203\).
РешениеНеизвестное слагаемое = сумма − известное слагаемое: \(x = 203 - 64 = 139\). Проверка: \(139 + 64 = 203\) ✓.

Ответ: 139

5. Повторение (урок 12) 7 одинаковых пачек тетрадей содержат 119 тетрадей. Сколько тетрадей в одной пачке? (Уравнение \(7\cdot x = 119\).)
РешениеНеизвестный множитель: \(x = 119 : 7 = 17\).

Ответ: 17

6. Повторение (урок 12) Решите уравнение \(9\cdot x = 144\).
РешениеНеизвестный множитель = произведение : известный множитель: \(x = 144 : 9 = 16\). Проверка: \(9\cdot16 = 144\) ✓.

Ответ: 16

7. Повторение (урок 8) Вычислите \(35 : 5\).
РешениеВспоминаем «семейство»: \(5\cdot7 = 35\), значит \(35 : 5 = 7\).

Ответ: 7

8. Повторение (урок 8) Какое число пропущено: \(5\cdot\square = 45\)?
РешениеПропущенный множитель: \(45 : 5 = 9\).

Ответ: 9

Шпаргалка

1. Прямоугольный треугольник — половина прямоугольника

\(S = \frac{a\cdot b}{2}\): здесь \(\frac{5\cdot3}{2} = 7{,}5\).

2. Любой треугольник с основанием по линии сетки

\(S = \frac{\text{основание}\cdot\text{высота}}{2}\). Высота — прямо вверх от основания до вершины: \(\frac{6\cdot3}{2} = 9\).

3. Сложная фигура — разрезать

Режем на прямоугольники \(5\times1\) и \(2\times2\): \(5 + 4 = 9\).
Дробный ответ записываем через запятую: \(7{,}5\).
