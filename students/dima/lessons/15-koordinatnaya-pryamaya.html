Для репетитора: план урока

Цель: Дима сравнивает числа (дроби, отрицательные, корни), находит место корня на прямой и решает три главных вида №7.

  1. 5–10 мин — проверка ДЗ урока 14.
  2. 15 мин — шпаргалка. Нарисовать прямую на доске, отметить −3, −1, 0, 2 — «кто больше?».
  3. 25–30 мин — практика. В задачах с буквами на прямой обязательно подставлять конкретное число (например, \(a = 3{,}4\)).
  4. 5 мин — итог: «правее — больше».

Типичные ошибки: думает, что \(-5 > -2\) («пять больше двух»); сравнивает 0,29 и 0,3 по количеству цифр; не проверяет все четыре варианта ответа.

Шпаргалка

1. Координатная прямая

Правее — больше, левее — меньше. Любое отрицательное число меньше нуля и меньше любого положительного.
\(-5 < -2\): минус пять левее, значит, меньше. У отрицательных чисел «больше цифра — меньше число» (долг 5 рублей хуже, чем долг 2 рубля).

2. Сравнение дробей

Переведи всё в десятичные дроби (урок 4) и уравняй количество знаков нулями: \(0{,}3 = 0{,}30\), значит, \(0{,}3 > 0{,}29\).
Сравним \(\frac{3}{8}\) и \(0{,}4\): \(\frac{3}{8} = 0{,}375\), а \(0{,}4 = 0{,}400\). \(0{,}375 < 0{,}400\), значит, \(\frac{3}{8} < 0{,}4\).

3. Где на прямой корень

  1. Найди ближайшие квадраты снизу и сверху: для \(\sqrt{67}\) это \(64 = 8^2\) и \(81 = 9^2\).
  2. Корень между 8 и 9.
  3. 67 гораздо ближе к 64, чем к 81, значит, \(\sqrt{67}\) ближе к 8 (примерно 8,2).

4. Задачи №7 «буква на прямой»

  1. Посмотри, между какими числами буква. Здесь \(a\) между 3 и 4.
  2. Придумай конкретное число: \(a = 3{,}4\).
  3. Подставь его в каждое утверждение и посчитай. Верное — одно.
«\(a - 4 < 0\)?» → \(3{,}4 - 4 = -0{,}6 < 0\) — верно. «\(a - 3 < 0\)?» → \(3{,}4 - 3 = 0{,}4\) — это больше нуля, неверно.

Практика на уроке

1. Какое из чисел \(0{,}29\); \(\frac{2}{7}\); \(0{,}3\); \(\frac{3}{11}\) наибольшее? В ответ запишите его в виде десятичной дроби.
РешениеПереводим: \(\frac{2}{7} = 0{,}285\ldots\), \(\frac{3}{11} = 0{,}272\ldots\). Сравниваем с тремя знаками: 0,290; 0,285; 0,300; 0,272. Наибольшее — 0,3.

Ответ: 0,3

2. Какое из чисел \(-1{,}5\); \(-0{,}8\); \(-2{,}1\); \(0{,}3\) наименьшее?
РешениеНаименьшее — самое левое на прямой. Среди отрицательных самое левое то, у которого дальше от нуля: \(-2{,}1\).

Ответ: \(-2{,}1\)

3. Между какими двумя соседними целыми числами находится \(\sqrt{47}\)? Запишите оба числа через точку с запятой.
Решение\(36 = 6^2 < 47 < 49 = 7^2\), значит, \(6 < \sqrt{47} < 7\).

Ответ: 6; 7

4. Прототип ОГЭ №7 (ФИПИ / Решу ОГЭ)
Одна из точек, отмеченных на координатной прямой, соответствует числу \(\sqrt{67}\). Какая это точка?
1) точка \(A\)2) точка \(B\)3) точка \(C\)4) точка \(D\)
Решение\(64 < 67 < 81\) → \(8 < \sqrt{67} < 9\), и число ближе к 8. Между 8 и 9, рядом с 8, стоит точка \(C\).

Ответ: 3

5. Прототип ОГЭ №7 (ФИПИ / Решу ОГЭ)
На координатной прямой отмечено число \(a\). Какое из утверждений верно?
1) \(a - 3 < 0\)2) \(a - 4 > 0\)3) \(3 - a > 0\)4) \(a - 4 < 0\)
РешениеБерём \(a = 3{,}4\).
1) \(3{,}4 - 3 = 0{,}4\) — не меньше нуля, неверно.
2) \(3{,}4 - 4 = -0{,}6\) — не больше нуля, неверно.
3) \(3 - 3{,}4 = -0{,}4\) — не больше нуля, неверно.
4) \(3{,}4 - 4 = -0{,}6 < 0\) — верно.

Ответ: 4

6. Прототип ОГЭ №7 (ФИПИ / Решу ОГЭ)
Какое из чисел отмечено на координатной прямой точкой \(A\)?
1) \(\sqrt{6}\)2) \(\sqrt{13}\)3) \(\sqrt{18}\)4) \(\sqrt{21}\)
РешениеТочка \(A\) между 3 и 4, значит, под корнем число между \(9\) и \(16\). Проверяем: 6 — меньше 9; 13 — подходит; 18 и 21 — больше 16.

Ответ: 2

7. Прототип ОГЭ №7 (ФИПИ / Решу ОГЭ)
На координатной прямой отмечены числа \(a\) и \(b\). Какое из утверждений верно?
1) \(a + b < 0\)2) \(ab > 0\)3) \(b - a > 0\)4) \(a > b\)
РешениеБерём \(a = -1{,}5\), \(b = 2{,}3\).
1) \(-1{,}5 + 2{,}3 = 0{,}8\) — не меньше нуля, неверно.
2) \(ab = -3{,}45\) — минус на плюс даёт минус, неверно.
3) \(2{,}3 - (-1{,}5) = 3{,}8 > 0\) — верно.
4) \(a\) левее \(b\), значит, \(a < b\) — неверно.

Ответ: 3
