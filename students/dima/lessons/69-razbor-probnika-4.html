Разминка-повторение (12 минут)

1. Повторение (урок 68) Вычислите \(3\cdot(-4) + (-20)\).
РешениеСначала умножение: \(3\cdot(-4) = -12\); потом \(-12 + (-20) = -32\).

Ответ: -32

2. Повторение (урок 68) Катеты прямоугольного треугольника равны 10 и 24. Найдите гипотенузу.
Решение\(c^2 = 10^2 + 24^2 = 100 + 576 = 676\), \(c = \sqrt{676} = 26\).

Ответ: 26

3. Повторение (урок 67) Решите уравнение \(9x + 7 = 5x + (-13)\).
РешениеИксы — влево, числа — вправо (при переносе знак меняется): \(9x - 5x = -13 - 7\); \(4x = -20\); \(x = -5\).

Ответ: -5

4. Повторение (урок 67) Найдите значение выражения \(\frac{27}{0{,}9}\).
РешениеПереносим запятую: \(270 : 9 = 30\).

Ответ: 30

5. Повторение (урок 65) Решите уравнение \(3x + 5x = -32\).
РешениеПриводим подобные: \(8x = -32\); \(x = -32 : 8 = -4\).

Ответ: -4

6. Повторение (урок 65) Найдите значение выражения \(\left(\frac{1}{2} + \frac{3}{5}\right)\cdot4\).
РешениеСкобка: \(1{,}1\); умножаем на 4: \(4{,}4\).

Ответ: 4,4

7. Повторение (урок 8) Вычислите \(24 : 8\).
РешениеВспоминаем «семейство»: \(8\cdot3 = 24\), значит \(24 : 8 = 3\).

Ответ: 3

8. Повторение (урок 14) Решите уравнение \(5x - 1 = 74\).
РешениеШаг 1 — неизвестное уменьшаемое: \(5x = 74 + 1 = 75\). Шаг 2 — неизвестный множитель: \(x = 75 : 5 = 15\). Проверка: \(5\cdot15 - 1 = 74\) ✓.

Ответ: 15

№9 — уравнения

1. Решите уравнение \(6x + 10 = 1x + 5\).
РешениеИксы — влево, числа — вправо (при переносе знак меняется): \(6x - 1x = 5 - 10\); \(5x = -5\); \(x = -1\).

Ответ: -1

2. Решите уравнение \(6x - 28 = 2\).
РешениеШаг 1 — неизвестное уменьшаемое: \(6x = 2 + 28 = 30\). Шаг 2 — неизвестный множитель: \(x = 30 : 6 = 5\). Проверка: \(6\cdot5 - 28 = 2\) ✓.

Ответ: 5

3. Решите уравнение \(5x + 2x = 70\).
РешениеПриводим подобные: \(7x = 70\); \(x = 70 : 7 = 10\).

Ответ: 10

№10 — вероятность

1. В лотерее 100 билетов, выигрышных 49. Найдите вероятность того, что билет выигрышный.
Решение\(P = \frac{49}{100} = 0{,}49\).

Ответ: 0,49

2. Бросают игральный кубик. Найдите вероятность того, что выпадет число больше 3.
РешениеПодходят: 4, 5, 6 — 3 из 6: \(0{,}5\).

Ответ: 0,5

3. Из 25 фонариков 5 неисправны. Найдите вероятность того, что случайно выбранный фонарик исправен.
РешениеИсправных 20: \(P = \frac{20}{25} = 0{,}8\).

Ответ: 0,8

№12 — формулы

Решение\(270 = 45\cdott\) — неизвестный множитель: \(t = 270 : 45 = 6\).

Ответ: 6

№14 — прогрессия

1. Арифметическая прогрессия: \(a_1 = 1\), \(d = -3\). Найдите \(a_{14}\).
Решение\(a_n = a_1 + (n - 1)d = 1 + 13\cdot(-3) = -38\).

Ответ: -38

2. В первом ряду кинотеатра 18 мест, а в каждом следующем на 2 больше. Сколько мест в 9-м ряду?
Решение\(a_{9} = 18 + 8\cdot2 = 34\).

Ответ: 34

3. Арифметическая прогрессия: \(a_1 = 11\), \(d = 2\). Найдите \(a_{8}\).
Решение\(a_n = a_1 + (n - 1)d = 11 + 7\cdot2 = 25\).

Ответ: 25

№15 — треугольники

1. Катеты прямоугольного треугольника равны 20 и 21. Найдите гипотенузу.
Решение\(c^2 = 20^2 + 21^2 = 400 + 441 = 841\), \(c = \sqrt{841} = 29\).

Ответ: 29

2. В равнобедренном треугольнике угол при вершине \(132^\circ\). Найдите угол при основании.
РешениеУглы при основании равны: \((180 - 132) : 2 = 24^\circ\).

Ответ: 24

3. В треугольнике два угла \(46^\circ\) и \(28^\circ\). Найдите третий.
Решение\(180 - 46 - 28 = 106^\circ\).

Ответ: 106

№16 — окружность

1. Вписанный угол равен \(33^\circ\). Найдите центральный угол, опирающийся на ту же дугу.
РешениеЦентральный — в 2 раза больше: \(66^\circ\).

Ответ: 66

2. \(AB\) — диаметр окружности, \(C\) — точка на ней, \(\angle CAB = 53^\circ\). Найдите \(\angle CBA\).
РешениеУгол на диаметр \(\angle ACB = 90^\circ\). \(\angle CBA = 90 - 53 = 37^\circ\).

Ответ: 37

3. Центральный угол равен \(186^\circ\). Найдите вписанный угол, опирающийся на ту же дугу.
РешениеВписанный — половина центрального: \(93^\circ\).

Ответ: 93

№17 — четырёхугольники

РешениеСторона \(24 : 4 = 6\), \(S = 6^2 = 36\).

Ответ: 36

2. Сумма двух углов параллелограмма \(124^\circ\). Найдите один из оставшихся углов.
РешениеРавные углы по 62°, оставшиеся по 118°.

Ответ: 118

3. Диагонали ромба 22 и 10. Найдите площадь.
Решение\(S = \frac{d_1d_2}{2} = \frac{22\cdot10}{2} = 110\).

Ответ: 110
