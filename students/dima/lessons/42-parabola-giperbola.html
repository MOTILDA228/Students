Для репетитора: план урока

Цель: Дима отличает на рисунке прямую, параболу и гиперболу, определяет знак \(a\) и \(c\) у параболы и знак \(k\) у гиперболы, решает №11.

  1. 5–10 мин — проверка ДЗ урока 41.
  2. 15 мин — шпаргалка: «галочка» и «шапочка», две ветви гиперболы в чётвертях.
  3. 25–30 мин — практика. В №11 сначала определить вид графика, потом знаки.
  4. 5 мин — итог: «\(x^2\) — парабола, \(x\) в знаменателе — гипербола, просто \(x\) — прямая».

Типичные ошибки: определяет знак \(c\) по вершине, а не по пересечению с осью \(y\); путает четверти у гиперболы.

Шпаргалка

1. Три вида графиков в №11

2. Парабола \(y = ax^2 + bx + c\)

\(a > 0\) — ветви вверх («улыбка»), \(a < 0\) — ветви вниз.
\(c\) — где парабола пересекает ось \(y\) (при \(x = 0\) \(y = c\)).
Вершина: \(x_0 = -\frac{b}{2a}\), \(y_0\) — подставить \(x_0\) в формулу.
Пересечение с осью \(x\) — корни уравнения \(ax^2 + bx + c = 0\).
\(y = x^2 - 4x + 3\): \(a = 1 > 0\) — ветви вверх; \(c = 3\); \(x_0 = \frac{4}{2} = 2\), \(y_0 = 4 - 8 + 3 = -1\). Вершина \((2; -1)\). С осью \(x\): корни 1 и 3.

3. Гипербола \(y = \frac{k}{x}\)

Две ветви, ось \(y\) не пересекает. \(k > 0\) — ветви справа вверху и слева внизу; \(k < 0\) — слева вверху и справа внизу. Точка \((1; k)\) всегда на графике.

Практика на уроке

1. Найдите ординату вершины параболы \(y = x^2 - 4x + 3\).
Решение\(x_0 = -\frac{-4}{2} = 2\). \(y_0 = 4 - 8 + 3 = -1\).

Ответ: \(-1\)

2. Найдите абсциссы точек пересечения параболы \(y = x^2 - 6x + 5\) с осью \(Ox\). Запишите их в порядке возрастания.
Решение\(x^2 - 6x + 5 = 0\): произведение 5, сумма 6 → 1 и 5.

Ответ: 1; 5

3. Найдите значение функции \(y = \frac{6}{x}\) при \(x = -3\).
Решение\(y = 6 : (-3) = -2\).

Ответ: \(-2\)

4. График функции \(y = \frac{k}{x}\) проходит через точку \((2; -4)\). Найдите \(k\).
Решение\(-4 = \frac{k}{2}\) → \(k = -8\).

Ответ: \(-8\)

6. Прототип ОГЭ №11 (ФИПИ / Решу ОГЭ)
На рисунках изображены графики функций вида \(y = ax^2 + c\). Установите соответствие между графиками и знаками коэффициентов \(a\) и \(c\).
1) \(a > 0,\ c > 0\)2) \(a < 0,\ c > 0\)3) \(a > 0,\ c < 0\)
РешениеА: ветви вверх, ось \(y\) пересекает ниже нуля → \(a > 0, c < 0\) (3).
Б: ветви вниз, выше нуля → (2). В: ветви вверх, выше нуля → (1).

Ответ: 321

7. Прототип ОГЭ №11 (ФИПИ / Решу ОГЭ)

РешениеА — парабола ветвями вниз → 3. Б — гипербола во II и IV четвертях → 1. В — прямая через начало координат, идёт вниз → 2.

Ответ: 312
