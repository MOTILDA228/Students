Для репетитора: план урока

Цель: Дима находит разность, любой член и сумму первых членов арифметической прогрессии по двум формулам.

  1. 5–10 мин — проверка ДЗ урока 35.
  2. 15 мин — шпаргалка. Лесенка: 3, 7, 11, 15… «сколько шагов от первого до десятого?» — девять, отсюда \((n - 1)\).
  3. 25–30 мин — практика. Перед формулой выписывать \(a_1\), \(d\), \(n\).
  4. 5 мин — итог. Формулы — на карточку «ОГЭ №14».

Типичные ошибки: пишет \(a_1 + nd\) вместо \(a_1 + (n - 1)d\); теряет минус у \(d\); в сумме забывает умножить на \(n\).

Шпаргалка

1. Что такое арифметическая прогрессия

Последовательность, в которой каждое следующее число получается из предыдущего прибавлением одного и того же числа \(d\) (разности).
3, 7, 11, 15, … — \(d = 4\) · 20, 17, 14, 11, … — \(d = -3\) · 5, 5, 5, … — \(d = 0\)
\(d = a_2 - a_1\) (второй минус первый).

2. Любой член: формула \(n\)-го члена

\[ a_n = a_1 + (n - 1)\cdot d \] От первого члена до \(n\)-го — \((n - 1)\) шагов по \(d\).
3, 7, 11, … Десятый член: \(a_{10} = 3 + 9\cdot4 = 39\).

3. Сумма первых \(n\) членов

\[ S_n = \frac{a_1 + a_n}{2}\cdot n \] «Первый плюс последний, пополам, умножить на количество».
Сумма первых 10 членов прогрессии 3, 7, 11, …: \(a_{10} = 39\), \(S_{10} = \frac{3 + 39}{2}\cdot10 = 21\cdot10 = 210\).

4. Алгоритм

  1. Выпиши \(a_1\) и \(d\) (если не даны — найди: \(d = a_2 - a_1\)).
  2. Выпиши \(n\) — номер нужного члена или сколько членов складываем.
  3. Подставь в формулу. Для суммы сначала найди \(a_n\).

Практика на уроке

1. Арифметическая прогрессия: \(a_1 = 3\), \(d = 4\). Найдите \(a_{10}\).
Решение\(a_{10} = 3 + 9\cdot4 = 39\).

Ответ: 39

2. Дана арифметическая прогрессия 20, 17, 14, … Найдите её восьмой член.
Решение\(d = 17 - 20 = -3\). \(a_8 = 20 + 7\cdot(-3) = 20 - 21 = -1\).

Ответ: \(-1\)

3. В арифметической прогрессии \(a_1 = 5\), \(a_2 = 9\). Найдите \(a_{15}\).
Решение\(d = 9 - 5 = 4\). \(a_{15} = 5 + 14\cdot4 = 61\).

Ответ: 61

4. Найдите сумму первых 10 членов арифметической прогрессии, если \(a_1 = 3\), \(d = 4\).
Решение\(a_{10} = 39\). \(S_{10} = \frac{3 + 39}{2}\cdot10 = 210\).

Ответ: 210

5. Последовательность задана формулой \(a_n = 5n - 2\). Найдите \(a_{12}\).
РешениеПодставляем \(n = 12\): \(5\cdot12 - 2 = 58\).

Ответ: 58

6. По мотивам ОГЭ №14 (ФИПИ / Решу ОГЭ)
Выписаны первые несколько членов арифметической прогрессии: \(-4;\ 2;\ 8;\ \ldots\) Найдите её одиннадцатый член.
Решение\(d = 2 - (-4) = 6\). \(a_{11} = -4 + 10\cdot6 = 56\).

Ответ: 56

7. Прототип ОГЭ №14 (ФИПИ / Решу ОГЭ)
В амфитеатре 12 рядов. В первом ряду 18 мест, а в каждом следующем на 2 места больше, чем в предыдущем. Сколько всего мест в амфитеатре?
Решение\(a_1 = 18\), \(d = 2\), \(n = 12\). Последний ряд: \(a_{12} = 18 + 11\cdot2 = 40\). Всего: \(S_{12} = \frac{18 + 40}{2}\cdot12 = 29\cdot12 = 348\).

Ответ: 348

Домашнее задание

1. Арифметическая прогрессия: \(a_1 = 7\), \(d = 3\). Найдите \(a_{20}\).
Решение\(7 + 19\cdot3 = 64\).

Ответ: 64

2. Дана арифметическая прогрессия 15, 11, 7, … Найдите её десятый член.
Решение\(d = -4\). \(a_{10} = 15 + 9\cdot(-4) = -21\).

Ответ: \(-21\)

3. Найдите сумму первых 8 членов арифметической прогрессии, если \(a_1 = 2\), \(d = 5\).
Решение\(a_8 = 2 + 35 = 37\). \(S_8 = \frac{2 + 37}{2}\cdot8 = 156\).

Ответ: 156

4. По мотивам ОГЭ №14 (ФИПИ / Решу ОГЭ)
Выписаны первые несколько членов арифметической прогрессии: \(1;\ 6;\ 11;\ \ldots\) Найдите сумму первых десяти её членов.
Решение\(d = 5\), \(a_{10} = 1 + 45 = 46\). \(S_{10} = \frac{1 + 46}{2}\cdot10 = 235\).

Ответ: 235

5. Прототип ОГЭ №14 (ФИПИ / Решу ОГЭ)
В амфитеатре 10 рядов. В первом ряду 20 мест, а в каждом следующем на 3 места больше, чем в предыдущем. Сколько мест в последнем ряду?
Решение\(a_{10} = 20 + 9\cdot3 = 47\).

Ответ: 47

6. Повторение (урок 35) В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(BC = 6\), \(\operatorname{tg} A = 0{,}75\). Найдите \(AC\).
Решение\(0{,}75 = \frac{6}{AC}\) → \(AC = 6 : 0{,}75 = 8\).

Ответ: 8

7. Повторение (урок 32) \(MN\) — средняя линия треугольника \(ABC\), параллельная стороне \(AC\), \(AC = 42\). Найдите \(MN\).
Решение\(42 : 2 = 21\).

Ответ: 21

8. Повторение (урок 28) Решите неравенство \(x^2 - 9 \le 0\). Сколько целых чисел являются его решениями?
Решение\([-3;\ 3]\): от \(-3\) до 3 — семь чисел.

Ответ: 7
