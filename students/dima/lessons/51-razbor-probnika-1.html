Цель: разобрать ошибки урока 50. Ниже — по 3 задачи-двойника на каждый номер ОГЭ 6–19. Решать только номера с ошибками; номера, решённые верно, — по одной задаче для темпа.

  1. 10 мин — разбор ошибок: «как думал?», найти шаг, где сломалось.
  2. 40 мин — двойники.
  3. 10 мин — по одной задаче из каждого ошибочного номера без подсказок.

Разминка-повторение (12 минут)

1. Повторение (урок 50) Найдите значение выражения \((2{,}5 - 0{,}3)\cdot3\).
РешениеСкобка \(2{,}2\); \(2{,}2\cdot3 = 6{,}6\).

Ответ: 6,6

2. Повторение (урок 50) Решите уравнение \(2(x - 9) + 7 = -7\).
РешениеРаскрываем скобки: \(2x - 18 + 7 = -7\); \(2x = -7 + 18 - 7 = 4\); \(x = 2\).

Ответ: 2

3. Повторение (урок 49) Центральный угол равен \(150^\circ\). Найдите вписанный угол, опирающийся на ту же дугу.
РешениеВписанный — половина центрального: \(75^\circ\).

Ответ: 75

4. Повторение (урок 49) Стороны прямоугольника 20 и 21. Найдите его диагональ.
РешениеДиагональ — гипотенуза: \(\sqrt{400 + 441} = 29\).

Ответ: 29

5. Повторение (урок 47) Решите уравнение \(\frac{x}{4} + \frac{x}{6} = 15\).
РешениеУмножаем всё на 12: \(3x + 2x = 180\); \(5x = 180\); \(x = 36\).

Ответ: 36

6. Повторение (урок 47) Решите уравнение \(\frac{x}{8} = \frac{3}{2}\).
РешениеКрест-накрест: \(2x = 8\cdot3\), \(x = 12\).

Ответ: 12

7. Повторение (урок 8) Вычислите \(14 : 2\).
РешениеВспоминаем «семейство»: \(2\cdot7 = 14\), значит \(14 : 2 = 7\).

Ответ: 7

8. Повторение (урок 14) Решите уравнение \(2x + 10 = 18\).
РешениеШаг 1 — «отцепляем» 10 (неизвестное слагаемое): \(2x = 18 - 10 = 8\). Шаг 2 — неизвестный множитель: \(x = 8 : 2 = 4\). Проверка: \(2\cdot4 + 10 = 18\) ✓.

Ответ: 4

РешениеСначала умножение: \(9\cdot(-2) = -18\); потом \(-18 + 18 = 0\).

№7 — числовая прямая, сравнение

1. Какое из чисел наибольшее: 1) \(0{,}4\); 2) \(0{,}6\); 3) \(0{,}65\); 4) \(0{,}8\)? В ответ запишите номер.
РешениеПереводим в десятичные: \(0{,}4\); \(0{,}6\); \(0{,}65\); \(0{,}8\). Ответ: 4.

Ответ: 4

2. Между какими соседними целыми числами находится \(\sqrt{95}\)? В ответ запишите меньшее.
Решение\(9^2 = 81 < 95 < 100 = 10^2\), значит \(9 < \sqrt{95} < 10\).

Ответ: 9

3. Какое из чисел наименьшее: 1) \(0{,}5\); 2) \(0{,}6\); 3) \(0{,}8\); 4) \(0{,}4\)? В ответ запишите номер.
РешениеПереводим в десятичные: \(0{,}5\); \(0{,}6\); \(0{,}8\); \(0{,}4\). Ответ: 4.

Ответ: 4

№8 — степени, подстановка

1. Вычислите \(4^3\).
Решение\(4^3 = 4\cdot4\cdot4 = 64\).

Ответ: 64

2. Найдите значение выражения \(3a^2 - b^3\) при \(a = 4\), \(b = 2\).
Решение\(3\cdot16 - 2^3 = 48 - 8 = 40\).

Ответ: 40

3. Вычислите \(2^4\).
Решение\(2^4 = 2\cdot2\cdot2\cdot2 = 16\).

Ответ: 16

№9 — уравнения

1. Решите уравнение \(2(x - 8) + 7 = 3\).
РешениеРаскрываем скобки: \(2x - 16 + 7 = 3\); \(2x = 3 + 16 - 7 = 12\); \(x = 6\).

Ответ: 6

2. Решите уравнение \(3(x + 8) = 84\).
РешениеШаг 1 — скобка — неизвестный множитель: \(x + 8 = 84 : 3 = 28\). Шаг 2 — неизвестное слагаемое: \(x = 28 - 8 = 20\).

Ответ: 20

3. Решите уравнение \(2x + 4x = 60\).
РешениеПриводим подобные: \(6x = 60\); \(x = 60 : 6 = 10\).

Ответ: 10

№10 — вероятность

1. Из 25 фонариков 5 неисправны. Найдите вероятность того, что случайно выбранный фонарик исправен.
РешениеИсправных 20: \(P = \frac{20}{25} = 0{,}8\).

Ответ: 0,8

2. Бросают игральный кубик. Найдите вероятность того, что выпадет число больше 3.
РешениеПодходят: 4, 5, 6 — 3 из 6: \(0{,}5\).

Ответ: 0,5

3. В лотерее 20 билетов, выигрышных 12. Найдите вероятность того, что билет выигрышный.
Решение\(P = \frac{12}{20} = 0{,}6\).

Ответ: 0,6

№11 — графики

1. Установите соответствие между графиками и формулами: 1) \(y = 2x + 1\); 2) \(y = \frac{2}{x}\); 3) \(y = -x^2\).
РешениеПарабола — есть \(x^2\), гипербола — \(x\) в знаменателе, прямая — \(kx + b\). А → 1, Б → 2, В → 3.

Ответ: 123

2. Установите соответствие между графиками и формулами: 1) \(y = x^2 - 2\); 2) \(y = -x + 2\); 3) \(y = -\frac{2}{x}\).
РешениеПарабола — есть \(x^2\), гипербола — \(x\) в знаменателе, прямая — \(kx + b\). А → 1, Б → 3, В → 2.

Ответ: 132

3. Установите соответствие между графиками и формулами: 1) \(y = -x^2\); 2) \(y = \frac{2}{x}\); 3) \(y = 2x + 1\).
РешениеПарабола — есть \(x^2\), гипербола — \(x\) в знаменателе, прямая — \(kx + b\). А → 1, Б → 2, В → 3.

№12 — формулы

1. Формула \(A = Pt\) — работа тока \(A\) (Дж), мощность \(P\) (Вт), время \(t\) (с). Найдите \(A\), если \(P = 13\), \(t = 10\).
РешениеПодставляем: \(P = 13\), \(t = 10\) → \(A = 130\).

Ответ: 130

2. По формуле \(S = vt\) найдите \(t\) (в часах), если \(S = 154\) км, \(v = 22\) км/ч.
Решение\(154 = 22\cdott\) — неизвестный множитель: \(t = 154 : 22 = 7\).

Ответ: 7

3. Формула \(P = 2(a + b)\) — периметр прямоугольника. Найдите \(P\), если \(a = 4\), \(b = 26\).
РешениеПодставляем: \(a = 4\), \(b = 26\) → \(P = 60\).

Ответ: 60

№13 — неравенства

1. Укажите решение неравенства \(3x + 5 \ge 5\).
1) \((-\infty;\ 0)\)2) \((0;\ +\infty)\)3) \((-\infty;\ 0]\)4) \([0;\ +\infty)\)
Решение\(3x \ge 0\), \(x \ge 0\) — точка закрашена, квадратная скобка: вариант 4.

Ответ: 4

2. Решите неравенство \(7x + (-8) > -1\). В ответ запишите наименьшее целое решение.
Решение\(7x > -1 - (-8) = 7\); \(x > 1\). Наименьшее целое: 2.

Ответ: 2

3. Укажите решение неравенства \(6x + 3 \ge 9\).
1) \((-\infty;\ 1)\)2) \((1;\ +\infty)\)3) \((-\infty;\ 1]\)4) \([1;\ +\infty)\)
Решение\(6x \ge 6\), \(x \ge 1\) — точка закрашена, квадратная скобка: вариант 4.

Ответ: 4

№14 — прогрессия

1. Арифметическая прогрессия: \(a_1 = -1\), \(d = -3\). Найдите \(a_{15}\).
Решение\(a_n = a_1 + (n - 1)d = -1 + 14\cdot(-3) = -43\).

Ответ: -43

2. В первом ряду кинотеатра 15 мест, а в каждом следующем на 2 больше. Сколько мест в 10-м ряду?
Решение\(a_{10} = 15 + 9\cdot2 = 33\).

Ответ: 33

3. Арифметическая прогрессия: \(a_1 = 6\), \(d = 2\). Найдите \(a_{11}\).
Решение\(a_n = a_1 + (n - 1)d = 6 + 10\cdot2 = 26\).

Ответ: 26

№15 — треугольники

1. Катеты прямоугольного треугольника равны 12 и 16. Найдите гипотенузу.
Решение\(c^2 = 12^2 + 16^2 = 144 + 256 = 400\), \(c = \sqrt{400} = 20\).

Ответ: 20

2. В равнобедренном треугольнике угол при вершине \(116^\circ\). Найдите угол при основании.
РешениеУглы при основании равны: \((180 - 116) : 2 = 32^\circ\).

Ответ: 32

3. В треугольнике два угла \(56^\circ\) и \(53^\circ\). Найдите третий.
Решение\(180 - 56 - 53 = 71^\circ\).

Ответ: 71

№16 — окружность

1. Центральный угол равен \(156^\circ\). Найдите вписанный угол, опирающийся на ту же дугу.
РешениеВписанный — половина центрального: \(78^\circ\).

Ответ: 78

2. \(AB\) — диаметр окружности, \(C\) — точка на ней, \(\angle CAB = 61^\circ\). Найдите \(\angle CBA\).
РешениеУгол на диаметр \(\angle ACB = 90^\circ\). \(\angle CBA = 90 - 61 = 29^\circ\).

Ответ: 29

3. Вписанный угол равен \(45^\circ\). Найдите центральный угол, опирающийся на ту же дугу.
РешениеЦентральный — в 2 раза больше: \(90^\circ\).

Ответ: 90

№17 — четырёхугольники

РешениеСторона \(28 : 4 = 7\), \(S = 7^2 = 49\).

2. Сумма двух углов параллелограмма \(118^\circ\). Найдите один из оставшихся углов.
РешениеРавные углы по 59°, оставшиеся по 121°.

Ответ: 121

3. Сторона параллелограмма 12, высота к ней 11. Найдите площадь.
Решение\(S = ah = 12\cdot11 = 132\).

Ответ: 132

№18 — клетчатая бумага

1. Найдите площадь треугольника на клетчатой бумаге (клетка \(1\times1\)).
РешениеОснование (по нижней линии) 4, высота 5: \(S = \frac{4\cdot5}{2} = 10\).

Ответ: 10

2. Найдите длину отрезка \(AB\) на клетчатой бумаге (клетка \(1\times1\)).
РешениеДостраиваем прямоугольный треугольник: катеты 4 и 3 клеток. \(AB = \sqrt{16 + 9} = 5\).

Ответ: 5

3. Найдите площадь трапеции на клетчатой бумаге (клетка \(1\times1\)).
РешениеОснования 8 и 2, высота 4: \(S = \frac{8+2}{2}\cdot4 = 20\).

Ответ: 20
