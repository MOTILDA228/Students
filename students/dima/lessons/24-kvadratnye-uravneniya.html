Для репетитора: план урока

Цель: Дима решает неполные квадратные уравнения и полные — через дискриминант, правильно выписывая \(a\), \(b\), \(c\) со знаками.

  1. 5–10 мин — проверка ДЗ урока 23.
  2. 15 мин — шпаргалка. Формулу дискриминанта и корней выписать на карточку «ОГЭ №9».
  3. 25–30 мин — практика. Каждое полное уравнение: строка «\(a = \ldots, b = \ldots, c = \ldots\)», строка \(D\), строка корней.
  4. 5 мин — итог: «\(D\) больше нуля — два корня, равен нулю — один, меньше нуля — нет корней».

Типичные ошибки: теряет минус у \(b\) или \(c\); считает \(-b\) как \(b\); \((-5)^2\) пишет как \(-25\); делит только корень из \(D\), а не всю сумму.

Шпаргалка

1. Что такое квадратное уравнение

\[ ax^2 + bx + c = 0,\quad a \ne 0 \] \(a\) — число перед \(x^2\), \(b\) — перед \(x\), \(c\) — число без \(x\). Знаки берём вместе с числами!
\(2x^2 - 3x - 5 = 0\): \(a = 2\), \(b = -3\), \(c = -5\).
\(x^2 + 4 = 0\): \(a = 1\), \(b = 0\), \(c = 4\). · \(x^2 - 7x = 0\): \(a = 1\), \(b = -7\), \(c = 0\).

2. Неполные уравнения (быстрый способ)

Нет \(c\): \(ax^2 + bx = 0\) → выносим \(x\): \(x(ax + b) = 0\) → \(x = 0\) или \(ax + b = 0\) (урок 22).
Нет \(b\): \(ax^2 + c = 0\) → \(x^2 = -\frac{c}{a}\) → если число положительное, два корня \(\pm\sqrt{\ldots}\); если отрицательное — корней нет.
\(3x^2 - 12x = 0\) → \(3x(x - 4) = 0\) → \(0\) и \(4\).
\(x^2 - 16 = 0\) → \(x^2 = 16\) → \(-4\) и \(4\). · \(x^2 + 9 = 0\) → \(x^2 = -9\) → корней нет.

3. Полное уравнение: дискриминант

\[ D = b^2 - 4ac \] \(D > 0\) — два корня: \(x = \frac{-b \pm \sqrt{D}}{2a}\).
\(D = 0\) — один корень: \(x = \frac{-b}{2a}\).
\(D < 0\) — корней нет.
Пример. \(x^2 + 2x - 15 = 0\)
\(a = 1,\ b = 2,\ c = -15\)
\(D = 2^2 - 4\cdot1\cdot(-15) = 4 + 60 = 64\), \(\sqrt{D} = 8\)
\(x_1 = \frac{-2 - 8}{2} = -5\), \(x_2 = \frac{-2 + 8}{2} = 3\)
Если \(b\) отрицательное, то \(-b\) — положительное: при \(b = -5\) пишем \(-b = 5\). И \(b^2\) всегда \(\ge 0\): \((-5)^2 = 25\).

4. Ответ в ОГЭ

Читай условие: «запишите корни через точку с запятой в порядке возрастания» или «в ответ запишите больший (меньший) корень».

Практика на уроке

1. Решите уравнение \(x^2 - 16 = 0\). Запишите корни в порядке возрастания.
Решение\(x^2 = 16\) → \(x = -4\) или \(x = 4\).

Ответ: \(-4\); 4

2. Решите уравнение \(3x^2 - 12x = 0\). Запишите корни в порядке возрастания.
Решение\(3x(x - 4) = 0\) → \(x = 0\) или \(x = 4\).

Ответ: 0; 4

3. Решите уравнение \(x^2 - 5x + 6 = 0\). Запишите корни в порядке возрастания.
Решение\(a = 1,\ b = -5,\ c = 6\). \(D = 25 - 24 = 1\), \(\sqrt{D} = 1\). \(x_1 = \frac{5 - 1}{2} = 2\), \(x_2 = \frac{5 + 1}{2} = 3\).

Ответ: 2; 3

4. Решите уравнение \(x^2 + 2x - 15 = 0\). Запишите корни в порядке возрастания.
Решение\(D = 4 + 60 = 64\). \(x = \frac{-2 \pm 8}{2}\): \(-5\) и \(3\).

Ответ: \(-5\); 3

5. Решите уравнение \(2x^2 - 3x - 2 = 0\). Запишите корни в порядке возрастания.
Решение\(a = 2,\ b = -3,\ c = -2\). \(D = 9 - 4\cdot2\cdot(-2) = 9 + 16 = 25\), \(\sqrt{D} = 5\). \(x_1 = \frac{3 - 5}{4} = -0{,}5\), \(x_2 = \frac{3 + 5}{4} = 2\).

Ответ: \(-0{,}5\); 2

6. Прототип ОГЭ №9 (ФИПИ / Решу ОГЭ)
Найдите корни уравнения \(x^2 + 3x - 18 = 0\). Если корней несколько, запишите их через точку с запятой в порядке возрастания.
Решение\(D = 9 + 72 = 81\), \(\sqrt{D} = 9\). \(x = \frac{-3 \pm 9}{2}\): \(-6\) и \(3\).

Ответ: \(-6\); 3

7. Прототип ОГЭ №9 (ФИПИ / Решу ОГЭ)
Решите уравнение \(x^2 - 6x + 9 = 0\).
Решение\(D = 36 - 36 = 0\) — один корень: \(x = \frac{6}{2} = 3\). (Это \((x - 3)^2 = 0\).)

Ответ: 3

Домашнее задание

1. Решите уравнение \(x^2 - 81 = 0\). Запишите корни в порядке возрастания.
Решение\(x^2 = 81\) → \(-9\) и \(9\).

Ответ: \(-9\); 9

2. Решите уравнение \(2x^2 + 10x = 0\). Запишите корни в порядке возрастания.
Решение\(2x(x + 5) = 0\) → \(x = 0\) или \(x = -5\).

Ответ: \(-5\); 0

3. Решите уравнение \(x^2 - 7x + 10 = 0\). Запишите корни в порядке возрастания.
Решение\(D = 49 - 40 = 9\). \(x = \frac{7 \pm 3}{2}\): 2 и 5.

Ответ: 2; 5

4. Решите уравнение \(x^2 + x - 12 = 0\). Запишите корни в порядке возрастания.
Решение\(D = 1 + 48 = 49\). \(x = \frac{-1 \pm 7}{2}\): \(-4\) и 3.

Ответ: \(-4\); 3

5. Прототип ОГЭ №9 (ФИПИ / Решу ОГЭ)

Решение\(D = 4 + 60 = 64\). \(x = \frac{2 \pm 8}{2}\): \(-3\) и 5.

Ответ: \(-3\); 5

7. Повторение (урок 20) Один из односторонних углов при параллельных прямых и секущей на \(30^\circ\) больше другого. Найдите больший угол.
Решение\(x + x + 30 = 180\) → \(x = 75\). Больший: \(105^\circ\).

Ответ: 105
