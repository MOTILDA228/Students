Для репетитора: план урока

Цель: Дима решает №12 обоих видов: «подставь и посчитай» и «найди букву внутри формулы» через уравнение.

  1. 5–10 мин — проверка ДЗ урока 12.
  2. 10–15 мин — шпаргалка: обратные действия, «треугольник» для формул вида \(a = b\cdot c\).
  3. 25–30 мин — практика. В каждой задаче сначала выписать: что дано (числа), что найти (букву).
  4. 5 мин — итог: «подставь всё, что знаешь, — получится уравнение с одной буквой».

Типичные ошибки: путает обратные действия (вместо деления вычитает); теряет запятую при делении на 1,8; забывает возвести в квадрат.

Шпаргалка

1. Два вида задачи №12

Вид 1. Неизвестная буква стоит слева одна: \(P = I^2R\), ищем \(P\). Подставляем и считаем (урок 12).
Вид 2. Неизвестная буква внутри формулы: \(P = I^2R\), ищем \(R\). Подставляем всё известное → получаем уравнение → решаем.

2. Обратные действия

С буквой сделалиприбавили 32отняли 5умножили на 6разделили на 4
Чтобы найти буквуотнимаем 32прибавляем 5делим на 6умножаем на 4
Пример. Температура по Фаренгейту: \(t_F = 1{,}8\,t_C + 32\). Найдите \(t_C\), если \(t_F = 50\).
\(50 = 1{,}8\,t_C + 32\) → отнимаем 32: \(18 = 1{,}8\,t_C\) → делим на 1,8: \(t_C = 18 : 1{,}8 = 10\).

3. Треугольник для формул «одно = другое × третье»

Если \(s = v\cdot t\), то \(v = \frac{s}{t}\) и \(t = \frac{s}{v}\).
Мысленно нарисуй треугольник: наверху \(s\), внизу \(v\) и \(t\). Закрой пальцем то, что ищешь, — останется ответ: верх делим на низ, низ умножаем друг на друга.

4. Алгоритм

  1. Выпиши, чему равна каждая буква. Найди, какой буквы не хватает.
  2. Подставь все числа в формулу. Посчитай всё, что считается (квадраты, произведения).
  3. Осталось уравнение вида «число = число · \(x\)» или «число = число · \(x\) + число». Реши обратными действиями.
  4. Проверка: подставь ответ в формулу — должно сойтись.

Практика на уроке

1. Путь вычисляется по формуле \(s = v\cdot t\). Найдите время \(t\), если \(s = 120\) км, \(v = 40\) км/ч.
Решение\(120 = 40\cdot t\) → \(t = 120 : 40 = 3\) ч.

Ответ: 3

2. Периметр прямоугольника \(P = 2(a + b)\). Найдите \(b\), если \(P = 26\), \(a = 5\).
Решение\(26 = 2(5 + b)\) → делим на 2: \(13 = 5 + b\) → отнимаем 5: \(b = 8\).

Ответ: 8

3. Формула перевода температуры: \(t_F = 1{,}8\,t_C + 32\). Найдите \(t_F\), если \(t_C = 25\).
РешениеВид 1 — просто подставляем: \(1{,}8\cdot25 + 32 = 45 + 32 = 77\).

Ответ: 77

4. По той же формуле \(t_F = 1{,}8\,t_C + 32\) найдите \(t_C\), если \(t_F = 68\).
Решение\(68 = 1{,}8\,t_C + 32\) → \(36 = 1{,}8\,t_C\) → \(t_C = 36 : 1{,}8 = 360 : 18 = 20\).

Ответ: 20

5. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Закон Джоуля–Ленца можно записать в виде \(Q = I^2Rt\), где \(Q\) — количество теплоты (в джоулях), \(I\) — сила тока (в амперах), \(R\) — сопротивление цепи (в омах), \(t\) — время (в секундах). Пользуясь этой формулой, найдите время \(t\) (в секундах), если \(Q = 1296\) Дж, \(I = 6\) А, \(R = 6\) Ом.
РешениеПодставляем: \(1296 = 6^2\cdot6\cdot t = 36\cdot6\cdot t = 216\,t\). Делим: \(t = 1296 : 216 = 6\) с. Проверка: \(36\cdot6\cdot6 = 1296\) ✓.

Ответ: 6

6. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Центростремительное ускорение при движении по окружности (в м/с²) вычисляется по формуле \(a = \omega^2R\), где \(\omega\) — угловая скорость (в с⁻¹), \(R\) — радиус окружности (в метрах). Пользуясь этой формулой, найдите радиус \(R\), если \(\omega = 4\) с⁻¹, \(a = 64\) м/с².
Решение\(64 = 4^2\cdot R = 16R\) → \(R = 64 : 16 = 4\) м.

Ответ: 4

7. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Площадь четырёхугольника можно вычислить по формуле \(S = \frac{d_1 d_2\sin\alpha}{2}\). Найдите длину диагонали \(d_2\), если \(d_1 = 16\), \(\sin\alpha = \frac{2}{5}\), \(S = 12{,}8\).
РешениеПодставляем: \(12{,}8 = \frac{16\cdot d_2\cdot\frac{2}{5}}{2}\). Считаем числа: \(16\cdot\frac{2}{5} = 6{,}4\), \(6{,}4 : 2 = 3{,}2\). Получили \(12{,}8 = 3{,}2\,d_2\). \(d_2 = 12{,}8 : 3{,}2 = 128 : 32 = 4\).

Ответ: 4

Домашнее задание

1. Путь вычисляется по формуле \(s = v\cdot t\). Найдите \(s\) (в км), если \(v = 60\) км/ч, \(t = 2{,}5\) ч.
Решение\(s = 60\cdot2{,}5 = 150\) км.

Ответ: 150

2. Периметр прямоугольника \(P = 2(a + b)\). Найдите \(a\), если \(P = 34\), \(b = 9\).
Решение\(34 = 2(a + 9)\) → \(17 = a + 9\) → \(a = 8\).

Ответ: 8

3. Формула \(t_F = 1{,}8\,t_C + 32\). Найдите \(t_F\), если \(t_C = -10\).
Решение\(1{,}8\cdot(-10) + 32 = -18 + 32 = 14\).

Ответ: 14

4. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Мощность постоянного тока (в ваттах) вычисляется по формуле \(P = I^2R\). Пользуясь этой формулой, найдите сопротивление \(R\) (в омах), если мощность составляет 147 Вт, а сила тока равна 3,5 А.
Решение\(I^2 = 3{,}5^2 = 12{,}25\). \(147 = 12{,}25\,R\) → \(R = 147 : 12{,}25 = 14700 : 1225 = 12\) Ом. Проверка: \(12{,}25\cdot12 = 147\) ✓.

Ответ: 12

5. По мотивам ОГЭ №12
Площадь трапеции вычисляется по формуле \(S = \frac{a + b}{2}\cdot h\). Найдите высоту \(h\), если \(a = 5\), \(b = 9\), \(S = 35\).
Решение\(\frac{5 + 9}{2} = 7\). \(35 = 7h\) → \(h = 5\).

Ответ: 5

6. Повторение (урок 11) Катеты прямоугольного треугольника равны 12 и 16. Найдите гипотенузу.
Решение\(\sqrt{144 + 256} = \sqrt{400} = 20\).

Ответ: 20

7. Повторение (урок 9) Вычислите \((-2)^4 - 2^3\).
Решение\((-2)^4 = 16\) (чётная степень — плюс), \(2^3 = 8\). \(16 - 8 = 8\).

Ответ: 8

8. Повторение (урок 5) В треугольнике \(ABC\) внешний угол при вершине \(C\) равен \(140^\circ\), угол \(A\) равен \(65^\circ\). Найдите угол \(B\).
РешениеВнешний угол равен сумме двух углов, не смежных с ним: \(\angle A + \angle B = 140^\circ\). \(\angle B = 140 - 65 = 75^\circ\).

Ответ: 75
