Для репетитора: план урока

Цель: неравенства и прогрессии — повторить все виды, включая «какое неравенство не имеет решений» и задачу, где номер члена находится из уравнения.

  1. 5–10 мин — проверка ДЗ урока 60.
  2. 10 мин — шпаргалки.
  3. 35 мин — практика: четыре №13, три №14.
  4. 5 мин — итог.

Типичные ошибки: «\(x^2 + 4 < 0\)» решает как обычное и получает ответ; в прогрессиях путает \(a_n\) и \(S_n\).

Шпаргалка

№13 — неравенства

• Линейное: как уравнение, но при делении на отрицательное знак переворачивается (урок 27).
• Квадратное: корни → парабола → «больше нуля — края, меньше — середина» (урок 28).
• Система: общая часть (урок 30).
• Особые случаи: \(x^2 + 4 > 0\) — верно при любом \(x\) (квадрат плюс положительное число всегда больше нуля); \(x^2 + 4 < 0\) — решений нет.

№14 — прогрессии

• Арифметическая: \(a_n = a_1 + (n - 1)d\), \(S_n = \frac{a_1 + a_n}{2}\cdot n\) (урок 36).
• Геометрическая: \(b_n = b_1q^{n-1}\) (урок 37).
• Текст: «на … больше» → арифметическая, «в … раз» → геометрическая (урок 39).
• Если неизвестен номер \(n\) — составь уравнение и реши его.
«В первый день 5 км, каждый следующий на 2 км больше. За сколько дней пройдено всего 45 км?»
\(S_n = \frac{5 + 5 + 2(n - 1)}{2}\cdot n = (n + 4)\cdot n = 45\) → \(n^2 + 4n - 45 = 0\) → \(n = 5\) (второй корень \(-9\) не подходит).

Практика на уроке

1. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Укажите решение неравенства \(2x + 5 \ge 9\).
1) \([2;\ +\infty)\)2) \((-\infty;\ 2]\)3) \((2;\ +\infty)\)4) \((-\infty;\ 7]\)
Решение\(2x \ge 4\) → \(x \ge 2\), точка закрашена: \([2;\ +\infty)\).

Ответ: 1

2. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Укажите решение неравенства \(x^2 - 4x \le 0\).
РешениеКорни 0 и 4, «\(\le\)» → середина: \([0;\ 4]\) — вариант 3.

Ответ: 3

3. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Решите систему \(\begin{cases} x - 1 > 0 \\ x - 5 < 0 \end{cases}\). Сколько целых чисел являются её решениями?
Решение\(1 < x < 5\): 2, 3, 4 — три числа.

Ответ: 3

4. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Какое из неравенств не имеет решений?
1) \(x^2 + 4 > 0\)2) \(x^2 + 4 < 0\)3) \(x^2 - 4 < 0\)4) \(x^2 - 4 > 0\)
Решение\(x^2 \ge 0\), значит, \(x^2 + 4 \ge 4\) — всегда положительно. Неравенство \(x^2 + 4 < 0\) не выполняется никогда — вариант 2.

Ответ: 2

5. Прототип ОГЭ №14 (ФИПИ / Решу ОГЭ)
Выписаны первые несколько членов арифметической прогрессии: \(7;\ 11;\ 15;\ \ldots\) Найдите её 31-й член.
Решение\(d = 4\). \(a_{31} = 7 + 30\cdot4 = 127\).

Ответ: 127

6. Прототип ОГЭ №14 (ФИПИ / Решу ОГЭ)
Геометрическая прогрессия: \(b_1 = 6\), \(q = 2\). Найдите \(b_6\).
Решение\(6\cdot2^5 = 192\).

Ответ: 192

7. Прототип ОГЭ №14 (ФИПИ / Решу ОГЭ)
Турист в первый день прошёл 5 км, а в каждый следующий день — на 2 км больше, чем в предыдущий. За сколько дней он прошёл всего 45 км?
РешениеСуммы по дням: 5, 12, 21, 32, 45 — на пятый день. (Или уравнение \(n(n + 4) = 45\), \(n = 5\).)

Ответ: 5

Домашнее задание

1. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Укажите решение неравенства \(3x - 2 < 7\).
1) \((3;\ +\infty)\)2) \((-\infty;\ 3]\)3) \((-\infty;\ 3)\)4) \((-\infty;\ 5)\)
Решение\(3x < 9\) → \(x < 3\), точка выколота — вариант 3.

Ответ: 3

2. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Укажите решение неравенства \(x^2 - 16 \ge 0\).
1) \([-4;\ 4]\)2) \([4;\ +\infty)\)3) \((-\infty;\ -4]\cup[4;\ +\infty)\)4) \((-\infty;\ 4]\)
РешениеКорни \(\pm4\), «\(\ge\)» → края — вариант 3.

Ответ: 3

3. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Решением какого из неравенств является любое число?
1) \(x^2 - 1 > 0\)2) \(x^2 + 1 > 0\)3) \(x^2 + 1 < 0\)4) \(x^2 - 1 < 0\)
Решение\(x^2 + 1 \ge 1 > 0\) при любом \(x\) — вариант 2.

Ответ: 2

4. Прототип ОГЭ №14 (ФИПИ / Решу ОГЭ)
В арифметической прогрессии \(a_1 = -3\), \(d = 5\). Найдите \(a_{20}\).
Решение\(-3 + 19\cdot5 = 92\).

Ответ: 92

5. Прототип ОГЭ №14 (ФИПИ / Решу ОГЭ)
Грибник в первый день нашёл 4 гриба, а в каждый следующий — на 3 больше, чем в предыдущий. Сколько грибов он нашёл за 6 дней?
Решение\(a_6 = 4 + 15 = 19\). \(S_6 = \frac{4 + 19}{2}\cdot6 = 69\).

Ответ: 69

6. Повторение (урок 59) Диагональ квадрата равна 10. Найдите площадь квадрата.
Решение\(\frac{100}{2} = 50\).

Ответ: 50

7. Повторение (урок 57) Найдите значение выражения \(\frac{(5\sqrt{2})^2}{25}\).
Решение\(\frac{25\cdot2}{25} = 2\).

Ответ: 2

8. Повторение (урок 53) Сторона равностороннего треугольника равна \(12\sqrt{3}\). Найдите его высоту.
Решение\(\frac{12\sqrt{3}\cdot\sqrt{3}}{2} = \frac{36}{2} = 18\).

Ответ: 18
