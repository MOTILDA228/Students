Для репетитора: план урока

Цель: Дима находит знаменатель, любой член и сумму нескольких членов геометрической прогрессии; не путает её с арифметической.

  1. 5–10 мин — проверка ДЗ урока 36.
  2. 15 мин — шпаргалка. Сравнить две строки: 2, 6, 10, 14 (прибавляем) и 2, 6, 18, 54 (умножаем).
  3. 25–30 мин — практика. Если членов немного (до 6–7), их проще выписать подряд, чем считать по формуле.
  4. 5 мин — итог: «арифметическая — плюс \(d\), геометрическая — умножить на \(q\)».

Типичные ошибки: считает \(q\) вычитанием; возводит в степень \(n\), а не \(n - 1\); теряет знак при отрицательном \(q\).

Шпаргалка

1. Что такое геометрическая прогрессия

Каждое следующее число получается из предыдущего умножением на одно и то же число \(q\) (знаменатель).
2, 6, 18, 54, … — \(q = 3\) · 64, 32, 16, 8, … — \(q = \frac{1}{2}\) · 3, −6, 12, −24, … — \(q = -2\) (знаки чередуются)
\(q = \frac{b_2}{b_1}\) (второй делить на первый).

2. Формула \(n\)-го члена

\[ b_n = b_1\cdot q^{\,n-1} \] От первого до \(n\)-го — \((n - 1)\) умножений на \(q\).
2, 6, 18, … Пятый член: \(b_5 = 2\cdot3^4 = 2\cdot81 = 162\).

3. Сумма нескольких членов

Если членов немного — выпиши их все и сложи. 1, 2, 4, 8, 16: сумма \(31\).
Формула (для больших \(n\)): \(S_n = \frac{b_1(q^n - 1)}{q - 1}\).

4. Как отличить прогрессии

арифметическаягеометрическая
шаг\(+d\)\(\times q\)
как найти шаг\(d = a_2 - a_1\)\(q = b_2 : b_1\)
\(n\)-й член\(a_1 + (n - 1)d\)\(b_1\cdot q^{n-1}\)
в тексте«на 3 больше»«в 3 раза больше», «удваивается»

Практика на уроке

1. Геометрическая прогрессия: \(b_1 = 2\), \(q = 3\). Найдите \(b_5\).
Решение\(b_5 = 2\cdot3^4 = 2\cdot81 = 162\).

Ответ: 162

2. Дана геометрическая прогрессия 64, 32, 16, … Найдите её седьмой член.
Решение\(q = \frac{32}{64} = \frac{1}{2}\). Выписываем: 64, 32, 16, 8, 4, 2, 1. Седьмой — 1.

Ответ: 1

3. Дана геометрическая прогрессия 3, −6, 12, … Найдите её шестой член.
Решение\(q = \frac{-6}{3} = -2\). \(b_6 = 3\cdot(-2)^5 = 3\cdot(-32) = -96\).

Ответ: \(-96\)

4. Найдите сумму первых пяти членов геометрической прогрессии 1, 2, 4, …
РешениеВыписываем: 1, 2, 4, 8, 16. Сумма: 31.

Ответ: 31

5. В геометрической прогрессии \(b_1 = 5\), \(b_2 = 15\). Найдите \(b_4\).
Решение\(q = 3\). \(b_4 = 5\cdot3^3 = 135\).

Ответ: 135

6. По мотивам ОГЭ №14 (ФИПИ / Решу ОГЭ)
Выписаны первые несколько членов геометрической прогрессии: \(750;\ 150;\ 30;\ \ldots\) Найдите её четвёртый член.
Решение\(q = \frac{150}{750} = \frac{1}{5}\). \(b_4 = 30\cdot\frac{1}{5} = 6\).

Ответ: 6

7. По мотивам ОГЭ №14
В начале опыта в пробирке была одна бактерия. Каждую минуту каждая бактерия делится на две. Сколько бактерий будет в пробирке через 6 минут?
РешениеКаждую минуту количество удваивается: 1 → 2 → 4 → 8 → 16 → 32 → 64. Через 6 минут: \(2^6 = 64\).

Ответ: 64

Домашнее задание

1. Геометрическая прогрессия: \(b_1 = 3\), \(q = 2\). Найдите \(b_6\).
Решение\(3\cdot2^5 = 96\).

Ответ: 96

2. Дана геометрическая прогрессия 1000, 100, 10, … Найдите её шестой член.
Решение\(q = 0{,}1\). 1000, 100, 10, 1, 0,1, 0,01. Шестой — 0,01.

Ответ: 0,01

3. Дана геометрическая прогрессия 2, −4, 8, … Найдите её седьмой член.
Решение\(q = -2\). \(b_7 = 2\cdot(-2)^6 = 2\cdot64 = 128\).

Ответ: 128

4. Найдите сумму первых четырёх членов геометрической прогрессии 5, 10, 20, …
Решение5, 10, 20, 40. Сумма: 75.

Ответ: 75

5. По мотивам ОГЭ №14 (ФИПИ / Решу ОГЭ)
Выписаны первые несколько членов геометрической прогрессии: \(-256;\ 128;\ -64;\ \ldots\) Найдите сумму первых семи её членов.
Решение\(q = -\frac{1}{2}\). Члены: \(-256,\ 128,\ -64,\ 32,\ -16,\ 8,\ -4\). Складываем по порядку: \(-256 + 128 = -128\); \(-128 - 64 = -192\); \(+32 = -160\); \(-16 = -176\); \(+8 = -168\); \(-4 = -172\).

Ответ: \(-172\)

6. Повторение (урок 35) В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AB = 25\), \(\sin A = 0{,}28\). Найдите \(BC\).
Решение\(BC = 0{,}28\cdot25 = 7\).

Ответ: 7

7. Повторение (урок 33) Вероятность того, что новая батарейка бракованная, равна 0,02. Найдите вероятность того, что батарейка исправна.
Решение\(1 - 0{,}02 = 0{,}98\).

Ответ: 0,98

8. Повторение (урок 29) Стороны параллелограмма равны 12 и 7, а угол между ними \(30^\circ\). Найдите площадь параллелограмма.
РешениеВысота к стороне 12: \(7 : 2 = 3{,}5\). \(S = 12\cdot3{,}5 = 42\).

Ответ: 42
