Для репетитора: план урока

Цель: Дима решает линейные уравнения по алгоритму из 4 шагов, в том числе со скобками и дробями, и делает проверку.

  1. 5–10 мин — проверка ДЗ урока 15.
  2. 15 мин — шпаргалка. Образ «весы»: что делаем с одной чашей, то и с другой.
  3. 25–30 мин — практика. Каждое решение записывать «лесенкой», по одному действию в строке.
  4. 5 мин — итог: «иксы — влево, числа — вправо, при переносе знак меняется».

Типичные ошибки: переносит слагаемое без смены знака; делит на коэффициент с неправильным знаком (\(-2x = 8 \Rightarrow x = 4\)); при раскрытии \(-2(x+3)\) пишет \(-2x + 6\).

Шпаргалка

1. Что значит «решить уравнение»

Найти число \(x\), при котором левая часть равна правой. Уравнение — как весы в равновесии: если с обеими чашами сделать одно и то же, равновесие сохранится.

2. Правило переноса

Любое слагаемое можно перенести через знак «=» в другую часть, поменяв его знак на противоположный.
\(x + 7 = 12\) → \(x = 12 - 7\) · \(3x = 2x + 5\) → \(3x - 2x = 5\)

3. Алгоритм

  1. Раскрой скобки (урок 12).
  2. Иксы — влево, числа — вправо (при переносе меняй знак).
  3. Приведи подобные: слева \(ax\), справа число.
  4. Раздели обе части на число перед \(x\).
  5. Проверка: подставь ответ в исходное уравнение.
Пример. \(4(x - 2) = 2x + 6\)
1) \(4x - 8 = 2x + 6\)
2) \(4x - 2x = 6 + 8\)
3) \(2x = 14\)
4) \(x = 7\)
Проверка: \(4\cdot(7 - 2) = 20\) и \(2\cdot7 + 6 = 20\) ✓
Деление с минусом: \(-2x = 8\) → \(x = 8 : (-2) = -4\). Знак числа перед \(x\) тоже участвует в делении!

4. Уравнение с дробями

Умножь обе части на общий знаменатель — дроби исчезнут. Дальше как обычно.
\(\frac{x}{3} + \frac{x}{4} = 7\). Общий знаменатель 12: \(12\cdot\frac{x}{3} + 12\cdot\frac{x}{4} = 12\cdot7\) → \(4x + 3x = 84\) → \(7x = 84\) → \(x = 12\).

5. Ответ в ОГЭ

Корень записываем числом: целым или десятичной дробью. Если получилось \(x = \frac{97}{10}\), пишем \(9{,}7\).

Практика на уроке

1. Решите уравнение \(3x + 7 = 22\).
Решение\(3x = 22 - 7\) → \(3x = 15\) → \(x = 5\). Проверка: \(3\cdot5 + 7 = 22\) ✓.

Ответ: 5

2. Решите уравнение \(5x - 3 = 2x + 9\).
РешениеИксы влево, числа вправо: \(5x - 2x = 9 + 3\) → \(3x = 12\) → \(x = 4\).

Ответ: 4

3. Решите уравнение \(7 - 2(x + 3) = 9\).
РешениеРаскрываем: \(7 - 2x - 6 = 9\) → \(1 - 2x = 9\) → \(-2x = 9 - 1 = 8\) → \(x = 8 : (-2) = -4\). Проверка: \(7 - 2\cdot(-4 + 3) = 7 - 2\cdot(-1) = 7 + 2 = 9\) ✓.

Ответ: \(-4\)

4. Решите уравнение \(3(2x - 5) = 4x + 1\).
Решение\(6x - 15 = 4x + 1\) → \(6x - 4x = 1 + 15\) → \(2x = 16\) → \(x = 8\).

Ответ: 8

5. Решите уравнение \(\frac{x}{2} + \frac{x}{5} = 14\).
РешениеОбщий знаменатель 10: \(5x + 2x = 140\) → \(7x = 140\) → \(x = 20\).

Ответ: 20

6. Прототип ОГЭ №9 (ФИПИ / Решу ОГЭ)
Найдите корень уравнения \(10(x - 9) = 7\).
Решение\(10x - 90 = 7\) → \(10x = 97\) → \(x = 9{,}7\).

Ответ: 9,7

7. Прототип ОГЭ №9 (ФИПИ / Решу ОГЭ)
Найдите корень уравнения \(6x - 5(2x + 8) = 14 + 2x\).
РешениеРаскрываем: \(6x - 10x - 40 = 14 + 2x\) → \(-4x - 40 = 14 + 2x\). Иксы влево, числа вправо: \(-4x - 2x = 14 + 40\) → \(-6x = 54\) → \(x = -9\). Проверка: \(6\cdot(-9) - 5\cdot(-18 + 8) = -54 + 50 = -4\) и \(14 + 2\cdot(-9) = -4\) ✓.

Ответ: \(-9\)

Домашнее задание

1. Решите уравнение \(4x - 9 = 15\).
Решение\(4x = 24\) → \(x = 6\).

Ответ: 6

2. Решите уравнение \(8x + 5 = 3x - 20\).
Решение\(8x - 3x = -20 - 5\) → \(5x = -25\) → \(x = -5\).

Ответ: \(-5\)

3. Решите уравнение \(\frac{x}{3} + \frac{x}{6} = 5\).
РешениеОбщий знаменатель 6: \(2x + x = 30\) → \(3x = 30\) → \(x = 10\).

Ответ: 10

4. Прототип ОГЭ №9 (ФИПИ / Решу ОГЭ)
Найдите корень уравнения \(7(x + 1) = 3x - 5\).
Решение\(7x + 7 = 3x - 5\) → \(7x - 3x = -5 - 7\) → \(4x = -12\) → \(x = -3\).

Ответ: \(-3\)

5. Прототип ОГЭ №9 (ФИПИ / Решу ОГЭ)
Найдите корень уравнения \(5(x - 2) = 3\).
Решение\(5x - 10 = 3\) → \(5x = 13\) → \(x = 13 : 5 = 2{,}6\).

Ответ: 2,6

6. Повторение (урок 14) На клетчатой бумаге с размером клетки \(1\times1\) изображён прямоугольный треугольник. Найдите его площадь.
РешениеКатеты 7 и 4. \(S = \frac{7\cdot4}{2} = 14\).

Ответ: 14

7. Повторение (урок 12) Найдите значение выражения \(x^2 - 4x\) при \(x = -2\).
Решение\((-2)^2 - 4\cdot(-2) = 4 + 8 = 12\).

Ответ: 12

8. Повторение (урок 8) В равнобедренном треугольнике угол при основании равен \(72^\circ\). Найдите угол при вершине.
Решение\(180 - 2\cdot72 = 180 - 144 = 36^\circ\).

Ответ: 36
