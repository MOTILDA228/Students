Для репетитора: план урока

Цель: собрать в одну систему всё про треугольники (уроки 5, 8, 11, 32, 35) и решать смешанные прототипы №15 без подсказки, какую тему применять.

  1. 5–10 мин — проверка ДЗ урока 52.
  2. 15 мин — «карта» №15: по ключевым словам условия выбрать инструмент.
  3. 25–30 мин — практика: все задачи из разных тем вперемешку.
  4. 5 мин — итог. Следующий урок — пробный ОГЭ.

Типичные ошибки: не видит внешний угол в задачах с биссектрисой; путает высоту равностороннего треугольника со стороной; при средней линии делит площадь на 2 вместо 4.

2. Два новых факта

Высота равностороннего треугольника со стороной \(a\): \(h = \frac{a\sqrt{3}}{2}\). Сторона \(16\sqrt{3}\) → \(h = \frac{16\sqrt{3}\cdot\sqrt{3}}{2} = \frac{16\cdot3}{2} = 24\).
Средняя линия отрезает треугольник, подобный исходному с \(k = \frac{1}{2}\), значит, его площадь в \(k^2 = \frac{1}{4}\) раза меньше: площадь 24 → маленький треугольник 6.

3. Биссектриса + внешний угол

\(\angle ALC\) — внешний угол треугольника \(ABL\), он равен сумме \(\angle ABL + \angle BAL\). Значит, \(\angle BAL = 112 - 106 = 6^\circ\), весь \(\angle A = 12^\circ\), \(\angle C = 180 - 106 - 12 = 62^\circ\). (Рисунок схематичный.)

Практика на уроке

1. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AC = 20\), \(\operatorname{tg} A = 0{,}5\). Найдите \(BC\).
Решение\(\operatorname{tg} A = \frac{BC}{AC}\) → \(BC = 0{,}5\cdot20 = 10\).

Ответ: 10

2. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) известно, что \(AB = BC\), внешний угол при вершине \(C\) равен \(128^\circ\). Найдите угол \(B\).
Решение\(\angle C = 180 - 128 = 52^\circ\). \(AB = BC\) → вершина \(B\), \(\angle A = \angle C = 52^\circ\). \(\angle B = 180 - 104 = 76^\circ\).

Ответ: 76

3. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) проведена биссектриса \(AL\), угол \(ALC\) равен \(112^\circ\), угол \(ABC\) равен \(106^\circ\). Найдите угол \(ACB\).
РешениеВнешний угол \(ALC\) треугольника \(ABL\): \(\angle BAL = 112 - 106 = 6^\circ\). \(\angle BAC = 12^\circ\). \(\angle ACB = 180 - 106 - 12 = 62^\circ\).

Ответ: 62

4. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
Два катета прямоугольного треугольника равны 4 и 10. Найдите площадь этого треугольника.
Решение\(S = \frac{4\cdot10}{2} = 20\).

Ответ: 20

5. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AB = 25\), \(BC = 7\). Найдите \(\cos B\).
РешениеДля угла \(B\) прилежащий катет — \(BC\): \(\cos B = \frac{7}{25} = 0{,}28\).

Ответ: 0,28

6. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
Сторона равностороннего треугольника равна \(16\sqrt{3}\). Найдите высоту этого треугольника.
Решение\(h = \frac{a\sqrt{3}}{2} = \frac{16\sqrt{3}\cdot\sqrt{3}}{2} = \frac{48}{2} = 24\).

Ответ: 24

7. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
Площадь треугольника \(ABC\) равна 24, \(DE\) — средняя линия, параллельная стороне \(AB\). Найдите площадь треугольника \(CDE\).
РешениеТреугольник \(CDE\) подобен \(CAB\) с \(k = \frac{1}{2}\). Площадь меньше в \(k^2 = 4\) раза: \(24 : 4 = 6\).

Ответ: 6

Домашнее задание

1. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(BC = 12\), \(\operatorname{tg} A = 0{,}4\). Найдите \(AC\).
Решение\(0{,}4 = \frac{12}{AC}\) → \(AC = 12 : 0{,}4 = 30\).

Ответ: 30

2. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) известно, что \(AB = BC\), внешний угол при вершине \(C\) равен \(136^\circ\). Найдите угол \(B\).
Решение\(\angle C = 44^\circ\), \(\angle A = 44^\circ\), \(\angle B = 180 - 88 = 92^\circ\).

Ответ: 92

3. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) проведена биссектриса \(AL\), угол \(ALC\) равен \(115^\circ\), угол \(ABC\) равен \(107^\circ\). Найдите угол \(ACB\).
Решение\(\angle BAL = 115 - 107 = 8^\circ\), \(\angle A = 16^\circ\), \(\angle C = 180 - 107 - 16 = 57^\circ\).

Ответ: 57

4. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
Сторона равностороннего треугольника равна \(10\sqrt{3}\). Найдите высоту этого треугольника.
Решение\(h = \frac{10\sqrt{3}\cdot\sqrt{3}}{2} = \frac{30}{2} = 15\).

Ответ: 15

5. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
Площадь треугольника \(ABC\) равна 36, \(DE\) — средняя линия, параллельная стороне \(AB\). Найдите площадь треугольника \(CDE\).
Решение\(36 : 4 = 9\).

Ответ: 9

6. Повторение (урок 51) Для дорожки нужно 23 плитки, в упаковке 6 штук. Сколько упаковок нужно купить?
Решение\(23 : 6 = 3{,}8\ldots\) → 4 упаковки.

Ответ: 4

7. Повторение (урок 49) Кожух печи имеет ширину 48 см и высоту боковых стенок 18 см, сверху — арка по дуге окружности с центром в середине нижней стороны кожуха. Найдите радиус арки (в см).
РешениеКатеты: половина ширины 24 и 18. \(R = \sqrt{576 + 324} = \sqrt{900} = 30\) см.

Ответ: 30

8. Повторение (урок 45) Решите систему \(\begin{cases} 2x + y = 7 \\ x - y = 2 \end{cases}\). В ответ запишите \(y\).
РешениеСкладываем: \(3x = 9\) → \(x = 3\), \(y = 7 - 6 = 1\).

Ответ: 1
