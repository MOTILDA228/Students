Для репетитора: план урока

Цель: Дима выносит общий множитель, раскладывает по формулам разности квадратов и решает уравнения вида «произведение равно нулю».

  1. 5–10 мин — проверка ДЗ урока 21 (формулы).
  2. 15 мин — шпаргалка. Разложение — это «формулы наоборот». Правило нуля — главное в уроке.
  3. 25–30 мин — практика. Задачи 1–2 — устный счёт, 3–4 и 7 — уравнения, 5–6 — дроби.
  4. 5 мин — итог: «произведение равно нулю, когда хотя бы один множитель равен нулю».

Типичные ошибки: в уравнении \(x^2 - 5x = 0\) делит на \(x\) и теряет корень 0; у \(x^2 - 49 = 0\) пишет только \(x = 7\).

Шпаргалка

1. Что значит «разложить на множители»

Записать выражение как произведение: \(6x + 9 = 3(2x + 3)\). Проверка — раскрыть скобки обратно.

2. Вынесение общего множителя

  1. Найди число, на которое делятся все коэффициенты.
  2. Найди букву, которая есть в каждом слагаемом (в наименьшей степени).
  3. Вынеси их за скобки, в скобках — то, что осталось от каждого слагаемого.
\(12x + 18 = 6(2x + 3)\) · \(x^2 - 5x = x(x - 5)\) · \(4a^2 + 8a = 4a(a + 2)\)
Удобный счёт: \(47\cdot13 + 47\cdot87 = 47\cdot(13 + 87) = 47\cdot100 = 4700\).

3. По формулам (урок 21, справа налево)

\(a^2 - b^2 = (a - b)(a + b)\) · \(a^2 + 2ab + b^2 = (a + b)^2\) · \(a^2 - 2ab + b^2 = (a - b)^2\)
\(x^2 - 16 = (x - 4)(x + 4)\) · \(x^2 + 6x + 9 = (x + 3)^2\)

4. Правило нуля

Произведение равно нулю, когда хотя бы один множитель равен нулю.
\(x(x - 5) = 0\) → \(x = 0\) или \(x - 5 = 0\), то есть \(x = 5\). Два корня: 0 и 5.
Делить уравнение на \(x\) нельзя — потеряешь корень \(x = 0\)! Выноси \(x\) за скобки.
\(x^2 = 49\) → \(x = 7\) или \(x = -7\): у квадрата два корня, с плюсом и с минусом.

5. Сокращение дробей

Разложи числитель и знаменатель на множители и сократи одинаковые скобки. \(\frac{x^2 - 9}{x + 3} = \frac{(x - 3)(x + 3)}{x + 3} = x - 3\).

Практика на уроке

1. Вычислите удобным способом: \(47\cdot13 + 47\cdot87\).
РешениеВыносим 47: \(47\cdot(13 + 87) = 47\cdot100 = 4700\).

Ответ: 4700

2. Вычислите удобным способом: \(8{,}6\cdot3{,}2 - 8{,}6\cdot1{,}2\).
Решение\(8{,}6\cdot(3{,}2 - 1{,}2) = 8{,}6\cdot2 = 17{,}2\).

Ответ: 17,2

3. Решите уравнение \(x^2 - 5x = 0\). В ответ запишите корни через точку с запятой в порядке возрастания.
Решение\(x(x - 5) = 0\) → \(x = 0\) или \(x = 5\).

Ответ: 0; 5

4. Решите уравнение \(x^2 - 49 = 0\). Запишите корни в порядке возрастания.
Решение\((x - 7)(x + 7) = 0\) → \(x = 7\) или \(x = -7\). По возрастанию: \(-7\); 7.

Ответ: \(-7\); 7

5. Сократите дробь \(\frac{x^2 - 9}{x + 3}\) и найдите её значение при \(x = 7\).
Решение\(\frac{(x - 3)(x + 3)}{x + 3} = x - 3\). При \(x = 7\): \(7 - 3 = 4\).

Ответ: 4

6. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{a^2 - 25}{2a^2 + 10a}\) при \(a = -0{,}4\).
РешениеЧислитель: \((a - 5)(a + 5)\). Знаменатель: \(2a(a + 5)\). Сокращаем \((a + 5)\): \(\frac{a - 5}{2a}\). При \(a = -0{,}4\): \(\frac{-0{,}4 - 5}{2\cdot(-0{,}4)} = \frac{-5{,}4}{-0{,}8} = 6{,}75\).

Ответ: 6,75

7. Прототип ОГЭ №9 (ФИПИ / Решу ОГЭ)
Решите уравнение \(2x^2 - 8x = 0\). Если уравнение имеет больше одного корня, в ответ запишите больший из корней.
Решение\(2x(x - 4) = 0\) → \(x = 0\) или \(x = 4\). Больший: 4.

Ответ: 4

Домашнее задание

1. Вычислите удобным способом: \(36\cdot58 + 36\cdot42\).
Решение\(36\cdot(58 + 42) = 36\cdot100 = 3600\).

Ответ: 3600

2. Решите уравнение \(x^2 + 6x = 0\). Запишите корни в порядке возрастания.
Решение\(x(x + 6) = 0\) → \(x = 0\) или \(x = -6\). По возрастанию: \(-6\); 0.

Ответ: \(-6\); 0

3. Решите уравнение \(x^2 - 64 = 0\). Запишите корни в порядке возрастания.
Решение\(x = -8\) или \(x = 8\).

Ответ: \(-8\); 8

4. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{x^2 - 16}{x - 4}\) при \(x = 6{,}5\).
Решение\(\frac{(x - 4)(x + 4)}{x - 4} = x + 4\). При \(x = 6{,}5\): \(10{,}5\).

Ответ: 10,5

5. Прототип ОГЭ №9 (ФИПИ / Решу ОГЭ)
Решите уравнение \(3x^2 - 27 = 0\). Если корней несколько, в ответ запишите меньший из них.
Решение\(3x^2 = 27\) → \(x^2 = 9\) → \(x = -3\) или \(x = 3\). Меньший: \(-3\).

Ответ: \(-3\)

6. Повторение (урок 20) При параллельных прямых и секущей сумма двух накрест лежащих углов равна \(136^\circ\). Найдите один из них.
РешениеОни равны: \(136 : 2 = 68^\circ\).

Ответ: 68

7. Повторение (урок 18) Абонентская плата за тариф — 350 руб. в месяц, в неё входит 8 ГБ интернета. Каждый гигабайт сверх пакета стоит 50 руб. За месяц израсходовано 11 ГБ. Сколько рублей нужно заплатить?
РешениеСверх пакета: \(11 - 8 = 3\) ГБ. \(350 + 3\cdot50 = 500\) руб.

Ответ: 500

8. Повторение (урок 14) На клетчатой бумаге с размером клетки \(1\times1\) изображена трапеция. Найдите её площадь.
РешениеОснования 6 и 4, высота 2: \(\frac{6 + 4}{2}\cdot2 = 10\).

Ответ: 10
