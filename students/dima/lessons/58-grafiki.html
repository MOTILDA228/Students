Для репетитора: план урока

Новая идея урока: три вида графиков: прямая \(y = kx + b\), парабола \(y = x^2\), гипербола \(y = \frac{k}{x}\). По форме определяем вид, по знакам — какая формула.

  1. 0–12 мин — разминка-повторение (8 задач на время; две — таблица/деление). Ошибки — сразу разобрать.
  2. 12–22 мин — новое: шпаргалка, проговорить алгоритм вслух, 2 примера у доски.
  3. 22–50 мин — «лесенка»: ступень 1 вместе (вы подсказываете), ступень 2 сам, ступень 3 сам на время. Кто быстро — дальше, не дожидаясь.
  4. 50–60 мин — мини-срез из 5 задач без подсказок. Результат: 5 → 10 баллов, 4 → 8, 3 → 6, 2 → 4 — в журнал.

Ошибки, которые ждём: путает параболу и гиперболу; не знает, что \(b\) — точка на оси \(y\).

Правило «проверь себя»: после каждого ответа — подставить обратно (умножением, сложением). Требовать это всегда, вслух.

ДЗ короткое (15 мин) и только на то, что получалось на уроке. Не сделал ДЗ — первые 10 минут следующего урока решает его при вас.

Разминка-повторение (12 минут)

1. Повторение (урок 57) Решите уравнение \(3x + 5x = 72\).
РешениеПриводим подобные: \(8x = 72\); \(x = 72 : 8 = 9\).

Ответ: 9

2. Повторение (урок 57) Найдите значение выражения \((3{,}6 - 0{,}2)\cdot3\).
РешениеСкобка \(3{,}4\); \(3{,}4\cdot3 = 10{,}2\).

Ответ: 10,2

3. Повторение (урок 56) Вписанный угол равен \(30^\circ\). Найдите центральный угол, опирающийся на ту же дугу.
РешениеЦентральный — в 2 раза больше: \(60^\circ\).

Ответ: 60

4. Повторение (урок 56) В треугольнике два угла \(53^\circ\) и \(24^\circ\). Найдите третий.
Решение\(180 - 53 - 24 = 103^\circ\).

Ответ: 103

5. Повторение (урок 54) Решите неравенство \(-3x \ge -9\). В ответ запишите наибольшее целое решение.
РешениеДелим на \(-3\) — знак переворачивается: \(x \le 3\). Наибольшее целое 3.

Ответ: 3

6. Повторение (урок 54) Решите неравенство \(3x + (-2) > 1\). В ответ запишите наименьшее целое решение.
Решение\(3x > 1 - (-2) = 3\); \(x > 1\). Наименьшее целое: 2.

Ответ: 2

7. Повторение (урок 8) Вычислите \(40 : 5\).
РешениеВспоминаем «семейство»: \(5\cdot8 = 40\), значит \(40 : 5 = 8\).

Ответ: 8

8. Повторение (урок 8) Какое число пропущено: \(4\cdot\square = 16\)?
РешениеПропущенный множитель: \(16 : 4 = 4\).

Ответ: 4

Шпаргалка

Прямая: \(k > 0\) — идёт вверх, \(k < 0\) — вниз; \(b\) — где пересекает ось \(y\). Парабола: перед \(x^2\) минус — ветви вниз. Гипербола: \(k > 0\) — в I и III четвертях.

Ступень 1. Значение функции

1. Функция задана формулой \(y = -5x + (-2)\). Найдите \(y\) при \(x = -1\).
Решение\(y = -5\cdot(-1) + (-2) = 3\).

Ответ: 3

2. Функция задана формулой \(y = -3x + 8\). Найдите \(y\) при \(x = 1\).
Решение\(y = -3\cdot1 + 8 = 5\).

Ответ: 5

3. Функция задана формулой \(y = 3x + (-1)\). Найдите \(y\) при \(x = 4\).
Решение\(y = 3\cdot4 + (-1) = 11\).

Ответ: 11

4. Функция задана формулой \(y = -3x + (-5)\). Найдите \(y\) при \(x = -1\).
Решение\(y = -3\cdot(-1) + (-5) = -2\).

Ответ: -2

5. Функция задана формулой \(y = -4x + 5\). Найдите \(y\) при \(x = 5\).
Решение\(y = -4\cdot5 + 5 = -15\).

Ответ: -15

6. Функция задана формулой \(y = -3x + 0\). Найдите \(y\) при \(x = 2\).
Решение\(y = -3\cdot2 + 0 = -6\).

Ответ: -6
