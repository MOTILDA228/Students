Для репетитора: план урока

Новая идея урока: три вида: \(x^2 = a\) (два корня \(\pm\)), \(x^2 - ax = 0\) (вынести \(x\)), полное — через дискриминант. Проходим, только если линейные уравнения уже надёжны.

  1. 0–12 мин — разминка-повторение (8 задач на время; две — таблица/деление). Ошибки — сразу разобрать.
  2. 12–22 мин — новое: шпаргалка, проговорить алгоритм вслух, 2 примера у доски.
  3. 22–50 мин — «лесенка»: ступень 1 вместе (вы подсказываете), ступень 2 сам, ступень 3 сам на время. Кто быстро — дальше, не дожидаясь.
  4. 50–60 мин — мини-срез из 5 задач без подсказок. Результат: 5 → 10 баллов, 4 → 8, 3 → 6, 2 → 4 — в журнал.

Ошибки, которые ждём: \(x^2 = 25\) → только 5 (теряет \(-5\)); в \(x^2 = 5x\) делит на \(x\) и теряет 0.

Правило «проверь себя»: после каждого ответа — подставить обратно (умножением, сложением). Требовать это всегда, вслух.

ДЗ короткое (15 мин) и только на то, что получалось на уроке. Не сделал ДЗ — первые 10 минут следующего урока решает его при вас.

Разминка-повторение (12 минут)

1. Повторение (урок 51) Из 25 фонариков 4 неисправны. Найдите вероятность того, что случайно выбранный фонарик исправен.
РешениеИсправных 21: \(P = \frac{21}{25} = 0{,}84\).

Ответ: 0,84

2. Повторение (урок 51) Формула \(F = 1{,}8C + 32\) — температура по Фаренгейту через Цельсий. Найдите \(F\), если \(C = -4\).
РешениеПодставляем: \(C = -4\) → \(F = 24{,}8\).

Ответ: 24,8

3. Повторение (урок 50) Найдите значение выражения \(\frac{6{,}6}{0{,}6}\).
РешениеПереносим запятую: \(66 : 6 = 11\).

Ответ: 11

4. Повторение (урок 50) Решите уравнение \(8x + 12 = 7x + 8\).
РешениеИксы — влево, числа — вправо (при переносе знак меняется): \(8x - 7x = 8 - 12\); \(1x = -4\); \(x = -4\).

Ответ: -4

5. Повторение (урок 48) В первом ряду кинотеатра 8 мест, а в каждом следующем на 1 больше. Сколько мест в 11-м ряду?
Решение\(a_{11} = 8 + 10\cdot1 = 18\).

Ответ: 18

6. Повторение (урок 48) Найдите следующий член последовательности: 8, 6, 4, 2, …
РешениеКаждый раз прибавляем -2: 2 + (-2) = 0.

Ответ: 0

7. Повторение (урок 8) Вычислите \(24 : 3\).
РешениеВспоминаем «семейство»: \(3\cdot8 = 24\), значит \(24 : 3 = 8\).

Ответ: 8

8. Повторение (урок 8) Какое число пропущено: \(7\cdot\square = 28\)?
РешениеПропущенный множитель: \(28 : 7 = 4\).

Ответ: 4

Шпаргалка

1. \(x^2 = a\)

\(x^2 = 49\) → \(x = 7\) или \(x = -7\).

2. \(x^2 - ax = 0\)

Выносим \(x\): \(x(x - 5) = 0\) → \(x = 0\) или \(x = 5\).

3. Полное: \(x^2 + bx + c = 0\)

  1. \(D = b^2 - 4c\) (для \(a = 1\)).
  2. \(x = \frac{-b \pm \sqrt{D}}{2}\).
\(x^2 - 5x + 6 = 0\): \(D = 25 - 24 = 1\), \(x = \frac{5 \pm 1}{2}\): 3 и 2.
