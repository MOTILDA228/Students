Для репетитора: план урока

Цель: Дима угадывает корни по Виета, приводит уравнение к стандартному виду и не попадается на «ловушки» №9.

  1. 5–10 мин — проверка ДЗ урока 24.
  2. 15 мин — шпаргалка: Виета как «угадайка» + проверка; перенос всего влево; уравнения-произведения.
  3. 25–30 мин — практика. Если корни не угадываются за 30 секунд — считать через \(D\).
  4. 5 мин — итог: «сначала всё влево, справа ноль».

Типичные ошибки: применяет Виета, когда \(a \ne 1\); путает знак суммы; в \((x + 10)^2 = (5 - x)^2\) решает квадратное уравнение, хотя \(x^2\) сокращается.

Шпаргалка

1. Теорема Виета (когда перед \(x^2\) стоит 1)

Для \(x^2 + bx + c = 0\): \[ x_1 + x_2 = -b,\qquad x_1\cdot x_2 = c \] Ищем два числа: произведение равно \(c\), сумма равна \(b\) с противоположным знаком.
\(x^2 - 7x + 12 = 0\): произведение 12, сумма 7 → числа 3 и 4 (\(3\cdot4 = 12\), \(3 + 4 = 7\)).
\(x^2 + x - 20 = 0\): произведение \(-20\), сумма \(-1\) → \(-5\) и 4.
Не угадывается — не мучайся, считай дискриминант (урок 24). Виета — только ускорение.

2. Сначала — стандартный вид

Перенеси всё в левую часть, справа должен остаться 0: \(x^2 = 3x + 10\) → \(x^2 - 3x - 10 = 0\).

3. Уравнение-произведение — скобки не раскрываем!

\((x - 3)(x + 5) = 0\) → каждая скобка может быть нулём: \(x = 3\) или \(x = -5\) (урок 22).

4. Ловушка: \(x^2\) сокращается

\((x + 10)^2 = (5 - x)^2\)
\(x^2 + 20x + 100 = 25 - 10x + x^2\) — \(x^2\) есть с обеих сторон, вычитаем.
\(20x + 10x = 25 - 100\) → \(30x = -75\) → \(x = -2{,}5\). Уравнение оказалось линейным!

5. Уравнение вида \((x + a)^2 = k\)

\((x + 2)^2 = 9\) → \(x + 2 = 3\) или \(x + 2 = -3\) → \(x = 1\) или \(x = -5\).

Практика на уроке

1. Решите по теореме Виета: \(x^2 - 7x + 12 = 0\). Запишите корни в порядке возрастания.
РешениеПроизведение 12, сумма 7: 3 и 4. Проверка: \(3 + 4 = 7\), \(3\cdot4 = 12\) ✓.

Ответ: 3; 4

2. Решите уравнение \(x^2 + x - 20 = 0\). Запишите корни в порядке возрастания.
РешениеПроизведение \(-20\), сумма \(-1\): \(-5\) и 4 (\(-5 + 4 = -1\), \(-5\cdot4 = -20\)).

Ответ: \(-5\); 4

3. Решите уравнение \((x - 3)(x + 5) = 0\). Запишите корни в порядке возрастания.
Решение\(x - 3 = 0\) → \(x = 3\); \(x + 5 = 0\) → \(x = -5\).

Ответ: \(-5\); 3

4. Решите уравнение \(x^2 = 3x + 10\). Запишите корни в порядке возрастания.
РешениеВсё влево: \(x^2 - 3x - 10 = 0\). Произведение \(-10\), сумма 3: \(-2\) и 5.

Ответ: \(-2\); 5

5. Решите уравнение \((x + 2)^2 = 9\). Запишите корни в порядке возрастания.
Решение\(x + 2 = 3\) → \(x = 1\); \(x + 2 = -3\) → \(x = -5\).

Ответ: \(-5\); 1

6. Прототип ОГЭ №9 (ФИПИ / Решу ОГЭ)
Найдите корни уравнения \(x^2 + x = 12\). Если корней несколько, запишите их через точку с запятой в порядке возрастания.
Решение\(x^2 + x - 12 = 0\). Произведение \(-12\), сумма \(-1\): \(-4\) и 3.

Ответ: \(-4\); 3

7. Прототип ОГЭ №9 (ФИПИ / Решу ОГЭ)
Решите уравнение \((x + 10)^2 = (5 - x)^2\).
Решение\(x^2 + 20x + 100 = 25 - 10x + x^2\). \(x^2\) сокращается: \(30x = -75\) → \(x = -2{,}5\). Проверка: \((7{,}5)^2 = (7{,}5)^2\) ✓.

Ответ: \(-2{,}5\)

Домашнее задание

1. Решите по теореме Виета: \(x^2 - 9x + 20 = 0\). Запишите корни в порядке возрастания.
РешениеПроизведение 20, сумма 9: 4 и 5.

Ответ: 4; 5

2. Решите уравнение \(x^2 + 2x - 24 = 0\). Запишите корни в порядке возрастания.
РешениеПроизведение \(-24\), сумма \(-2\): \(-6\) и 4.

Ответ: \(-6\); 4

3. Решите уравнение \((x + 7)(x - 2) = 0\). Запишите корни в порядке возрастания.
Решение\(x = -7\) или \(x = 2\).

Ответ: \(-7\); 2

4. Решите уравнение \(x^2 = 2x + 8\). Запишите корни в порядке возрастания.
Решение\(x^2 - 2x - 8 = 0\): произведение \(-8\), сумма 2 → \(-2\) и 4.

Ответ: \(-2\); 4

5. Прототип ОГЭ №9 (ФИПИ / Решу ОГЭ)
Решите уравнение \((x - 6)^2 = (x + 8)^2\).
Решение\(x^2 - 12x + 36 = x^2 + 16x + 64\) → \(-12x - 16x = 64 - 36\) → \(-28x = 28\) → \(x = -1\).

Ответ: \(-1\)

6. Повторение (урок 23) Диагонали ромба равны 6 и 8. Найдите сторону ромба.
РешениеПоловины 3 и 4, сторона \(\sqrt{9 + 16} = 5\).

Ответ: 5

7. Повторение (урок 21) Найдите значение выражения \((\sqrt{6} - 2)(\sqrt{6} + 2)\).
Решение\(6 - 4 = 2\).

Ответ: 2

8. Повторение (урок 17) \(AB\) — диаметр окружности, точка \(C\) на окружности, \(\angle CAB = 41^\circ\). Найдите \(\angle CBA\).
Решение\(\angle ACB = 90^\circ\). \(\angle CBA = 180 - 90 - 41 = 49^\circ\).

Ответ: 49
