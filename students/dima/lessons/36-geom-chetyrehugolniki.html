Для репетитора: план урока

Новая идея урока: параллелограмм (противоположные стороны и углы равны, соседние углы — \(180^\circ\)), ромб, трапеция и их площади.

  1. 0–12 мин — разминка-повторение (8 задач на время; две — таблица/деление). Ошибки — сразу разобрать.
  2. 12–22 мин — новое: шпаргалка, проговорить алгоритм вслух, 2 примера у доски.
  3. 22–50 мин — «лесенка»: ступень 1 вместе (вы подсказываете), ступень 2 сам, ступень 3 сам на время. Кто быстро — дальше, не дожидаясь.
  4. 50–60 мин — мини-срез из 5 задач без подсказок. Результат: 5 → 10 баллов, 4 → 8, 3 → 6, 2 → 4 — в журнал.

Ошибки, которые ждём: путает формулы площадей; в трапеции забывает делить сумму оснований на 2.

Правило «проверь себя»: после каждого ответа — подставить обратно (умножением, сложением). Требовать это всегда, вслух.

ДЗ короткое (15 мин) и только на то, что получалось на уроке. Не сделал ДЗ — первые 10 минут следующего урока решает его при вас.

Разминка-повторение (12 минут)

1. Повторение (урок 35) По формуле \(S = vt\) найдите \(t\) (в часах), если \(S = 22\) км, \(v = 11\) км/ч.
Решение\(22 = 11\cdott\) — неизвестный множитель: \(t = 22 : 11 = 2\).

Ответ: 2

2. Повторение (урок 35) Формула \(F = 1{,}8C + 32\) — температура по Фаренгейту через Цельсий. Найдите \(F\), если \(C = -20\).
РешениеПодставляем: \(C = -20\) → \(F = -4\).

Ответ: -4

3. Повторение (урок 34) Из 200 фонариков 7 неисправны. Найдите вероятность того, что случайно выбранный фонарик исправен.
РешениеИсправных 193: \(P = \frac{193}{200} = 0{,}965\).

Ответ: 0,965

4. Повторение (урок 34) Бросают игральный кубик. Найдите вероятность того, что выпадет число меньше 4.
РешениеПодходят: 1, 2, 3 — 3 из 6: \(0{,}5\).

Ответ: 0,5

5. Повторение (урок 32) Найдите 10% от 120.
Решение\(120\cdot\frac{10}{100} = 12\).

Ответ: 12

6. Повторение (урок 32) Товар стоит 5000 руб. Сколько он будет стоить со скидкой 25%?
РешениеОстаётся 75%: \(5000\cdot0{,}75 = 3750\) руб.

Ответ: 3750

7. Повторение (урок 8) Вычислите \(6 : 2\).
РешениеВспоминаем «семейство»: \(2\cdot3 = 6\), значит \(6 : 2 = 3\).

Ответ: 3

8. Повторение (урок 8) Какое число пропущено: \(3\cdot\square = 15\)?
РешениеПропущенный множитель: \(15 : 3 = 5\).

Ответ: 5

Ступень 2. Площади по формулам
