Для репетитора: план урока

Цель: Дима решает квадратные неравенства «методом параболы»: корни → ветви вверх → края или середина.

  1. 5–10 мин — проверка ДЗ урока 27.
  2. 15 мин — шпаргалка. Нарисовать параболу, показать: «над осью — плюс, под осью — минус».
  3. 25–30 мин — практика. Каждый раз рисовать маленькую параболу через корни — без рисунка не решать.
  4. 5 мин — итог: «больше нуля — края, меньше нуля — середина».

Типичные ошибки: пишет ответ «между корнями» для «\(> 0\)»; в \(x^2 < 9\) пишет \(x < 3\) и теряет \(-3\); путает закрашенные и выколотые точки.

Шпаргалка

1. Идея: парабола и знаки

График \(y = x^2 - 2x - 3\): корни \(-1\) и \(3\).

Если перед \(x^2\) стоит плюс, парабола смотрит ветвями вверх. Она ниже оси \(x\) (значения отрицательные) только между корнями, а слева и справа от корней — выше оси (значения положительные).

2. Алгоритм

  1. Перенеси всё влево, справа 0: \(ax^2 + bx + c > 0\) (или \(<, \ge, \le\)).
  2. Реши уравнение \(ax^2 + bx + c = 0\) → корни \(x_1 < x_2\) (уроки 24–25).
  3. Нарисуй прямую, отметь корни, нарисуй параболу ветвями вверх.
  4. Знак \(> 0\) или \(\ge 0\) → берём края (левее \(x_1\) и правее \(x_2\)).
    Знак \(< 0\) или \(\le 0\) → берём середину (между корнями).
  5. Точки: \(\ge, \le\) — закрашены; \(>, <\) — выколоты.

3. Частые случаи

\(x^2 < 9\) → корни \(\pm3\) → середина: \(-3 < x < 3\).
\(x^2 > 9\) → края: \(x < -3\) или \(x > 3\).
\(x^2 - 5x \le 0\) → \(x(x - 5) = 0\), корни 0 и 5 → середина: \(0 \le x \le 5\).
Если перед \(x^2\) минус (\(-x^2 + \ldots\)), сначала умножь всё на \(-1\) и переверни знак неравенства.

Практика на уроке

1. Решите неравенство \(x^2 - 4 < 0\). Сколько целых чисел являются его решениями?
РешениеКорни \(\pm2\). Знак «\(<\)» → середина: \(-2 < x < 2\). Целые: \(-1, 0, 1\) — три числа.

Ответ: 3

2. Решите неравенство \(x^2 - 5x + 6 \le 0\). Сколько целых чисел являются его решениями?
РешениеКорни 2 и 3 (Виета). «\(\le\)» → середина с концами: \(2 \le x \le 3\). Целые: 2 и 3 — два числа.

Ответ: 2

3. Решите неравенство \(x^2 + 2x - 8 > 0\). Найдите наименьшее натуральное решение.
РешениеКорни: \(-4\) и 2. «\(>\)» → края: \(x < -4\) или \(x > 2\). Натуральные числа (1, 2, 3, …) начинаются справа от 2: наименьшее — 3.

Ответ: 3

4. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Укажите решение неравенства \(x^2 - 36 \le 0\).
РешениеКорни \(\pm6\). «\(\le\)» → середина, точки закрашены: \([-6;\ 6]\) — вариант 2.

Ответ: 2

5. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Укажите решение неравенства \(x^2 - 3x > 0\).
1) \((0;\ 3)\)2) \((3;\ +\infty)\)3) \((-\infty;\ 3)\)4) \((-\infty;\ 0)\cup(3;\ +\infty)\)
Решение\(x(x - 3) = 0\) → корни 0 и 3. «\(>\)» → края: \(x < 0\) или \(x > 3\) — вариант 4.

Ответ: 4

6. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Укажите решение неравенства \(x^2 \le 4x\).
РешениеВсё влево: \(x^2 - 4x \le 0\) → корни 0 и 4 → «\(\le\)» → середина: \([0;\ 4]\) — вариант 1.

Ответ: 1

7. Решите неравенство \((x - 2)(x + 5) < 0\). Сколько целых чисел являются его решениями?
РешениеКорни 2 и \(-5\) (скобки не раскрываем!). «\(<\)» → середина: \(-5 < x < 2\). Целые: \(-4, -3, -2, -1, 0, 1\) — шесть чисел.

Ответ: 6

Домашнее задание

1. Решите неравенство \(x^2 - 16 < 0\). Сколько целых чисел являются его решениями?
Решение\(-4 < x < 4\): целые от \(-3\) до 3 — семь чисел.

Ответ: 7

2. Решите неравенство \(x^2 - 6x + 8 \le 0\). Сколько целых чисел являются его решениями?
РешениеКорни 2 и 4. Середина с концами: \(2 \le x \le 4\) → 2, 3, 4 — три числа.

Ответ: 3

3. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Укажите решение неравенства \(x^2 - 49 \ge 0\).
РешениеКорни \(\pm7\). «\(\ge\)» → края, точки закрашены — вариант 2.

Ответ: 2

4. Прототип ОГЭ №13 (ФИПИ / Решу ОГЭ)
Укажите решение неравенства \(x^2 + 4x < 0\).
1) \((-\infty;\ -4)\cup(0;\ +\infty)\)2) \((0;\ 4)\)3) \((-4;\ 0)\)4) \((-\infty;\ 0)\)
Решение\(x(x + 4) = 0\) → корни \(-4\) и 0. «\(<\)» → середина: \((-4;\ 0)\) — вариант 3.

Ответ: 3

5. Решите неравенство \((x + 3)(x - 4) > 0\). Найдите наименьшее натуральное решение.
РешениеКорни \(-3\) и 4. «\(>\)» → края: \(x < -3\) или \(x > 4\). Наименьшее натуральное: 5.

Ответ: 5

6. Повторение (урок 26) Основания трапеции равны 6 и 14. Найдите её среднюю линию.
Решение\(\frac{6 + 14}{2} = 10\).

Ответ: 10

7. Повторение (урок 24) Решите уравнение \(3x^2 - 27 = 0\). Запишите корни в порядке возрастания.
Решение\(x^2 = 9\) → \(-3\) и 3.

Ответ: \(-3\); 3

8. Повторение (урок 20) Сумма двух соответственных углов при параллельных прямых и секущей равна \(144^\circ\). Найдите один из них.
РешениеСоответственные углы равны: \(144 : 2 = 72^\circ\).

Ответ: 72
