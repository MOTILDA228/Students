Для репетитора: план урока

Новая идея урока: три «бытовых» темы, которые дают баллы в №1–5, №10, №12.

  1. 0–12 мин — разминка-повторение (8 задач на время; две — таблица/деление). Ошибки — сразу разобрать.
  2. 12–22 мин — новое: шпаргалка, проговорить алгоритм вслух, 2 примера у доски.
  3. 22–50 мин — «лесенка»: ступень 1 вместе (вы подсказываете), ступень 2 сам, ступень 3 сам на время. Кто быстро — дальше, не дожидаясь.
  4. 50–60 мин — мини-срез из 5 задач без подсказок. Результат: 5 → 10 баллов, 4 → 8, 3 → 6, 2 → 4 — в журнал.

Ошибки, которые ждём: в вероятности переворачивает дробь; в процентах вычитает проценты как рубли.

Правило «проверь себя»: после каждого ответа — подставить обратно (умножением, сложением). Требовать это всегда, вслух.

ДЗ короткое (15 мин) и только на то, что получалось на уроке. Не сделал ДЗ — первые 10 минут следующего урока решает его при вас.

Разминка-повторение (12 минут)

1. Повторение (урок 63) Цена 1800 руб. повысилась на 15%. Какой стала цена?
РешениеСтало 115%: \(1800\cdot1{,}15 = 2070\) руб.

Ответ: 2070

2. Повторение (урок 63) Формула \(F = 1{,}8C + 32\) — температура по Фаренгейту через Цельсий. Найдите \(F\), если \(C = -12\).
РешениеПодставляем: \(C = -12\) → \(F = 10{,}4\).

Ответ: 10,4

3. Повторение (урок 62) Найдите площадь трапеции на клетчатой бумаге (клетка \(1\times1\)).
РешениеОснования 7 и 3, высота 3: \(S = \frac{7+3}{2}\cdot3 = 15\).

Ответ: 15

4. Повторение (урок 62) Катеты прямоугольного треугольника равны 5 и 12. Найдите гипотенузу.
Решение\(c^2 = 5^2 + 12^2 = 25 + 144 = 169\), \(c = \sqrt{169} = 13\).

Ответ: 13

5. Повторение (урок 60) Найдите площадь треугольника на клетчатой бумаге (клетка \(1\times1\)).
РешениеОснование (по нижней линии) 4, высота 3: \(S = \frac{4\cdot3}{2} = 6\).

Ответ: 6

6. Повторение (урок 60) Решите уравнение \(4(x - 8) + 1 = -19\).
РешениеРаскрываем скобки: \(4x - 32 + 1 = -19\); \(4x = -19 + 32 - 1 = 12\); \(x = 3\).

Ответ: 3

7. Повторение (урок 8) Вычислите \(12 : 3\).
РешениеВспоминаем «семейство»: \(3\cdot4 = 12\), значит \(12 : 3 = 4\).

Ответ: 4

8. Повторение (урок 8) Какое число пропущено: \(3\cdot\square = 24\)?
РешениеПропущенный множитель: \(24 : 3 = 8\).

Ответ: 8

Шпаргалка

Проценты (урок 32): скидка \(p\%\) — умножить на \((100 - p)\%\). Вероятность (34): подходящие : все. Формулы (35): подставить; неизвестное — уравнение.

Ступень 1. Проценты

1. Товар стоит 2300 руб. Сколько он будет стоить со скидкой 15%?
РешениеОстаётся 85%: \(2300\cdot0{,}85 = 1955\) руб.

Ответ: 1955

2. Сколько процентов составляет 200 от 500?
Решение\(\frac{200}{500}\cdot100\% = 40\%\).

Ответ: 40

3. 50% числа равны 300. Найдите это число.
Решение1% — это \(300 : 50 = 6\); 100% — \(6\cdot100 = 600\).

Ответ: 600

4. Сколько процентов составляет 18 от 25?
Решение\(\frac{18}{25}\cdot100\% = 72\%\).

Ответ: 72

5. 5% числа равны 8. Найдите это число.
Решение1% — это \(8 : 5 = 1{,}6\); 100% — \(1{,}6\cdot100 = 160\).

Ответ: 160

6. Найдите 10% от 80.
Решение\(80\cdot\frac{10}{100} = 8\).

Ответ: 8

7. Сколько процентов составляет 4 от 20?
Решение\(\frac{4}{20}\cdot100\% = 20\%\).

Ответ: 20

Ступень 2. Вероятность

1. В классе 50 учеников: 11 занимаются футболом, 14 — плаванием (каждый одним видом), остальные не занимаются спортом. Найдите вероятность того, что случайный ученик не занимается спортом.
РешениеНе занимаются: \(50 - 11 - 14 = 25\). \(P = \frac{25}{50} = 0{,}5\).

Ответ: 0,5

2. Из 25 фонариков 1 неисправны. Найдите вероятность того, что случайно выбранный фонарик исправен.
РешениеИсправных 24: \(P = \frac{24}{25} = 0{,}96\).

Ответ: 0,96

3. Из 400 фонариков 92 неисправны. Найдите вероятность того, что случайно выбранный фонарик исправен.
РешениеИсправных 308: \(P = \frac{308}{400} = 0{,}77\).

Ответ: 0,77

4. В классе 25 учеников: 8 занимаются футболом, 6 — плаванием (каждый одним видом), остальные не занимаются спортом. Найдите вероятность того, что случайный ученик не занимается спортом.
РешениеНе занимаются: \(25 - 8 - 6 = 11\). \(P = \frac{11}{25} = 0{,}44\).

Ответ: 0,44

5. Из 200 фонариков 6 неисправны. Найдите вероятность того, что случайно выбранный фонарик исправен.
РешениеИсправных 194: \(P = \frac{194}{200} = 0{,}97\).

Ответ: 0,97

6. В коробке 50 ручек, из них 38 красных. Найдите вероятность того, что ручка красная.
Решение\(P = \frac{38}{50} = 0{,}76\).

Ответ: 0,76

7. В классе 20 учеников: 4 занимаются футболом, 3 — плаванием (каждый одним видом), остальные не занимаются спортом. Найдите вероятность того, что случайный ученик не занимается спортом.
РешениеНе занимаются: \(20 - 4 - 3 = 13\). \(P = \frac{13}{20} = 0{,}65\).

Ответ: 0,65

Ступень 3. Формулы

1. Формула \(C = 150 + 11(t - 5)\) — стоимость поездки на такси \(C\) (руб.) длительностью \(t\) мин. Найдите \(C\), если \(t = 37\).
РешениеПодставляем: \(t = 37\) → \(C = 502\).

Ответ: 502

2. Формула \(F = 1{,}8C + 32\) — температура по Фаренгейту через Цельсий. Найдите \(F\), если \(C = -17\).
РешениеПодставляем: \(C = -17\) → \(F = 1{,}4\).

Ответ: 1,4

3. Формула \(S = vt\) — путь \(S\) (км), скорость \(v\) (км/ч), время \(t\) (ч). Найдите \(S\), если \(v = 10\), \(t = 23\).
РешениеПодставляем: \(v = 10\), \(t = 23\) → \(S = 230\).

Ответ: 230

4. Формула \(P = 2(a + b)\) — периметр прямоугольника. Найдите \(P\), если \(a = 15\), \(b = 19\).
РешениеПодставляем: \(a = 15\), \(b = 19\) → \(P = 68\).

Ответ: 68

5. По формуле \(P = 2(a + b)\) найдите \(b\), если \(P = 102\), \(a = 26\).
Решение\(102 = 2(a + b)\) → \(a + b = 51\) → \(b = 51 - 26 = 25\).

Ответ: 25

6. По формуле \(S = vt\) найдите \(t\) (в часах), если \(S = 222\) км, \(v = 37\) км/ч.
Решение\(222 = 37\cdott\) — неизвестный множитель: \(t = 222 : 37 = 6\).

Ответ: 6

7. По формуле \(S = vt\) найдите \(t\) (в часах), если \(S = 145\) км, \(v = 29\) км/ч.
Решение\(145 = 29\cdott\) — неизвестный множитель: \(t = 145 : 29 = 5\).

Ответ: 5

Мини-срез (10 минут, без подсказок)

1. Сколько процентов составляет 4 от 40?
Решение\(\frac{4}{40}\cdot100\% = 10\%\).

Ответ: 10

2. Формула \(A = Pt\) — работа тока \(A\) (Дж), мощность \(P\) (Вт), время \(t\) (с). Найдите \(A\), если \(P = 11\), \(t = 19\).
РешениеПодставляем: \(P = 11\), \(t = 19\) → \(A = 209\).

Ответ: 209

3. По формуле \(S = vt\) найдите \(t\) (в часах), если \(S = 148\) км, \(v = 37\) км/ч.
Решение\(148 = 37\cdott\) — неизвестный множитель: \(t = 148 : 37 = 4\).

Ответ: 4

4. По формуле \(P = 2(a + b)\) найдите \(b\), если \(P = 94\), \(a = 25\).
Решение\(94 = 2(a + b)\) → \(a + b = 47\) → \(b = 47 - 25 = 22\).

Ответ: 22

5. Формула \(C = 150 + 11(t - 5)\) — стоимость поездки на такси \(C\) (руб.) длительностью \(t\) мин. Найдите \(C\), если \(t = 6\).
РешениеПодставляем: \(t = 6\) → \(C = 161\).

Ответ: 161

10. Повторение (урок 60) Решите уравнение \(4x + (-14) = 5x + (-11)\).
РешениеИксы — влево, числа — вправо (при переносе знак меняется): \(4x - 5x = -11 - (-14)\); \(-1x = 3\); \(x = -3\).

Ответ: -3

РешениеВписанный — половина центрального: \(41^\circ\).

Ответ: 41
