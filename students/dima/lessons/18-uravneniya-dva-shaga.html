Для репетитора: план урока

Новая идея урока: уравнение \(5x + 3 = 48\) — «матрёшка»: сначала \(5x\) — неизвестное слагаемое, потом \(x\) — неизвестный множитель. Два раза применяем правила уроков 9–14.

  1. 0–12 мин — разминка-повторение (8 задач на время; две — таблица/деление). Ошибки — сразу разобрать.
  2. 12–22 мин — новое: шпаргалка, проговорить алгоритм вслух, 2 примера у доски.
  3. 22–50 мин — «лесенка»: ступень 1 вместе (вы подсказываете), ступень 2 сам, ступень 3 сам на время. Кто быстро — дальше, не дожидаясь.
  4. 50–60 мин — мини-срез из 5 задач без подсказок. Результат: 5 → 10 баллов, 4 → 8, 3 → 6, 2 → 4 — в журнал.

Ошибки, которые ждём: в срезе \(3x + 5 = 26\) и \(2x - 7 = 15\) не начал. Делит на 3 раньше, чем вычел 5.

Правило «проверь себя»: после каждого ответа — подставить обратно (умножением, сложением). Требовать это всегда, вслух.

ДЗ короткое (15 мин) и только на то, что получалось на уроке. Не сделал ДЗ — первые 10 минут следующего урока решает его при вас.

Шпаргалка

1. Матрёшка

\(5x + 3 = 48\). Закроем \(5x\) ладонью: «что-то + 3 = 48». Что-то — неизвестное слагаемое: \(48 - 3 = 45\).
Теперь \(5x = 45\) — неизвестный множитель: \(x = 45 : 5 = 9\).
Проверка: \(5\cdot9 + 3 = 48\) ✓.
Порядок: сначала «отцепляем» то, что прибавлено или вычтено (шаг 1), потом делим (шаг 2). Обратный порядок к порядку действий!

2. Все виды

УравнениеШаг 1Шаг 2
\(3x + 5 = 26\)\(3x = 26 - 5 = 21\)\(x = 21 : 3 = 7\)
\(2x - 7 = 15\)\(2x = 15 + 7 = 22\)\(x = 11\)
\(4(x + 3) = 28\)\(x + 3 = 28 : 4 = 7\)\(x = 4\)
\(x : 3 + 2 = 9\)\(x : 3 = 7\)\(x = 21\)
Проверка — обязательна: подставь ответ в исходное уравнение.

Ступень 1. ax + b = c

РешениеШаг 1 — «отцепляем» 30 (неизвестное слагаемое): \(4x = 38 - 30 = 8\). Шаг 2 — неизвестный множитель: \(x = 8 : 4 = 2\). Проверка: \(4\cdot2 + 30 = 38\) ✓.

Ответ: 2
