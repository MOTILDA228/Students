Для репетитора: план урока

Цель: Дима знает три формулы (квадрат суммы, квадрат разности, разность квадратов), раскрывает по ним скобки и решает прототипы №8 «упрости и подставь».

  1. 5–10 мин — проверка ДЗ урока 20.
  2. 15 мин — шпаргалка. Показать на числах, что \((2 + 3)^2 \ne 2^2 + 3^2\). Формулы выписать на карточку.
  3. 25–30 мин — практика: сначала устный счёт (задачи 1–3), потом выражения.
  4. 5 мин — итог: «первое в квадрате, удвоенное произведение, второе в квадрате».

Типичные ошибки: \((a + b)^2 = a^2 + b^2\) (теряет удвоенное произведение); путает знак у \(2ab\); после минуса перед скобкой не меняет знаки.

Шпаргалка

1. Три формулы

\[ (a + b)^2 = a^2 + 2ab + b^2 \] \[ (a - b)^2 = a^2 - 2ab + b^2 \] \[ (a - b)(a + b) = a^2 - b^2 \] Словами: «квадрат первого, плюс (минус) удвоенное произведение первого на второе, плюс квадрат второго». Третья — «разность квадратов».
Главная ошибка: \((a + b)^2 \ne a^2 + b^2\). Проверь на числах: \((2 + 3)^2 = 25\), а \(2^2 + 3^2 = 13\). Не хватает \(2\cdot2\cdot3 = 12\).
\((x + 3)^2 = x^2 + 6x + 9\) · \((2x - 5)^2 = 4x^2 - 20x + 25\) · \((x - 4)(x + 4) = x^2 - 16\)

2. Устный счёт по формулам

\(21^2 = (20 + 1)^2 = 400 + 40 + 1 = 441\)
\(51^2 - 49^2 = (51 - 49)(51 + 49) = 2\cdot100 = 200\)

3. Корни и разность квадратов (частый №8)

\((\sqrt{a} - b)(\sqrt{a} + b) = a - b^2\): корень в квадрате «исчезает».
\((\sqrt{13} - 3)(\sqrt{13} + 3) = 13 - 9 = 4\)

4. Шаблон №8 «упростите и найдите значение»

  1. Раскрой скобки по формулам и обычным правилам (урок 12).
  2. Приведи подобные — обычно \(x^2\) сокращается.
  3. Подставь число в короткое выражение.
\((x + 5)^2 - x(x - 10)\) при \(x = -\frac{1}{20}\):
\(x^2 + 10x + 25 - x^2 + 10x = 20x + 25\). Подставляем: \(20\cdot\left(-\frac{1}{20}\right) + 25 = -1 + 25 = 24\).

Практика на уроке

1. Вычислите \(21^2\) с помощью формулы квадрата суммы.
Решение\((20 + 1)^2 = 20^2 + 2\cdot20\cdot1 + 1^2 = 400 + 40 + 1 = 441\).

Ответ: 441

2. Вычислите \(99^2\) с помощью формулы квадрата разности.
Решение\((100 - 1)^2 = 10000 - 200 + 1 = 9801\).

Ответ: 9801

3. Вычислите \(53^2 - 47^2\).
РешениеРазность квадратов: \((53 - 47)(53 + 47) = 6\cdot100 = 600\).

Ответ: 600

4. Найдите значение выражения \((x - 3)^2 - x^2\) при \(x = 0{,}5\).
Решение\(x^2 - 6x + 9 - x^2 = -6x + 9\). При \(x = 0{,}5\): \(-3 + 9 = 6\).

Ответ: 6

5. Найдите значение выражения \((\sqrt{13} - 3)(\sqrt{13} + 3)\).
РешениеРазность квадратов: \((\sqrt{13})^2 - 3^2 = 13 - 9 = 4\).

Ответ: 4

6. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \((x + 4)^2 - x(x - 8)\) при \(x = -\frac{1}{16}\).
Решение\(x^2 + 8x + 16 - x^2 + 8x = 16x + 16\). Подставляем: \(16\cdot\left(-\frac{1}{16}\right) + 16 = -1 + 16 = 15\).

Ответ: 15

7. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \((\sqrt{7} + 3)^2 - 6\sqrt{7}\).
Решение\((\sqrt{7})^2 + 2\cdot3\cdot\sqrt{7} + 9 - 6\sqrt{7} = 7 + 6\sqrt{7} + 9 - 6\sqrt{7} = 16\).

Ответ: 16

Домашнее задание

1. Вычислите \(31^2\) с помощью формулы квадрата суммы.
Решение\((30 + 1)^2 = 900 + 60 + 1 = 961\).

Ответ: 961

2. Вычислите \(62^2 - 38^2\).
Решение\((62 - 38)(62 + 38) = 24\cdot100 = 2400\).

Ответ: 2400

3. Найдите значение выражения \((x + 2)^2 - x^2\) при \(x = 3{,}5\).
Решение\(x^2 + 4x + 4 - x^2 = 4x + 4\). При \(x = 3{,}5\): \(14 + 4 = 18\).

Ответ: 18

4. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \((\sqrt{11} - 3)(\sqrt{11} + 3)\).
Решение\(11 - 9 = 2\).

Ответ: 2

5. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \((x - 4)^2 - x(x + 12)\) при \(x = \frac{1}{20}\).
Решение\(x^2 - 8x + 16 - x^2 - 12x = -20x + 16\). При \(x = \frac{1}{20}\): \(-1 + 16 = 15\).

Ответ: 15

6. Повторение (урок 20) При параллельных прямых и секущей один из односторонних углов равен \(57^\circ\). Найдите другой.
Решение\(180 - 57 = 123^\circ\).

Ответ: 123

7. Повторение (урок 17) Центральный угол равен \(124^\circ\). Найдите вписанный угол, опирающийся на ту же дугу.
Решение\(124 : 2 = 62^\circ\).

Ответ: 62

8. Повторение (урок 13) Формула \(t_F = 1{,}8\,t_C + 32\). Найдите \(t_F\), если \(t_C = 15\).
Решение\(1{,}8\cdot15 + 32 = 27 + 32 = 59\).

Ответ: 59
