Для репетитора: план урока

Новая идея урока: неизвестный множитель = произведение : известный множитель. Это решает \(5x = 95\) без подбора.

  1. 0–12 мин — разминка-повторение (8 задач на время; две — таблица/деление). Ошибки — сразу разобрать.
  2. 12–22 мин — новое: шпаргалка, проговорить алгоритм вслух, 2 примера у доски.
  3. 22–50 мин — «лесенка»: ступень 1 вместе (вы подсказываете), ступень 2 сам, ступень 3 сам на время. Кто быстро — дальше, не дожидаясь.
  4. 50–60 мин — мини-срез из 5 задач без подсказок. Результат: 5 → 10 баллов, 4 → 8, 3 → 6, 2 → 4 — в журнал.

Ошибки, которые ждём: при \(5x = 95\) подбирает «5·19» — подбор долгий и на ОГЭ не сработает. Пишет \(x = 95\cdot5\) — спутал с делимым.

Правило «проверь себя»: после каждого ответа — подставить обратно (умножением, сложением). Требовать это всегда, вслух.

ДЗ короткое (15 мин) и только на то, что получалось на уроке. Не сделал ДЗ — первые 10 минут следующего урока решает его при вас.

Разминка-повторение (12 минут)

1. Повторение (урок 11) Решите уравнение \(79 - x = 23\).
РешениеНеизвестное вычитаемое = уменьшаемое − разность: \(x = 79 - 23 = 56\). Проверка: \(79 - 56 = 23\) ✓.

Ответ: 56

2. Повторение (урок 11) Решите уравнение \(x - 31 = 82\).
РешениеНеизвестное уменьшаемое = разность + вычитаемое: \(x = 82 + 31 = 113\). Проверка: \(113 - 31 = 82\) ✓.

Ответ: 113

3. Повторение (урок 10) Найдите длину отрезка \(AB\) (клетка \(1\times1\)).
РешениеОтрезок идёт по линии сетки — считаем клетки: 6.

Ответ: 6

4. Повторение (урок 10) На клетчатой бумаге с клеткой \(1\times1\) изображён прямоугольник. Найдите его площадь.
РешениеСчитаем клетки: длина 5, ширина 3. \(S = 5\cdot3 = 15\).

Ответ: 15

5. Повторение (урок 8) Вычислите \(27 : 9\).
РешениеВспоминаем «семейство»: \(9\cdot3 = 27\), значит \(27 : 9 = 3\).

Ответ: 3

Ответ: 7

Шпаргалка

1. Названия

\(\underbrace{5}_{\text{множитель}}\cdot\underbrace{19}_{\text{множитель}} = \underbrace{95}_{\text{произведение}}\). Запись \(5x\) — это \(5\cdot x\).

2. Правило

Неизвестный множитель = произведение : известный множитель.
\(5x = 95\) → \(x = 95 : 5 = 19\). Проверка: \(5\cdot19 = 95\) ✓.
\(x\cdot7 = 84\) → \(x = 84 : 7 = 12\).

3. На пальцах

5 одинаковых коробок, в них 95 карандашей. Сколько в одной? — Делим поровну: \(95 : 5\).
Не «95 · 5»! Произведение — самое большое число, его делим. Проверяй умножением.

4. Как делить «большое» на однозначное

\(95 : 5\): \(95 = 50 + 45\); \(50 : 5 = 10\), \(45 : 5 = 9\) → 19.
