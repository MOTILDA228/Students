Для репетитора: план урока

Цель: Дима читает по графику прямой коэффициенты \(k\) и \(b\), подставляет точки и решает №11 на соответствие «график — формула».

  1. 5–10 мин — проверка ДЗ урока 39.
  2. 15 мин — шпаргалка. Построить вместе \(y = 2x - 1\) по двум точкам на клетчатой бумаге.
  3. 25–30 мин — практика. В №11 для каждого графика сначала найти \(b\) (где пересекает ось \(y\)), потом наклон.
  4. 5 мин — итог: «\(b\) — где пересекает ось \(y\); \(k\) — вверх или вниз и насколько круто».

Типичные ошибки: путает оси \(x\) и \(y\); определяет знак \(k\) справа налево; считает \(b\) по пересечению с осью \(x\).

Шпаргалка

1. Формула и график

\(y = kx + b\) — линейная функция, её график — прямая. Для построения хватит двух точек.
\(y = 2x - 1\): при \(x = 0\) \(y = -1\); при \(x = 1\) \(y = 1\). Отмечаем точки \((0; -1)\) и \((1; 1)\), проводим прямую.

2. Что показывают \(k\) и \(b\)

\(b\) — точка, где прямая пересекает ось \(y\): \((0; b)\).
\(k\) — наклон. Иди по прямой слева направо:
• поднимается → \(k > 0\); опускается → \(k < 0\); горизонтальная → \(k = 0\);
• сдвинься вправо на 1 клетку — на сколько клеток прямая поднялась (опустилась)? Это и есть \(k\).
Чем больше \(|k|\), тем круче прямая.

3. Точка на графике и пересечение прямых

Точка \((x_0; y_0)\) лежит на графике, если при подстановке \(x_0\) получается \(y_0\).
Точка пересечения двух прямых: приравняй правые части и реши уравнение.
\(y = 2x - 1\) и \(y = -x + 5\): \(2x - 1 = -x + 5\) → \(3x = 6\) → \(x = 2\), \(y = 2\cdot2 - 1 = 3\). Точка \((2; 3)\).

4. Алгоритм №11

  1. Для каждого графика найди \(b\) — где прямая пересекает ось \(y\).
  2. Определи знак \(k\): вверх или вниз слева направо.
  3. Найди формулу с таким \(b\) и таким знаком \(k\). Ответ — цифры формул под буквами А, Б, В.

Практика на уроке

1. Найдите значение функции \(y = 2x - 3\) при \(x = 4\).
Решение\(y = 2\cdot4 - 3 = 5\).

Ответ: 5

2. Найдите абсциссу точки пересечения графика функции \(y = 3x + 6\) с осью \(Ox\).
РешениеНа оси \(Ox\) \(y = 0\): \(3x + 6 = 0\) → \(x = -2\).

Ответ: \(-2\)

3. График функции \(y = kx + 1\) проходит через точку \((2; 7)\). Найдите \(k\).
РешениеПодставляем: \(7 = k\cdot2 + 1\) → \(2k = 6\) → \(k = 3\).

Ответ: 3

4. По графику определите коэффициенты \(k\) и \(b\) функции \(y = kx + b\). Запишите их через точку с запятой: сначала \(k\), потом \(b\).
РешениеПрямая пересекает ось \(y\) в точке \(-1\): \(b = -1\). От \(x = 0\) до \(x = 1\) прямая поднялась с \(-1\) до \(1\), то есть на 2: \(k = 2\).

Ответ: 2; \(-1\)

5. Прототип ОГЭ №11 (ФИПИ / Решу ОГЭ)
Установите соответствие между графиками функций и формулами, которые их задают. В ответ запишите цифры под буквами А, Б, В.
1) \(y = -x + 3\)2) \(y = 0{,}5x - 2\)3) \(y = 2x + 1\)
РешениеА: пересекает ось \(y\) в 1, круто вверх → \(y = 2x + 1\) (3).
Б: пересекает в 3, идёт вниз → \(y = -x + 3\) (1).
В: пересекает в \(-2\), полого вверх → \(y = 0{,}5x - 2\) (2).

Ответ: 312

6. Прототип ОГЭ №11 (ФИПИ / Решу ОГЭ)
Установите соответствие между графиками функций вида \(y = kx + b\) и знаками коэффициентов \(k\) и \(b\).
1) \(k > 0,\ b < 0\)2) \(k > 0,\ b > 0\)3) \(k < 0,\ b > 0\)
РешениеА: вверх, пересекает ось \(y\) выше нуля → \(k > 0, b > 0\) (2).
Б: вниз, выше нуля → \(k < 0, b > 0\) (3).
В: вверх, ниже нуля → \(k > 0, b < 0\) (1).

Ответ: 231

7. Найдите абсциссу точки пересечения графиков \(y = 2x - 1\) и \(y = -x + 5\).
Решение\(2x - 1 = -x + 5\) → \(3x = 6\) → \(x = 2\).

Ответ: 2

Домашнее задание

1. Найдите значение функции \(y = -3x + 2\) при \(x = -2\).
Решение\(y = -3\cdot(-2) + 2 = 6 + 2 = 8\).

Ответ: 8

2. Найдите абсциссу точки пересечения графика функции \(y = 4x - 8\) с осью \(Ox\).
Решение\(4x - 8 = 0\) → \(x = 2\).

Ответ: 2

3. График функции \(y = kx - 3\) проходит через точку \((2; 5)\). Найдите \(k\).
Решение\(5 = 2k - 3\) → \(2k = 8\) → \(k = 4\).

Ответ: 4

4. Прототип ОГЭ №11 (ФИПИ / Решу ОГЭ)
Установите соответствие между графиками функций и формулами, которые их задают. В ответ запишите цифры под буквами А, Б, В.
1) \(y = x - 1\)2) \(y = -2x + 1\)3) \(y = 0{,}5x + 2\)
РешениеА: вниз, пересекает ось \(y\) в 1 → \(y = -2x + 1\) (2). Б: полого вверх, в 2 → (3). В: вверх, в \(-1\) → (1).

Ответ: 231

5. Найдите ординату точки пересечения графиков \(y = 3x + 1\) и \(y = x + 5\).
Решение\(3x + 1 = x + 5\) → \(x = 2\). \(y = 3\cdot2 + 1 = 7\).

Ответ: 7

8. Повторение (урок 32) В треугольнике \(ABC\) отрезок \(MN\) параллелен \(AC\) (\(M\) на \(AB\), \(N\) на \(BC\)). \(BM = 3\), \(AB = 9\), \(AC = 12\). Найдите \(MN\).
Решение\(k = \frac{3}{9} = \frac{1}{3}\). \(MN = 12 : 3 = 4\).
