Для репетитора: план урока

Новая идея урока: отрицательное число — это «долг». Сложение: одинаковые знаки — складываем и оставляем знак; разные — вычитаем из большего модуля меньший, знак берём у «сильного». Вычитание = прибавить противоположное.

  1. 0–12 мин — разминка-повторение (8 задач на время; две — таблица/деление). Ошибки — сразу разобрать.
  2. 12–22 мин — новое: шпаргалка, проговорить алгоритм вслух, 2 примера у доски.
  3. 22–50 мин — «лесенка»: ступень 1 вместе (вы подсказываете), ступень 2 сам, ступень 3 сам на время. Кто быстро — дальше, не дожидаясь.
  4. 50–60 мин — мини-срез из 5 задач без подсказок. Результат: 5 → 10 баллов, 4 → 8, 3 → 6, 2 → 4 — в журнал.

Ошибки, которые ждём: \(-3 - 4 = 1\) (теряет минус); \(5 - (-2) = 3\) (минус на минус не превращает в плюс).

Правило «проверь себя»: после каждого ответа — подставить обратно (умножением, сложением). Требовать это всегда, вслух.

ДЗ короткое (15 мин) и только на то, что получалось на уроке. Не сделал ДЗ — первые 10 минут следующего урока решает его при вас.

Разминка-повторение (12 минут)

1. Повторение (урок 27) Вычислите \(2{,}9\cdot2{,}2\).
РешениеУмножаем без запятых, в ответе после запятой столько цифр, сколько у обоих множителей вместе: \(6{,}38\).

Ответ: 6,38

2. Повторение (урок 27) Вычислите \(\frac{1}{3} + \frac{4}{6}\).
РешениеШаг 1 — общий знаменатель 6. Шаг 2 — доп. множители: 2 и 1. Шаг 3: \(\frac{2}{6} + \frac{4}{6} = \frac{6}{6}\) \(= 1\).

Ответ: 1

3. Повторение (урок 26) Решите уравнение \(2x - 4 = 0\).
РешениеШаг 1 — неизвестное уменьшаемое: \(2x = 0 + 4 = 4\). Шаг 2 — неизвестный множитель: \(x = 4 : 2 = 2\). Проверка: \(2\cdot2 - 4 = 0\) ✓.

Ответ: 2

4. Повторение (урок 26) Решите уравнение \(72 : x = 24\).
РешениеНеизвестный делитель = делимое : частное: \(x = 72 : 24 = 3\). Проверка: \(72 : 3 = 24\) ✓.

Ответ: 3

5. Повторение (урок 24) Вычислите \(2{,}76 - 0{,}3\).
РешениеЗапятая под запятой: \(2{,}46\).

Ответ: 2,46

6. Повторение (урок 24) Вычислите \(0{,}42\cdot2\).
РешениеУмножаем как целые, потом отделяем запятой столько цифр, сколько после запятой в множителе: \(0{,}42\cdot2 = 0{,}84\).

Ответ: 0,84

7. Повторение (урок 8) Вычислите \(18 : 6\).
РешениеВспоминаем «семейство»: \(6\cdot3 = 18\), значит \(18 : 6 = 3\).

Ответ: 3

8. Повторение (урок 8) Какое число пропущено: \(5\cdot\square = 30\)?
РешениеПропущенный множитель: \(30 : 5 = 6\).

Ответ: 6

Шпаргалка

1. Числовая прямая и «долги»

Модуль — расстояние до нуля, без знака: \(|-4| = 4\). Отрицательное число — «долг»: \(-4\) — должен 4.

2. Сложение

СлучайКакПример
оба «−»долги складываются: модули сложить, минус оставить\(-5 + (-7) = -12\)
знаки разныеиз большего модуля вычесть меньший, знак — у большего модуля\(-9 + 4 = -5\); \(-3 + 8 = 5\)

3. Вычитание

Вычесть — значит прибавить противоположное: \(a - b = a + (-b)\).
\(5 - (-2) = 5 + 2 = 7\); \(-3 - 4 = -3 + (-4) = -7\).
Два минуса рядом («\(- (-\)») дают плюс. Минус перед числом без скобок — это просто «долг».
