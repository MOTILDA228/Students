Для репетитора: план урока

Новая идея урока: деление столбиком как повторяющийся цикл из 4 шагов: «взять — разделить — умножить — вычесть — снести».

  1. 0–12 мин — разминка-повторение (8 задач на время; две — таблица/деление). Ошибки — сразу разобрать.
  2. 12–22 мин — новое: шпаргалка, проговорить алгоритм вслух, 2 примера у доски.
  3. 22–50 мин — «лесенка»: ступень 1 вместе (вы подсказываете), ступень 2 сам, ступень 3 сам на время. Кто быстро — дальше, не дожидаясь.
  4. 50–60 мин — мини-срез из 5 задач без подсказок. Результат: 5 → 10 баллов, 4 → 8, 3 → 6, 2 → 4 — в журнал.

Ошибки, которые ждём: в срезе \(144 : 12 = 9\); забывает ноль в частном (\(824 : 4 = 26\) вместо 206); не делает проверку умножением.

Правило «проверь себя»: после каждого ответа — подставить обратно (умножением, сложением). Требовать это всегда, вслух.

ДЗ короткое (15 мин) и только на то, что получалось на уроке. Не сделал ДЗ — первые 10 минут следующего урока решает его при вас.

Разминка-повторение (12 минут)

1. Повторение (урок 14) Решите уравнение \(x : 9 = 27\).
РешениеНеизвестное делимое = частное · делитель: \(x = 27\cdot9 = 243\). Проверка: \(243 : 9 = 27\) ✓.

Ответ: 243

2. Повторение (урок 14) Решите уравнение \(120 : x = 15\).
РешениеНеизвестный делитель = делимое : частное: \(x = 120 : 15 = 8\). Проверка: \(120 : 8 = 15\) ✓.

Ответ: 8

3. Повторение (урок 13) Один из вертикальных углов равен \(142^\circ\). Найдите другой.
РешениеВертикальные углы равны: \(142^\circ\).

Ответ: 142

4. Повторение (урок 13) В треугольнике два угла \(66^\circ\) и \(77^\circ\). Найдите третий.
Решение\(180 - 66 - 77 = 37^\circ\).

Ответ: 37

5. Повторение (урок 11) Решите уравнение \(119 - x = 100\).
РешениеНеизвестное вычитаемое = уменьшаемое − разность: \(x = 119 - 100 = 19\). Проверка: \(119 - 19 = 100\) ✓.

Ответ: 19

6. Повторение (урок 11) Решите уравнение \(x - 114 = 57\).
РешениеНеизвестное уменьшаемое = разность + вычитаемое: \(x = 57 + 114 = 171\). Проверка: \(171 - 114 = 57\) ✓.

Ответ: 171

7. Повторение (урок 8) Вычислите \(40 : 5\).
РешениеВспоминаем «семейство»: \(5\cdot8 = 40\), значит \(40 : 5 = 8\).

Ответ: 8

8. Повторение (урок 8) Какое число пропущено: \(4\cdot\square = 20\)?
РешениеПропущенный множитель: \(20 : 4 = 5\).

Ответ: 5

Шпаргалка

1. Цикл из пяти шагов

  1. Взять первое число, которое делится (≥ делителя).
  2. Разделить — сколько раз помещается делитель? (таблица!)
  3. Умножить цифру частного на делитель, записать под числом.
  4. Вычесть — остаток должен быть меньше делителя.
  5. Снести следующую цифру — и снова с шага 2.
\(864 : 4\): \(8 : 4 = 2\); сносим 6: \(6 : 4 = 1\), остаток 2; сносим 4: \(24 : 4 = 6\). Ответ 216.
Ноль в частном. Если после сноса цифры число меньше делителя — пишем в частном 0 и сносим ещё. \(824 : 4 = 206\), не 26!
Прикидка до деления: сколько цифр будет в ответе? \(864 : 4\) — первое число 8, значит частное трёхзначное. Проверка после: частное · делитель = делимое.

2. Двузначный делитель

\(144 : 12\): «12 на сколько ≈ 144?» — \(12\cdot10 = 120\), остаётся 24, \(24 : 12 = 2\). Ответ 12.
