Для репетитора: план урока

Цель: Дима по рисунку находит противолежащий и прилежащий катеты, считает \(\sin\), \(\cos\), \(\operatorname{tg}\) и находит стороны по ним.

  1. 5–10 мин — разбор контрольной №2.
  2. 15 мин — шпаргалка. На одном треугольнике для угла \(A\) подписать три стороны словами. Потом то же для угла \(B\) — показать, что катеты «меняются ролями».
  3. 25–30 мин — практика. Во всех задачах на стороны: записать формулу, подставить, решить как пропорцию (урок 13).
  4. 5 мин — итог: «синус — напротив, косинус — рядом, тангенс — напротив делить на рядом».

Типичные ошибки: путает противолежащий и прилежащий катеты; делит гипотенузу на катет; при \(\operatorname{tg}A = \frac{BC}{AC}\) ищет \(AC\) умножением.

Шпаргалка

1. Стороны относительно острого угла

Смотрим на угол \(A\):
• противолежащий катет — лежит напротив угла: \(BC\);
• прилежащий катет — касается угла (образует его): \(AC\);
• гипотенуза — напротив прямого угла: \(AB\).

2. Три определения

\[ \sin A = \frac{\text{противолежащий}}{\text{гипотенуза}} = \frac{BC}{AB} \qquad \cos A = \frac{\text{прилежащий}}{\text{гипотенуза}} = \frac{AC}{AB} \qquad \operatorname{tg} A = \frac{\text{противолежащий}}{\text{прилежащий}} = \frac{BC}{AC} \]
Для рисунка: \(\sin A = \frac{3}{5} = 0{,}6\), \(\cos A = \frac{4}{5} = 0{,}8\), \(\operatorname{tg} A = \frac{3}{4} = 0{,}75\).
Запоминалка: синус — «сидит напротив», косинус — «касается», тангенс — «напротив делить на рядом» (гипотенузы в тангенсе нет).

3. Как найти сторону

  1. Выбери формулу, где есть известная сторона и искомая.
  2. Подставь числа — получится пропорция.
  3. Реши её (урок 13).
\(\angle C = 90^\circ\), \(BC = 12\), \(\operatorname{tg} A = 1{,}5\). Найти \(AC\).
\(\operatorname{tg}A = \frac{BC}{AC}\) → \(1{,}5 = \frac{12}{AC}\) → \(AC = 12 : 1{,}5 = 8\).

4. Полезное

Для острых углов прямоугольного треугольника: \(\sin A = \cos B\) и \(\cos A = \sin B\) — это одна и та же дробь.

Практика на уроке

1. В прямоугольном треугольнике катеты равны 3 и 4, гипотенуза равна 5. Угол \(A\) лежит напротив катета 3. Найдите: а) \(\sin A\); б) \(\cos A\); в) \(\operatorname{tg} A\).
Решениеа) \(\frac{3}{5} = 0{,}6\); б) \(\frac{4}{5} = 0{,}8\); в) \(\frac{3}{4} = 0{,}75\).

Ответ: а) 0,6; б) 0,8; в) 0,75

2. В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AB = 10\), \(\sin A = 0{,}6\). Найдите \(BC\).
Решение\(\sin A = \frac{BC}{AB}\) → \(0{,}6 = \frac{BC}{10}\) → \(BC = 0{,}6\cdot10 = 6\).

Ответ: 6

3. В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AC = 8\), \(\cos A = 0{,}8\). Найдите \(AB\).
Решение\(\cos A = \frac{AC}{AB}\) → \(0{,}8 = \frac{8}{AB}\) → \(AB = 8 : 0{,}8 = 10\).

Ответ: 10

4. В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AC = 12\), \(\operatorname{tg} A = 0{,}75\). Найдите \(BC\).
Решение\(\operatorname{tg}A = \frac{BC}{AC}\) → \(BC = 0{,}75\cdot12 = 9\).

Ответ: 9

5. В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(\sin A = 0{,}3\). Найдите \(\cos B\).
Решение\(\sin A = \frac{BC}{AB}\), \(\cos B = \frac{BC}{AB}\) (для угла \(B\) катет \(BC\) прилежащий) — одна и та же дробь. \(\cos B = 0{,}3\).

Ответ: 0,3

6. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(BC = 12\), \(\operatorname{tg} A = 1{,}5\). Найдите \(AC\).
Решение\(\operatorname{tg} A = \frac{BC}{AC}\) → \(1{,}5 = \frac{12}{AC}\) → \(AC = 12 : 1{,}5 = 8\).

Ответ: 8

7. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AC = 9\), \(\cos A = 0{,}3\). Найдите \(AB\).
Решение\(\cos A = \frac{AC}{AB}\) → \(0{,}3 = \frac{9}{AB}\) → \(AB = 9 : 0{,}3 = 30\).

Ответ: 30

Домашнее задание

1. Катеты прямоугольного треугольника равны 7 и 24, гипотенуза равна 25. Угол \(A\) лежит напротив катета 7. Найдите: а) \(\sin A\); б) \(\cos A\).
Решениеа) \(\frac{7}{25} = \frac{28}{100} = 0{,}28\); б) \(\frac{24}{25} = \frac{96}{100} = 0{,}96\).

Ответ: а) 0,28; б) 0,96

2. В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AB = 20\), \(\sin A = 0{,}35\). Найдите \(BC\).
Решение\(BC = 0{,}35\cdot20 = 7\).

Ответ: 7

3. В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AC = 15\), \(\cos A = 0{,}6\). Найдите \(AB\).
Решение\(AB = 15 : 0{,}6 = 25\).

Ответ: 25

4. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AC = 6\), \(\operatorname{tg} A = 1{,}5\). Найдите \(BC\).
Решение\(\operatorname{tg} A = \frac{BC}{AC}\) → \(BC = 1{,}5\cdot6 = 9\).

Ответ: 9

5. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(\sin A = 0{,}4\). Найдите \(\cos B\).
Решение\(\cos B = \frac{BC}{AB} = \sin A = 0{,}4\).

Ответ: 0,4

6. Повторение (урок 33) Монету бросают дважды. Найдите вероятность того, что орёл выпадет хотя бы один раз.
РешениеИсходы ОО, ОР, РО, РР. Хотя бы один орёл — все, кроме РР: 3 из 4. \(P = 0{,}75\). (Или \(1 - 0{,}25\).)

Ответ: 0,75

7. Повторение (урок 31) На тарелке 20 пирожков: 11 с мясом, остальные с капустой. Найдите вероятность того, что случайно выбранный пирожок окажется с капустой.
РешениеС капустой \(20 - 11 = 9\). \(P = \frac{9}{20} = 0{,}45\).

Ответ: 0,45

8. Повторение (урок 27) Решите неравенство \(5x - 2 > 3x + 6\). В ответ запишите наименьшее целое решение.
Решение\(2x > 8\) → \(x > 4\). Наименьшее целое: 5.

Ответ: 5
