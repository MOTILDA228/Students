Для репетитора: план урока

Новая идея урока: собрать в одну таблицу все виды №6: обыкновенные дроби, десятичные, с минусами и степенями 10. Первый вопрос к себе: «какой это вид?»

  1. 0–12 мин — разминка-повторение (8 задач на время; две — таблица/деление). Ошибки — сразу разобрать.
  2. 12–22 мин — новое: шпаргалка, проговорить алгоритм вслух, 2 примера у доски.
  3. 22–50 мин — «лесенка»: ступень 1 вместе (вы подсказываете), ступень 2 сам, ступень 3 сам на время. Кто быстро — дальше, не дожидаясь.
  4. 50–60 мин — мини-срез из 5 задач без подсказок. Результат: 5 → 10 баллов, 4 → 8, 3 → 6, 2 → 4 — в журнал.

Ошибки, которые ждём: начинает считать, не определив вид; смешивает обыкновенные и десятичные без перевода.

Правило «проверь себя»: после каждого ответа — подставить обратно (умножением, сложением). Требовать это всегда, вслух.

ДЗ короткое (15 мин) и только на то, что получалось на уроке. Не сделал ДЗ — первые 10 минут следующего урока решает его при вас.

Разминка-повторение (12 минут)

1. Повторение (урок 36) Периметр квадрата 48. Найдите его площадь.
РешениеСторона \(48 : 4 = 12\), \(S = 12^2 = 144\).

Ответ: 144

2. Повторение (урок 36) Один угол параллелограмма \(36^\circ\). Найдите соседний с ним угол.
РешениеСоседние углы в сумме \(180^\circ\): 144°.

Ответ: 144

3. Повторение (урок 35) Формула \(C = 150 + 11(t - 5)\) — стоимость поездки на такси \(C\) (руб.) длительностью \(t\) мин. Найдите \(C\), если \(t = 21\).
РешениеПодставляем: \(t = 21\) → \(C = 326\).

Ответ: 326

4. Повторение (урок 35) По формуле \(P = 2(a + b)\) найдите \(b\), если \(P = 58\), \(a = 27\).
Решение\(58 = 2(a + b)\) → \(a + b = 29\) → \(b = 29 - 27 = 2\).

Ответ: 2

5. Повторение (урок 33) \(AB\) — диаметр окружности, \(C\) — точка на ней, \(\angle CAB = 57^\circ\). Найдите \(\angle CBA\).
РешениеУгол на диаметр \(\angle ACB = 90^\circ\). \(\angle CBA = 90 - 57 = 33^\circ\).

Ответ: 33

6. Повторение (урок 33) Радиус окружности 11. Найдите диаметр.
РешениеДиаметр — два радиуса: 22.

Ответ: 22

7. Повторение (урок 8) Вычислите \(18 : 2\).
РешениеВспоминаем «семейство»: \(2\cdot9 = 18\), значит \(18 : 2 = 9\).

Ответ: 9

8. Повторение (урок 8) Какое число пропущено: \(5\cdot\square = 25\)?
РешениеПропущенный множитель: \(25 : 5 = 5\).

Ответ: 5
