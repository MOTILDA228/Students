Для репетитора: план урока

Цель: Дима сокращает алгебраические дроби через разложение на множители и решает прототипы №8 «упростите и найдите значение», где часто одна буква исчезает.

  1. 5–10 мин — проверка ДЗ урока 42.
  2. 15 мин — шпаргалка. Главное: сокращаются только множители. Повторить разложение (урок 22).
  3. 25–30 мин — практика. Сначала упростить, только потом подставлять — так проще и меньше ошибок.
  4. 5 мин — итог.

Типичные ошибки: «сокращает» слагаемые (\(\frac{x + 3}{x} = 3\)); теряет минус в \(\frac{1}{b} - \frac{1}{a}\); подставляет числа в длинное выражение и тонет в вычислениях.

Шпаргалка

1. Что такое алгебраическая дробь

Дробь с буквами: \(\frac{3a}{a + 2}\), \(\frac{x^2 - 9}{x + 3}\). Знаменатель не может быть нулём. Правила — как у обычных дробей (урок 3).

2. Сокращение

  1. Разложи числитель и знаменатель на множители (вынеси общий множитель, примени формулы — уроки 21–22).
  2. Сократи одинаковые множители (скобки, буквы, числа).
\(\frac{3a + 6}{a^2 + 2a} = \frac{3(a + 2)}{a(a + 2)} = \frac{3}{a}\) · \(\frac{x^2 - 25}{x - 5} = \frac{(x - 5)(x + 5)}{x - 5} = x + 5\)
Сокращаются только множители! \(\frac{x + 3}{x}\) сократить нельзя: \(x\) в числителе — слагаемое. А \(\frac{2x}{x} = 2\) — можно, там \(x\) множитель.

3. Умножение и деление

Умножение: разложи всё на множители, сократи крест-накрест, перемножь остатки. Деление: переверни вторую дробь.
\(\frac{9b}{a - b}\cdot\frac{a^2 - ab}{27b} = \frac{9b}{a - b}\cdot\frac{a(a - b)}{27b} = \frac{a}{3}\) — буква \(b\) исчезла!

4. Сложение и вычитание

Общий знаменатель, как у обычных дробей: \(\frac{1}{b} - \frac{1}{a} = \frac{a}{ab} - \frac{b}{ab} = \frac{a - b}{ab}\).

5. Алгоритм №8

  1. Упрости выражение до короткого (часто остаётся одна буква или число).
  2. Подставь число. Считай аккуратно с десятичными дробями.

Практика на уроке

1. Сократите дробь \(\frac{6x^2}{9x}\) и найдите её значение при \(x = 6\).
Решение\(\frac{6x^2}{9x} = \frac{2x}{3}\) (сократили на \(3x\)). При \(x = 6\): \(\frac{12}{3} = 4\).

Ответ: 4

2. Найдите значение выражения \(\frac{x^2 - 25}{x - 5}\) при \(x = 3{,}5\).
Решение\(\frac{(x - 5)(x + 5)}{x - 5} = x + 5 = 8{,}5\).

Ответ: 8,5

3. Найдите значение выражения \(\frac{3a + 6}{a^2 + 2a}\) при \(a = 0{,}6\).
Решение\(\frac{3(a + 2)}{a(a + 2)} = \frac{3}{a} = \frac{3}{0{,}6} = 5\).

Ответ: 5

4. Упростите выражение \(\frac{a}{a - b} - \frac{b}{a - b}\) и найдите его значение при \(a = 7\), \(b = 3\).
РешениеЗнаменатели одинаковые: \(\frac{a - b}{a - b} = 1\) (при любых \(a \ne b\)).

Ответ: 1

5. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{a^2 - 4b^2}{2ab}\cdot\frac{b}{a - 2b}\) при \(a = 4\), \(b = 3\).
Решение\(a^2 - 4b^2 = (a - 2b)(a + 2b)\). Сокращаем \((a - 2b)\) и \(b\): \(\frac{a + 2b}{2a}\). При \(a = 4\), \(b = 3\): \(\frac{4 + 6}{8} = \frac{10}{8} = 1{,}25\).

Ответ: 1,25

6. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{a^2 - b^2}{ab} : \left(\frac{1}{b} - \frac{1}{a}\right)\) при \(a = 1{,}2\), \(b = 0{,}8\).
РешениеСкобка: \(\frac{a - b}{ab}\). Делим — переворачиваем: \(\frac{(a - b)(a + b)}{ab}\cdot\frac{ab}{a - b} = a + b\). \(1{,}2 + 0{,}8 = 2\).

Ответ: 2

7. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{9b}{a - b}\cdot\frac{a^2 - ab}{27b}\) при \(a = 5{,}4\), \(b = 7\).
Решение\(\frac{9b}{a - b}\cdot\frac{a(a - b)}{27b} = \frac{a}{3}\). При \(a = 5{,}4\): \(1{,}8\). Значение \(b\) не понадобилось.

Ответ: 1,8

Домашнее задание

1. Сократите дробь \(\frac{8x^3}{12x^2}\) и найдите её значение при \(x = 9\).
Решение\(\frac{2x}{3}\). При \(x = 9\): 6.

Ответ: 6

2. Найдите значение выражения \(\frac{x^2 - 49}{x + 7}\) при \(x = 10{,}5\).
Решение\(x - 7 = 3{,}5\).

Ответ: 3,5

3. Найдите значение выражения \(\frac{5a - 10}{a^2 - 2a}\) при \(a = 2{,}5\).
Решение\(\frac{5(a - 2)}{a(a - 2)} = \frac{5}{a} = 2\).

Ответ: 2

4. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{12b}{a - b}\cdot\frac{a^2 - ab}{48b}\) при \(a = 2{,}8\), \(b = 5\).
Решение\(\frac{12b}{a - b}\cdot\frac{a(a - b)}{48b} = \frac{a}{4} = 0{,}7\).

Ответ: 0,7

5. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{a^2 - 9b^2}{3ab} : \left(\frac{1}{3b} - \frac{1}{a}\right)\) при \(a = 2{,}5\), \(b = 1{,}5\).
РешениеСкобка: \(\frac{a - 3b}{3ab}\). Делим: \(\frac{(a - 3b)(a + 3b)}{3ab}\cdot\frac{3ab}{a - 3b} = a + 3b = 2{,}5 + 4{,}5 = 7\).

Ответ: 7

6. Повторение (урок 41) Четырёхугольник \(ABCD\) вписан в окружность, \(\angle B = 67^\circ\). Найдите \(\angle D\).
Решение\(180 - 67 = 113^\circ\).

Ответ: 113

7. Повторение (урок 39) Камень бросают в ущелье. В первую секунду он пролетает 6 м, а в каждую следующую — на 10 м больше, чем в предыдущую. Сколько метров он пролетит за первые 4 секунды?
Решение\(a_4 = 6 + 30 = 36\). \(S_4 = \frac{6 + 36}{2}\cdot4 = 84\) м.

Ответ: 84

8. Повторение (урок 35) В треугольнике \(ABC\) угол \(C\) равен \(90^\circ\), \(AB = 40\), \(\cos A = 0{,}45\). Найдите \(AC\).
Решение\(\cos A = \frac{AC}{AB}\) → \(AC = 0{,}45\cdot40 = 18\).

Ответ: 18
