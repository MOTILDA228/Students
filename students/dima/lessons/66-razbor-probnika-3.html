Разминка-повторение (12 минут)

1. Повторение (урок 65) Найдите значение выражения \(\frac{14{,}5}{0{,}5}\).
РешениеПереносим запятую: \(145 : 5 = 29\).

Ответ: 29

2. Повторение (урок 65) Решите уравнение \(4x + 2x = 18\).
РешениеПриводим подобные: \(6x = 18\); \(x = 18 : 6 = 3\).

Ответ: 3

3. Повторение (урок 64) По формуле \(P = 2(a + b)\) найдите \(b\), если \(P = 100\), \(a = 27\).
Решение\(100 = 2(a + b)\) → \(a + b = 50\) → \(b = 50 - 27 = 23\).

Ответ: 23

4. Повторение (урок 64) Сколько процентов составляет 25 от 50?
Решение\(\frac{25}{50}\cdot100\% = 50\%\).

Ответ: 50

5. Повторение (урок 62) Найдите площадь трапеции на клетчатой бумаге (клетка \(1\times1\)).
РешениеОснования 5 и 4, высота 3: \(S = \frac{5+4}{2}\cdot3 = 13{,}5\).

Ответ: 13,5

6. Повторение (урок 62) Катеты прямоугольного треугольника равны 12 и 35. Найдите гипотенузу.
Решение\(c^2 = 12^2 + 35^2 = 144 + 1225 = 1369\), \(c = \sqrt{1369} = 37\).

Ответ: 37

7. Повторение (урок 8) Вычислите \(27 : 9\).
РешениеВспоминаем «семейство»: \(9\cdot3 = 27\), значит \(27 : 9 = 3\).

Ответ: 3

8. Повторение (урок 14) Решите уравнение \(x : 5 + 5 = 14\).
РешениеШаг 1: \(x : 5 = 14 - 5 = 9\). Шаг 2 — неизвестное делимое: \(x = 9\cdot5 = 45\).

Ответ: 45

Ответ: 1

2. Между какими соседними целыми числами находится \(\sqrt{80}\)? В ответ запишите меньшее.
Решение\(8^2 = 64 < 80 < 81 = 9^2\), значит \(8 < \sqrt{80} < 9\).

Ответ: 8

3. Какое из чисел наименьшее: 1) \(0{,}6\); 2) \(0{,}75\); 3) \(0{,}5\); 4) \(0{,}7\)? В ответ запишите номер.

Ответ: 27

№9 — уравнения

1. Решите уравнение \(2(x - 2) + 4 = 6\).
РешениеРаскрываем скобки: \(2x - 4 + 4 = 6\); \(2x = 6 + 4 - 4 = 6\); \(x = 3\).

Ответ: 3

2. Решите уравнение \(x : 2 + 15 = 23\).
РешениеШаг 1: \(x : 2 = 23 - 15 = 8\). Шаг 2 — неизвестное делимое: \(x = 8\cdot2 = 16\).

Ответ: 16

3. Решите уравнение \(8x + (-2) = 7x + (-6)\).
РешениеИксы — влево, числа — вправо (при переносе знак меняется): \(8x - 7x = -6 - (-2)\); \(1x = -4\); \(x = -4\).

Ответ: -4

№10 — вероятность

1. Из 400 фонариков 54 неисправны. Найдите вероятность того, что случайно выбранный фонарик исправен.
РешениеИсправных 346: \(P = \frac{346}{400} = 0{,}865\).

Ответ: 0,865

2. Бросают игральный кубик. Найдите вероятность того, что выпадет число больше 3.
РешениеПодходят: 4, 5, 6 — 3 из 6: \(0{,}5\).

Ответ: 0,5

3. Из 50 фонариков 4 неисправны. Найдите вероятность того, что случайно выбранный фонарик исправен.
РешениеИсправных 46: \(P = \frac{46}{50} = 0{,}92\).

Ответ: 0,92

№12 — формулы

1. Формула \(F = 1{,}8C + 32\) — температура по Фаренгейту через Цельсий. Найдите \(F\), если \(C = -2\).
РешениеПодставляем: \(C = -2\) → \(F = 28{,}4\).

Ответ: 28,4

2. По формуле \(S = vt\) найдите \(t\) (в часах), если \(S = 287\) км, \(v = 41\) км/ч.
Решение\(287 = 41\cdott\) — неизвестный множитель: \(t = 287 : 41 = 7\).

Ответ: 7

3. Формула \(A = Pt\) — работа тока \(A\) (Дж), мощность \(P\) (Вт), время \(t\) (с). Найдите \(A\), если \(P = 17\), \(t = 4\).
РешениеПодставляем: \(P = 17\), \(t = 4\) → \(A = 68\).

Ответ: 68

№13 — неравенства

1. Укажите решение неравенства \(5x + 4 \ge 9\).
1) \((-\infty;\ 1)\)2) \((1;\ +\infty)\)3) \((-\infty;\ 1]\)4) \([1;\ +\infty)\)
Решение\(5x \ge 5\), \(x \ge 1\) — точка закрашена, квадратная скобка: вариант 4.

Ответ: 4

2. Решите неравенство \(3x + 10 > 31\). В ответ запишите наименьшее целое решение.
Решение\(3x > 31 - 10 = 21\); \(x > 7\). Наименьшее целое: 8.

Ответ: 8

3. Укажите решение неравенства \(6x + 2 \ge -4\).
1) \((-\infty;\ -1)\)2) \((-1;\ +\infty)\)3) \((-\infty;\ -1]\)4) \([-1;\ +\infty)\)
Решение\(6x \ge -6\), \(x \ge -1\) — точка закрашена, квадратная скобка: вариант 4.

Ответ: 4

№14 — прогрессия

1. Арифметическая прогрессия: \(a_1 = 12\), \(d = -3\). Найдите \(a_{10}\).
Решение\(a_n = a_1 + (n - 1)d = 12 + 9\cdot(-3) = -15\).

Ответ: -15

2. В первом ряду кинотеатра 19 мест, а в каждом следующем на 2 больше. Сколько мест в 10-м ряду?
Решение\(a_{10} = 19 + 9\cdot2 = 37\).

Ответ: 37

3. Арифметическая прогрессия: \(a_1 = 14\), \(d = -3\). Найдите \(a_{8}\).
Решение\(a_n = a_1 + (n - 1)d = 14 + 7\cdot(-3) = -7\).

Ответ: -7

№15 — треугольники

1. Катеты прямоугольного треугольника равны 10 и 24. Найдите гипотенузу.
Решение\(c^2 = 10^2 + 24^2 = 100 + 576 = 676\), \(c = \sqrt{676} = 26\).

Ответ: 26

2. В равнобедренном треугольнике угол при вершине \(134^\circ\). Найдите угол при основании.
РешениеУглы при основании равны: \((180 - 134) : 2 = 23^\circ\).

Ответ: 23

3. В треугольнике два угла \(37^\circ\) и \(32^\circ\). Найдите третий.
Решение\(180 - 37 - 32 = 111^\circ\).

Ответ: 111

№16 — окружность

1. Вписанный угол равен \(46^\circ\). Найдите центральный угол, опирающийся на ту же дугу.
РешениеЦентральный — в 2 раза больше: \(92^\circ\).

Ответ: 92

2. \(AB\) — диаметр окружности, \(C\) — точка на ней, \(\angle CAB = 62^\circ\). Найдите \(\angle CBA\).
РешениеУгол на диаметр \(\angle ACB = 90^\circ\). \(\angle CBA = 90 - 62 = 28^\circ\).

Ответ: 28

3. Центральный угол равен \(188^\circ\). Найдите вписанный угол, опирающийся на ту же дугу.
РешениеВписанный — половина центрального: \(94^\circ\).

Ответ: 94
