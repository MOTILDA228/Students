Цель: разобрать ошибки урока 59. Ниже — по 3 задачи-двойника на каждый номер ОГЭ 6–19. Решать только номера с ошибками; номера, решённые верно, — по одной задаче для темпа.

  1. 10 мин — разбор ошибок: «как думал?», найти шаг, где сломалось.
  2. 40 мин — двойники.
  3. 10 мин — по одной задаче из каждого ошибочного номера без подсказок.

Разминка-повторение (12 минут)

1. Повторение (урок 59) Найдите значение выражения \(-0{,}5\cdot(-10)^3 + 5\cdot(-10)^2 - 21\).
Решение\((-10)^3 = -1000\), \((-10)^2 = 100\): \(500 + 500 - 21 = 979\).

Ответ: 979

2. Повторение (урок 59) В классе 20 учеников: 6 занимаются футболом, 4 — плаванием (каждый одним видом), остальные не занимаются спортом. Найдите вероятность того, что случайный ученик не занимается спортом.
РешениеНе занимаются: \(20 - 6 - 4 = 10\). \(P = \frac{10}{20} = 0{,}5\).

Ответ: 0,5

3. Повторение (урок 58) Установите соответствие между графиками и формулами: 1) \(y = -x + 2\); 2) \(y = x^2 - 2\); 3) \(y = -\frac{2}{x}\).
РешениеПарабола — есть \(x^2\), гипербола — \(x\) в знаменателе, прямая — \(kx + b\). А → 1, Б → 2, В → 3.

Ответ: 123

4. Повторение (урок 58) Функция задана формулой \(y = -3x + 2\). Найдите \(y\) при \(x = -3\).
Решение\(y = -3\cdot(-3) + 2 = 11\).

Ответ: 11

5. Повторение (урок 56) В треугольнике два угла \(28^\circ\) и \(23^\circ\). Найдите третий.
Решение\(180 - 28 - 23 = 129^\circ\).

Ответ: 129

6. Повторение (урок 56) Вписанный угол равен \(73^\circ\). Найдите центральный угол, опирающийся на ту же дугу.
РешениеЦентральный — в 2 раза больше: \(146^\circ\).

Ответ: 146

7. Повторение (урок 8) Вычислите \(48 : 8\).
РешениеВспоминаем «семейство»: \(8\cdot6 = 48\), значит \(48 : 8 = 6\).

Ответ: 6

8. Повторение (урок 14) Решите уравнение \(x\cdot6 = 114\).
РешениеНеизвестный множитель = произведение : известный множитель: \(x = 114 : 6 = 19\). Проверка: \(6\cdot19 = 114\) ✓.

Ответ: 19

№7 — числовая прямая, сравнение

1. Какое из чисел наибольшее: 1) \(0{,}45\); 2) \(0{,}25\); 3) \(0{,}375\); 4) \(0{,}4\)? В ответ запишите номер.
РешениеПереводим в десятичные: \(0{,}45\); \(0{,}25\); \(0{,}375\); \(0{,}4\). Ответ: 1.

Ответ: 1

2. Между какими соседними целыми числами находится \(\sqrt{73}\)? В ответ запишите меньшее.
Решение\(8^2 = 64 < 73 < 81 = 9^2\), значит \(8 < \sqrt{73} < 9\).

Ответ: 8

3. Какое из чисел наибольшее: 1) \(0{,}65\); 2) \(0{,}45\); 3) \(0{,}5\); 4) \(0{,}6\)? В ответ запишите номер.

№8 — степени, подстановка

Решение\(2^5 = 2\cdot2\cdot2\cdot2\cdot2 = 32\).

Ответ: 32

2. Найдите значение выражения \(3a^2 - b^3\) при \(a = 4\), \(b = 1\).
Решение\(3\cdot16 - 1^3 = 48 - 1 = 47\).

Ответ: 47

3. Вычислите \(10^4\).
Решение\(10^4 = 10\cdot10\cdot10\cdot10 = 10000\).

Ответ: 10000

№9 — уравнения

1. Решите уравнение \(9x + 1x = 100\).
РешениеПриводим подобные: \(10x = 100\); \(x = 100 : 10 = 10\).

Ответ: 10

2. Решите уравнение \(3x - 23 = 22\).
РешениеШаг 1 — неизвестное уменьшаемое: \(3x = 22 + 23 = 45\). Шаг 2 — неизвестный множитель: \(x = 45 : 3 = 15\). Проверка: \(3\cdot15 - 23 = 22\) ✓.

Ответ: 15

3. Решите уравнение \(7x + 5x = 36\).
РешениеПриводим подобные: \(12x = 36\); \(x = 36 : 12 = 3\).

Ответ: 3

№10 — вероятность

1. Из 25 фонариков 5 неисправны. Найдите вероятность того, что случайно выбранный фонарик исправен.
РешениеИсправных 20: \(P = \frac{20}{25} = 0{,}8\).

Ответ: 0,8

2. Бросают игральный кубик. Найдите вероятность того, что выпадет число меньше 4.
РешениеПодходят: 1, 2, 3 — 3 из 6: \(0{,}5\).

Ответ: 0,5

3. Из 1000 фонариков 123 неисправны. Найдите вероятность того, что случайно выбранный фонарик исправен.
РешениеИсправных 877: \(P = \frac{877}{1000} = 0{,}877\).

Ответ: 0,877

№12 — формулы

1. Формула \(C = 150 + 11(t - 5)\) — стоимость поездки на такси \(C\) (руб.) длительностью \(t\) мин. Найдите \(C\), если \(t = 27\).
РешениеПодставляем: \(t = 27\) → \(C = 392\).

Ответ: 392

2. По формуле \(S = vt\) найдите \(t\) (в часах), если \(S = 45\) км, \(v = 9\) км/ч.
Решение\(45 = 9\cdott\) — неизвестный множитель: \(t = 45 : 9 = 5\).

Ответ: 5

3. Формула \(S = vt\) — путь \(S\) (км), скорость \(v\) (км/ч), время \(t\) (ч). Найдите \(S\), если \(v = 7\), \(t = 13\).
РешениеПодставляем: \(v = 7\), \(t = 13\) → \(S = 91\).

Ответ: 91

№13 — неравенства

1. Укажите решение неравенства \(2x + 7 \ge 1\).
1) \((-\infty;\ -3)\)2) \((-3;\ +\infty)\)3) \((-\infty;\ -3]\)4) \([-3;\ +\infty)\)
Решение\(2x \ge -6\), \(x \ge -3\) — точка закрашена, квадратная скобка: вариант 4.

Ответ: 4

2. Решите неравенство \(8x + 2 > 50\). В ответ запишите наименьшее целое решение.
Решение\(8x > 50 - 2 = 48\); \(x > 6\). Наименьшее целое: 7.

Ответ: 7

3. Укажите решение неравенства \(2x + 7 \ge 17\).
1) \((-\infty;\ 5)\)2) \((5;\ +\infty)\)3) \((-\infty;\ 5]\)4) \([5;\ +\infty)\)
Решение\(2x \ge 10\), \(x \ge 5\) — точка закрашена, квадратная скобка: вариант 4.

Ответ: 4

№14 — прогрессия

1. Арифметическая прогрессия: \(a_1 = 7\), \(d = 2\). Найдите \(a_{17}\).
Решение\(a_n = a_1 + (n - 1)d = 7 + 16\cdot2 = 39\).

Ответ: 39

2. В первом ряду кинотеатра 11 мест, а в каждом следующем на 2 больше. Сколько мест в 13-м ряду?
Решение\(a_{13} = 11 + 12\cdot2 = 35\).

Ответ: 35

3. Арифметическая прогрессия: \(a_1 = 18\), \(d = 5\). Найдите \(a_{5}\).
Решение\(a_n = a_1 + (n - 1)d = 18 + 4\cdot5 = 38\).

Ответ: 38

№15 — треугольники

1. Катеты прямоугольного треугольника равны 7 и 24. Найдите гипотенузу.
Решение\(c^2 = 7^2 + 24^2 = 49 + 576 = 625\), \(c = \sqrt{625} = 25\).

Ответ: 25

2. В равнобедренном треугольнике угол при вершине \(146^\circ\). Найдите угол при основании.
РешениеУглы при основании равны: \((180 - 146) : 2 = 17^\circ\).

Ответ: 17

3. В треугольнике два угла \(39^\circ\) и \(37^\circ\). Найдите третий.
Решение\(180 - 39 - 37 = 104^\circ\).

Ответ: 104

№16 — окружность

1. Вписанный угол равен \(68^\circ\). Найдите центральный угол, опирающийся на ту же дугу.
РешениеЦентральный — в 2 раза больше: \(136^\circ\).

Ответ: 136

2. \(AB\) — диаметр окружности, \(C\) — точка на ней, \(\angle CAB = 64^\circ\). Найдите \(\angle CBA\).
РешениеУгол на диаметр \(\angle ACB = 90^\circ\). \(\angle CBA = 90 - 64 = 26^\circ\).

Ответ: 26

3. Центральный угол равен \(198^\circ\). Найдите вписанный угол, опирающийся на ту же дугу.
РешениеВписанный — половина центрального: \(99^\circ\).

Ответ: 99

№17 — четырёхугольники

1. Диагонали ромба 14 и 20. Найдите площадь.
Решение\(S = \frac{d_1d_2}{2} = \frac{14\cdot20}{2} = 140\).

Ответ: 140

2. Один угол параллелограмма \(31^\circ\). Найдите соседний с ним угол.
РешениеСоседние углы в сумме \(180^\circ\): 149°.

Ответ: 149

3. Периметр квадрата 52. Найдите его площадь.
РешениеСторона \(52 : 4 = 13\), \(S = 13^2 = 169\).

Ответ: 169

№18 — клетчатая бумага

1. Найдите площадь треугольника на клетчатой бумаге (клетка \(1\times1\)).
РешениеОснование (по нижней линии) 3, высота 3: \(S = \frac{3\cdot3}{2} = 4{,}5\).

Ответ: 4,5

2. Найдите длину отрезка \(AB\) на клетчатой бумаге (клетка \(1\times1\)).
РешениеДостраиваем прямоугольный треугольник: катеты 6 и 8 клеток. \(AB = \sqrt{36 + 64} = 10\).

Ответ: 10

3. Найдите площадь трапеции на клетчатой бумаге (клетка \(1\times1\)).
РешениеОснования 8 и 4, высота 3: \(S = \frac{8+4}{2}\cdot3 = 18\).

Ответ: 18
