Цель: разобрать ошибки урока 40. Ниже — по 3 задачи-двойника на каждый номер ОГЭ 6–19. Решать только номера с ошибками; номера, решённые верно, — по одной задаче для темпа.

  1. 10 мин — разбор ошибок: «как думал?», найти шаг, где сломалось.
  2. 40 мин — двойники.
  3. 10 мин — по одной задаче из каждого ошибочного номера без подсказок.

Разминка-повторение (12 минут)

1. Повторение (урок 40) В классе 40 учеников: 5 занимаются футболом, 6 — плаванием (каждый одним видом), остальные не занимаются спортом. Найдите вероятность того, что случайный ученик не занимается спортом.
РешениеНе занимаются: \(40 - 5 - 6 = 29\). \(P = \frac{29}{40} = 0{,}725\).

Ответ: 0,725

2. Повторение (урок 40) Решите уравнение \(9x + 7x = 96\).
РешениеПриводим подобные: \(16x = 96\); \(x = 96 : 16 = 6\).

Ответ: 6

3. Повторение (урок 39) В равнобедренном треугольнике угол при вершине \(84^\circ\). Найдите угол при основании.
РешениеУглы при основании равны: \((180 - 84) : 2 = 48^\circ\).

Ответ: 48

4. Повторение (урок 39) Центральный угол равен \(110^\circ\). Найдите вписанный угол, опирающийся на ту же дугу.
РешениеВписанный — половина центрального: \(55^\circ\).

Ответ: 55

5. Повторение (урок 37) Найдите значение выражения \(-0{,}5\cdot(-10)^3 + 3\cdot(-10)^2 - 16\).
Решение\((-10)^3 = -1000\), \((-10)^2 = 100\): \(500 + 300 - 16 = 784\).

Ответ: 784

6. Повторение (урок 37) Найдите значение выражения \(\left(\frac{3}{4} + \frac{1}{2}\right)\cdot10\).
РешениеСкобка: \(1{,}25\); умножаем на 10: \(12{,}5\).

Ответ: 12,5

7. Повторение (урок 8) Вычислите \(30 : 5\).
РешениеВспоминаем «семейство»: \(5\cdot6 = 30\), значит \(30 : 5 = 6\).

Ответ: 6

8. Повторение (урок 14) Решите уравнение \(x : 3 + 8 = 12\).
РешениеШаг 1: \(x : 3 = 12 - 8 = 4\). Шаг 2 — неизвестное делимое: \(x = 4\cdot3 = 12\).

Ответ: 12

№7 — числовая прямая, сравнение

Решение\(9^2 = 81 < 98 < 100 = 10^2\), значит \(9 < \sqrt{98} < 10\).

Ответ: 9

3. Какое из чисел наибольшее: 1) \(0{,}7\); 2) \(0{,}45\); 3) \(0{,}65\); 4) \(0{,}75\)? В ответ запишите номер.

№9 — уравнения

1. Решите уравнение \(3x + (-7) = 6x + (-19)\).
РешениеИксы — влево, числа — вправо (при переносе знак меняется): \(3x - 6x = -19 - (-7)\); \(-3x = -12\); \(x = 4\).

Ответ: 4

2. Решите уравнение \(7x - 18 = 24\).
РешениеШаг 1 — неизвестное уменьшаемое: \(7x = 24 + 18 = 42\). Шаг 2 — неизвестный множитель: \(x = 42 : 7 = 6\). Проверка: \(7\cdot6 - 18 = 24\) ✓.

Ответ: 6

3. Решите уравнение \(4(x - 3) + 8 = -20\).
РешениеРаскрываем скобки: \(4x - 12 + 8 = -20\); \(4x = -20 + 12 - 8 = -16\); \(x = -4\).

Ответ: -4

Ответ: 0,76

2. Бросают игральный кубик. Найдите вероятность того, что выпадет число меньше 4.
РешениеПодходят: 1, 2, 3 — 3 из 6: \(0{,}5\).

Ответ: 0,5

3. Из 100 фонариков 1 неисправны. Найдите вероятность того, что случайно выбранный фонарик исправен.
РешениеИсправных 99: \(P = \frac{99}{100} = 0{,}99\).

Ответ: 0,99

№12 — формулы

1. Формула \(A = Pt\) — работа тока \(A\) (Дж), мощность \(P\) (Вт), время \(t\) (с). Найдите \(A\), если \(P = 15\), \(t = 17\).
РешениеПодставляем: \(P = 15\), \(t = 17\) → \(A = 255\).

Ответ: 255

2. По формуле \(P = 2(a + b)\) найдите \(b\), если \(P = 20\), \(a = 2\).
Решение\(20 = 2(a + b)\) → \(a + b = 10\) → \(b = 10 - 2 = 8\).

Ответ: 8

3. Формула \(C = 150 + 11(t - 5)\) — стоимость поездки на такси \(C\) (руб.) длительностью \(t\) мин. Найдите \(C\), если \(t = 9\).
РешениеПодставляем: \(t = 9\) → \(C = 194\).

Ответ: 194

№13 — неравенства

1. Укажите решение неравенства \(2x + 1 \ge -5\).
1) \((-\infty;\ -3)\)2) \((-3;\ +\infty)\)3) \((-\infty;\ -3]\)4) \([-3;\ +\infty)\)
Решение\(2x \ge -6\), \(x \ge -3\) — точка закрашена, квадратная скобка: вариант 4.

Ответ: 4

2. Решите неравенство \(4x + 0 > 16\). В ответ запишите наименьшее целое решение.
Решение\(4x > 16 - 0 = 16\); \(x > 4\). Наименьшее целое: 5.

Ответ: 5

3. Укажите решение неравенства \(5x + 1 \ge -19\).

Решение\(5x \ge -20\), \(x \ge -4\) — точка закрашена, квадратная скобка: вариант 4.

№14 — прогрессия

1. Арифметическая прогрессия: \(a_1 = 4\), \(d = 3\). Найдите \(a_{5}\).
Решение\(a_n = a_1 + (n - 1)d = 4 + 4\cdot3 = 16\).

Ответ: 16

2. В первом ряду кинотеатра 11 мест, а в каждом следующем на 4 больше. Сколько мест в 12-м ряду?
Решение\(a_{12} = 11 + 11\cdot4 = 55\).

Ответ: 55

3. Арифметическая прогрессия: \(a_1 = 3\), \(d = 5\). Найдите \(a_{15}\).
Решение\(a_n = a_1 + (n - 1)d = 3 + 14\cdot5 = 73\).

Ответ: 73

№15 — треугольники

Решение\(c^2 = 5^2 + 12^2 = 25 + 144 = 169\), \(c = \sqrt{169} = 13\).

Ответ: 13

РешениеУглы при основании равны: \((180 - 42) : 2 = 69^\circ\).

Ответ: 69

3. В треугольнике два угла \(21^\circ\) и \(45^\circ\). Найдите третий.
Решение\(180 - 21 - 45 = 114^\circ\).

Ответ: 114

№16 — окружность

Ответ: 156
