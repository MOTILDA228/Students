Для репетитора: план урока

Цель: №21 на уровне реального экзамена: движение по кругу, средняя скорость, задачи на две неизвестные, проценты с концентрацией. Каждую задачу оформлять полностью.

  1. 5 мин — ДЗ урока 42.
  2. 10 мин — новые сюжеты: средняя скорость, круговая трасса.
  3. 35 мин — практика 1–5.
  4. 10 мин — итог, ДЗ.

Шпаргалка

Средняя скорость = весь путь : всё время (не среднее арифметическое скоростей!).
По кругу: первый догоняет второго, когда проезжает на целый круг больше. Скорость сближения — разность скоростей.
Оформление: «Пусть \(x\) км/ч — …», уравнение с пояснением, решение, отбор корней, ответ с единицами.

Практика на уроке

1. Прототип ОГЭ №21 (ФИПИ / Решу ОГЭ)
Первую половину пути автомобиль ехал со скоростью 60 км/ч, а вторую — 90 км/ч. Найдите среднюю скорость на всём пути.
РешениеПуть \(2s\): время \(\frac{s}{60} + \frac{s}{90} = \frac{5s}{180} = \frac{s}{36}\). \(v = 2s : \frac{s}{36} = 72\) км/ч.

Ответ: 72

2. Прототип ОГЭ №21 (ФИПИ / Решу ОГЭ)
Из одной точки круговой трассы длиной 12 км одновременно в одном направлении стартовали два автомобиля со скоростями 100 и 80 км/ч. Через сколько минут первый впервые опередит второго на один круг?
РешениеСближение 20 км/ч, 12 км → \(0{,}6\) ч = 36 мин.

Ответ: 36

3. Прототип ОГЭ №21 (ФИПИ / Решу ОГЭ)
Смешали 30%-й и 60%-й растворы кислоты и добавили 10 кг воды, получили 36%-й раствор. Если бы вместо воды добавили 10 кг 50%-го раствора, получили бы 41%-й раствор. Сколько килограммов 30%-го раствора использовали?
Решение\(x\), \(y\) — массы. \(0{,}3x + 0{,}6y = 0{,}36(x + y + 10)\); \(0{,}3x + 0{,}6y + 5 = 0{,}41(x + y + 10)\). Вычтем: \(5 = 0{,}05(x + y + 10)\) → \(x + y = 90\). Первое: \(0{,}3x + 0{,}6y = 36\) → \(x + 2y = 120\) → \(y = 30\), \(x = 60\).

Ответ: 60

4. Прототип ОГЭ №21 (ФИПИ / Решу ОГЭ)
Два велосипедиста одновременно отправились в пробег на 208 км. Первый ехал со скоростью на 3 км/ч большей и прибыл на 3 часа раньше. Найдите скорость второго велосипедиста.
Решение\(\frac{208}{x} - \frac{208}{x + 3} = 3\) → \(624 = 3x(x + 3)\) → \(x^2 + 3x - 208 = 0\), \(D = 841\), \(x = 13\).

Ответ: 13

5. Прототип ОГЭ №21 (для «5»)
Баржа прошла по течению 40 км и, повернув обратно, прошла ещё 30 км, затратив на весь путь 5 часов. Найдите собственную скорость баржи, если скорость течения 5 км/ч.
Решение\(\frac{40}{x + 5} + \frac{30}{x - 5} = 5\) → \(40(x - 5) + 30(x + 5) = 5(x^2 - 25)\) → \(70x - 50 = 5x^2 - 125\) → \(x^2 - 14x - 15 = 0\), \(x = 15\).

Ответ: 15

Домашнее задание

1. Прототип ОГЭ №21
Первую треть пути автомобиль ехал со скоростью 60 км/ч, вторую — 120 км/ч, третью — 110 км/ч. Найдите среднюю скорость. Ответ округлите до целых.
Решение\(\frac{3}{\frac{1}{60} + \frac{1}{120} + \frac{1}{110}} = \frac{3}{\frac{22 + 11 + 12}{1320}} = \frac{3960}{45} = 88\).

Ответ: 88

2. Прототип ОГЭ №21
Из одной точки круговой трассы длиной 15 км стартовали два мотоцикла со скоростями 110 и 80 км/ч. Через сколько минут первый опередит второго на один круг?
Решение\(\frac{15}{30} = 0{,}5\) ч = 30 мин.

Ответ: 30

3. Прототип ОГЭ №21
Теплоход проходит по течению до пункта назначения 255 км и после стоянки возвращается. Скорость течения 1 км/ч, стоянка 2 часа, в исходный пункт он вернулся через 34 часа после отплытия. Найдите скорость теплохода в неподвижной воде.
Решение\(\frac{255}{x + 1} + \frac{255}{x - 1} = 32\) → \(510x = 32(x^2 - 1)\) → \(16x^2 - 255x - 16 = 0\), \(D = 65025 + 1024 = 66049 = 257^2\), \(x = \frac{255 + 257}{32} = 16\).

Ответ: 16

4. Прототип ОГЭ №21
Имеется два сосуда с кислотой: 30 кг и 20 кг. Если их слить, получится 68%-й раствор. Если слить равные массы, получится 70%-й. Сколько килограммов кислоты в первом сосуде?
Решение\(a\), \(b\) — концентрации (доли). \(30a + 20b = 34\); \(a + b = 1{,}4\). \(30a + 20(1{,}4 - a) = 34\) → \(10a = 6\), \(a = 0{,}6\). Кислоты \(18\) кг.

Ответ: 18
