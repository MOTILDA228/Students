Для репетитора: план урока

Цель: тригонометрия прямоугольного треугольника, табличные значения, основное тригонометрическое тождество. Для «5» — площадь через синус и теорема косинусов (понадобятся в №23).

  1. 5 мин — проверка ДЗ урока 18.
  2. 15 мин — определения на чертеже, таблица 30°/45°/60°.
  3. 30 мин — практика 1–7.
  4. 10 мин — итог, ДЗ.

Шпаргалка

\(\sin A = \frac{\text{противолежащий}}{\text{гипотенуза}}\), \(\cos A = \frac{\text{прилежащий}}{\text{гипотенуза}}\), \(\operatorname{tg} A = \frac{\text{противолежащий}}{\text{прилежащий}}\). \(\sin^2 A + \cos^2 A = 1\).

Для «5»: \(S = \frac{1}{2}ab\sin C\); теорема косинусов \(c^2 = a^2 + b^2 - 2ab\cos C\).

Практика на уроке

1. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) \(\angle C = 90^\circ\), \(AB = 25\), \(\sin A = 0{,}28\). Найдите \(BC\).
Решение\(BC = AB\sin A = 7\).

Ответ: 7

2. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) \(\angle C = 90^\circ\), \(AC = 12\), \(\operatorname{tg} A = 0{,}75\). Найдите \(AB\).
Решение\(BC = 9\), \(AB = 15\).

Ответ: 15

3. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) \(\angle C = 90^\circ\), \(\cos A = \frac{\sqrt{91}}{10}\). Найдите \(\sin A\).
Решение\(\sin^2 A = 1 - 0{,}91 = 0{,}09\), \(\sin A = 0{,}3\).

Ответ: 0,3

4. Прототип ОГЭ №15
В треугольнике \(ABC\) \(\angle C = 90^\circ\), \(\angle A = 60^\circ\), \(AC = 4\sqrt{3}\). Найдите \(BC\).
Решение\(BC = AC\cdot\operatorname{tg}60^\circ = 4\sqrt{3}\cdot\sqrt{3} = 12\).

Ответ: 12

5. Прототип ОГЭ №18 (ФИПИ / Решу ОГЭ)
Найдите тангенс угла \(AOB\), изображённого на клетчатой бумаге.
РешениеОпустим из \(B\) перпендикуляр на \(OA\): противолежащий катет 4 клетки, прилежащий 2. \(\operatorname{tg} = \frac{4}{2} = 2\).

Ответ: 2

6. Прототип ОГЭ №17 (ФИПИ / Решу ОГЭ)
Найдите площадь параллелограмма со сторонами 8 и 10 и углом \(30^\circ\).
Решение\(S = ab\sin\alpha = 80\cdot\frac{1}{2} = 40\).

Ответ: 40

7. Для «5»: подготовка к №23
В треугольнике две стороны 5 и 8, угол между ними \(60^\circ\). Найдите третью сторону.
Решение\(c^2 = 25 + 64 - 2\cdot5\cdot8\cdot\frac{1}{2} = 49\), \(c = 7\).

Ответ: 7

Домашнее задание

1. Прототип ОГЭ №15
В треугольнике \(ABC\) \(\angle C = 90^\circ\), \(AB = 40\), \(\cos A = 0{,}8\). Найдите \(AC\).
Решение\(32\).

Ответ: 32

2. Прототип ОГЭ №15
В треугольнике \(ABC\) \(\angle C = 90^\circ\), \(BC = 10\), \(\operatorname{tg} A = 2{,}5\). Найдите \(AC\).
Решение\(AC = \frac{BC}{\operatorname{tg} A} = 4\).

Ответ: 4

3. Прототип ОГЭ №15
\(\sin A = \frac{2\sqrt{6}}{5}\) (угол острый). Найдите \(\cos A\).
Решение\(1 - \frac{24}{25} = \frac{1}{25}\), \(\cos A = 0{,}2\).

Ответ: 0,2

4. Прототип ОГЭ №15
В треугольнике \(ABC\) \(\angle C = 90^\circ\), \(\angle B = 30^\circ\), \(AB = 16\). Найдите \(BC\), делённое на \(\sqrt{3}\).
Решение\(BC = 16\cos30^\circ = 8\sqrt{3}\); делённое на \(\sqrt{3}\) — 8.

Ответ: 8

5. Прототип ОГЭ №17
Найдите площадь треугольника со сторонами 12 и 9 и углом \(150^\circ\) между ними.
Решение\(\sin150^\circ = \frac{1}{2}\): \(\frac{1}{2}\cdot12\cdot9\cdot\frac{1}{2} = 27\).

Ответ: 27

6. Повторение (урок 17) Сколько целых решений имеет система \(\begin{cases} 4x + 3 \ge -9 \\ 2 - x > -2 \end{cases}\)?
Решение\(x \ge -3\), \(x < 4\): 7.

Ответ: 7

7. Повторение (урок 15) Решите уравнение \((x^2 + 2x)^2 - 2(x^2 + 2x) - 3 = 0\). Запишите сумму корней.
Решение\(t = 3\): \(x = 1, -3\); \(t = -1\): \(x = -1\). Сумма \(-3\).

Ответ: -3

8. Повторение (урок 11) Найдите значение выражения \(\sqrt{\frac{50a^{10}}{2a^{8}}}\) при \(a = 3\).
Решение\(5a = 15\).

Ответ: 15
