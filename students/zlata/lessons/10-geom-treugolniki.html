Для репетитора: план урока

Цель: сумма углов, внешний угол, равнобедренный треугольник, медиана/биссектриса/высота. Это самая частая база №15. Используем параллельные прямые из урока 7.

  1. 5 мин — проверка ДЗ урока 9.
  2. 15 мин — теория: доказать сумму углов через параллельную прямую (Злате понравится), затем факты.
  3. 30 мин — практика 1–7.
  4. 10 мин — итог, ДЗ.

Типичные ошибки: путают основание и боковую сторону; забывают, что внешний угол = сумма двух не смежных с ним.

Шпаргалка

Сумма углов треугольника \(180^\circ\). Внешний угол равен сумме двух внутренних, не смежных с ним.
Равнобедренный (\(AB = BC\)): углы при основании равны; медиана к основанию — она же высота и биссектриса.
Медиана — в середину стороны; биссектриса делит угол пополам; высота — перпендикуляр к стороне (или её продолжению).
Против большей стороны лежит больший угол. В равностороннем треугольнике все углы по \(60^\circ\).

Практика на уроке

1. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) \(AB = BC\), внешний угол при вершине \(C\) равен \(123^\circ\). Найдите угол \(B\).
Решение\(\angle C = 57^\circ = \angle A\). \(\angle B = 180 - 114 = 66^\circ\).

Ответ: 66

2. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) \(\angle A = 44^\circ\), \(\angle C = 62^\circ\), \(BD\) — биссектриса. Найдите угол \(ADB\).
Решение\(\angle B = 74^\circ\), \(\angle ABD = 37^\circ\). В треугольнике \(ABD\): \(\angle ADB = 180 - 44 - 37 = 99^\circ\).

Ответ: 99

3. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) \(AB = BC\), \(BM\) — медиана, \(\angle ABC = 82^\circ\). Найдите угол \(ABM\).
РешениеМедиана к основанию — биссектриса: \(41^\circ\).

Ответ: 41

4. Прототип ОГЭ №15
Углы треугольника относятся как \(2 : 3 : 7\). Найдите больший угол.
Решение\(12x = 180\), \(x = 15\); \(7x = 105^\circ\).

Ответ: 105

5. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) \(\angle C = 90^\circ\), \(CH\) — высота, \(\angle A = 34^\circ\). Найдите угол \(BCH\).
Решение\(\angle B = 56^\circ\), в треугольнике \(BCH\): \(\angle BCH = 90 - 56 = 34^\circ\).

Ответ: 34

6. Прототип ОГЭ №15 (для «5»)
В треугольнике \(ABC\) \(\angle A = 70^\circ\), \(\angle C = 50^\circ\). Биссектрисы углов \(A\) и \(C\) пересекаются в точке \(O\). Найдите угол \(AOC\).
Решение\(\angle OAC = 35^\circ\), \(\angle OCA = 25^\circ\), \(\angle AOC = 180 - 60 = 120^\circ\).

Ответ: 120

7. Прототип ОГЭ №19 (ФИПИ / Решу ОГЭ)
Какие из утверждений верны?
1) Внешний угол треугольника равен сумме двух его внутренних углов, не смежных с ним.
2) В тупоугольном треугольнике все углы тупые.
3) Медиана равнобедренного треугольника, проведённая к основанию, является его высотой.
Решение1 — верно. 2 — неверно (тупой только один). 3 — верно.

Ответ: 13

Домашнее задание

1. Прототип ОГЭ №15
В треугольнике \(ABC\) \(AC = BC\), \(\angle C = 38^\circ\). Найдите внешний угол при вершине \(B\).
Решение\(\angle B = 71^\circ\), внешний — \(109^\circ\).

Ответ: 109

2. Прототип ОГЭ №15
В треугольнике \(ABC\) \(\angle A = 52^\circ\), \(\angle B = 76^\circ\), \(CD\) — биссектриса. Найдите угол \(BDC\).
Решение\(\angle C = 52^\circ\), \(\angle BCD = 26^\circ\), \(\angle BDC = 180 - 76 - 26 = 78^\circ\).

Ответ: 78

3. Прототип ОГЭ №15
Один из углов равнобедренного треугольника равен \(112^\circ\). Найдите один из других его углов.
Решение\(112^\circ\) может быть только при вершине: \((180 - 112) : 2 = 34^\circ\).

Ответ: 34

4. Прототип ОГЭ №15
В прямоугольном треугольнике один из острых углов на \(18^\circ\) больше другого. Найдите больший острый угол.
Решение\(2x + 18 = 90\), \(x = 36\), больший — \(54^\circ\).

Ответ: 54

5. Прототип ОГЭ №19
Какие из утверждений верны? 1) Если два угла треугольника равны, то треугольник равнобедренный. 2) Сумма острых углов прямоугольного треугольника равна \(90^\circ\). 3) Биссектриса треугольника делит противоположную сторону пополам.
Решение1 — верно. 2 — верно. 3 — неверно (это медиана).

Ответ: 12

6. Повторение (урок 8) Найдите значение выражения \(\frac{61^2 - 39^2}{44}\).
Решение\(\frac{22\cdot100}{44} = 50\).

Ответ: 50

7. Повторение (урок 6) Найдите значение выражения \(\frac{10}{\sqrt{6} - 1} - 2\sqrt{6}\).
Решение\(\frac{10(\sqrt{6} + 1)}{5} = 2\sqrt{6} + 2\) → 2.

Ответ: 2
