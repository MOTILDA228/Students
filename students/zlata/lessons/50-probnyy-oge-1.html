Для репетитора: план урока

Цель: первый полный вариант. На экзамене 3 ч 55 мин, урок длится 60 минут, поэтому:

  1. На уроке (60 мин): часть 1, задания 1–19, строго по времени.
  2. Дома (≈ 1,5 ч, одним подходом, без подсказок): часть 2, задания 20–25, оформить на листах.
  3. Разбор — урок 51.

Перевод в оценку (ориентир ФИПИ): 0–7 — «2»; 8–14 — «3»; 15–21 — «4»; 22–31 — «5». Для «4» и «5» нужно не меньше 2 баллов за геометрию (№15–19, 23–25). Записать баллы по номерам в progress.md и в журнал.

Инструкция

Часть 1 (№1–19) — только ответ. Часть 2 (№20–25) — полное решение. Порядок: №6–14 → №15–19 → №1–5 → часть 2 (№20, 21, 22, 23, 24, затем 25).

Условие к заданиям 1–5

Листы бумаги формата A имеют стандартные размеры (в миллиметрах). Каждый следующий формат получается делением предыдущего пополам по длинной стороне.

ФорматA2A3A4A5
Размеры, мм420 × 594297 × 420210 × 297148 × 210

Плотность офисной бумаги — 80 г/м² (столько весит 1 м² бумаги).

Сколько листов формата A5 получится из одного листа формата A2?

Ответ: 8

Часть 2

1. ОГЭ №20 (2 балла)
Решите уравнение \(x^3 + 5x^2 - 4x - 20 = 0\).
Решение\(x^2(x + 5) - 4(x + 5) = (x + 5)(x - 2)(x + 2) = 0\). Ответ: \(-5;\ -2;\ 2\). (Для проверки: сумма корней \(-5\).)

Ответ: \(-5\); \(-2\); 2

2. ОГЭ №21 (2 балла)
Моторная лодка прошла против течения 112 км и вернулась, затратив на обратный путь на 6 часов меньше. Скорость лодки в неподвижной воде 11 км/ч. Найдите скорость течения.
Решение\(\frac{112}{11 - x} - \frac{112}{11 + x} = 6\) → \(224x = 6(121 - x^2)\) → \(3x^2 + 112x - 363 = 0\), \(D = 12544 + 4356 = 16900\), \(x = \frac{-112 + 130}{6} = 3\). Ответ: 3 км/ч.

Ответ: 3

3. ОГЭ №22 (2 балла)
Постройте график \(y = \frac{(x^2 + 4)(x - 1)}{1 - x}\). При каких \(k\) прямая \(y = kx\) имеет с графиком ровно одну общую точку?
Решение\(x \ne 1\): \(y = -x^2 - 4\), выколота \((1;\ -5)\). Прямая \(y = kx\): \(-x^2 - 4 = kx\) → \(x^2 + kx + 4 = 0\). Одна точка: \(D = 0\) → \(k = \pm4\); или два корня, один из которых \(x = 1\): \(1 + k + 4 = 0\), \(k = -5\) (второй корень \(x = 4\)). Ответ: \(-5;\ -4;\ 4\).

Ответ: \(-5\); \(-4\); 4

4. ОГЭ №23 (2 балла)

РешениеГипотенуза 20, \(h = \frac{12\cdot16}{20} = 9{,}6\).

Ответ: 9,6

5. ОГЭ №24 (2 балла)
В параллелограмме \(ABCD\) точки \(M\) и \(N\) — середины сторон \(BC\) и \(AD\). Докажите, что \(ABMN\) — параллелограмм.
Решение\(BM = \frac{1}{2}BC = \frac{1}{2}AD = AN\), и \(BM \parallel AN\) (лежат на параллельных сторонах). Четырёхугольник, у которого две стороны равны и параллельны, — параллелограмм.

Ответ: доказательство

Решение\(k = 3\): \(S_{AOD} = 45\), боковые — по \(\sqrt{5\cdot45} = 15\). \(S = 5 + 45 + 30 = 80\).
