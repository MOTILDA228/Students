Для репетитора: план урока

Цель: теорема Пифагора, катет против \(30^\circ\), медиана к гипотенузе. Это инструменты для половины задач №15–17.

  1. 5 мин — проверка ДЗ урока 12.
  2. 10 мин — теория + «пифагоровы тройки» наизусть.
  3. 35 мин — практика 1–7.
  4. 10 мин — итог, ДЗ.

Шпаргалка

Пифагор: \(c^2 = a^2 + b^2\). Тройки: 3–4–5, 5–12–13, 8–15–17, 7–24–25 (и кратные: 6–8–10, 9–12–15…).
Катет против угла \(30^\circ\) равен половине гипотенузы. Медиана, проведённая к гипотенузе, равна её половине.
Если \(\angle A = 30^\circ\) и \(AB = 14\), то \(BC = 7\), \(AC = \sqrt{196 - 49} = 7\sqrt{3}\).

Практика на уроке

1. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
Катеты прямоугольного треугольника равны 20 и 21. Найдите гипотенузу.
Решение\(\sqrt{400 + 441} = \sqrt{841} = 29\).

Ответ: 29

2. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В прямоугольном треугольнике гипотенуза 34, один катет 16. Найдите другой катет.
Решение\(\sqrt{1156 - 256} = 30\).

Ответ: 30

3. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) \(\angle C = 90^\circ\), \(\angle A = 30^\circ\), \(AB = 2\sqrt{3}\). Найдите \(AC\).
Решение\(BC = \sqrt{3}\), \(AC = \sqrt{12 - 3} = 3\).

Ответ: 3

4. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В равнобедренном треугольнике боковая сторона 25, основание 48. Найдите высоту, проведённую к основанию.
РешениеВысота делит основание пополам: \(\sqrt{625 - 576} = 7\).

Ответ: 7

5. Прототип ОГЭ №17 (ФИПИ / Решу ОГЭ)
Сторона ромба равна 10, одна из диагоналей 16. Найдите другую диагональ.
РешениеДиагонали ромба перпендикулярны и делятся пополам: половина второй \(\sqrt{100 - 64} = 6\), диагональ 12.

Ответ: 12

6. Прототип ОГЭ №15
Катеты прямоугольного треугольника 18 и 24. Найдите медиану, проведённую к гипотенузе.
РешениеГипотенуза 30, медиана 15.

Ответ: 15

7. Прототип ОГЭ №15 (для «5»)
В прямоугольном треугольнике один катет на 7 меньше гипотенузы, другой равен 21. Найдите гипотенузу.
Решение\(c^2 = (c - 7)^2 + 441\) → \(14c = 490\), \(c = 35\).

Ответ: 35

Домашнее задание

1. Прототип ОГЭ №15
Катеты 12 и 35. Найдите гипотенузу.
Решение\(\sqrt{144 + 1225} = 37\).

Ответ: 37

2. Прототип ОГЭ №15
В треугольнике \(ABC\) \(\angle C = 90^\circ\), \(\angle B = 30^\circ\), \(AC = 9\). Найдите \(AB\).
Решение\(AC\) лежит против \(30^\circ\): \(AB = 18\).

Ответ: 18

3. Прототип ОГЭ №15
Равнобедренный треугольник: основание 30, высота к основанию 8. Найдите боковую сторону.
Решение\(\sqrt{225 + 64} = 17\).

Ответ: 17

4. Прототип ОГЭ №17
Диагонали ромба равны 18 и 80. Найдите сторону ромба.
Решение\(\sqrt{81 + 1600} = 41\).

Ответ: 41

5. Прототип ОГЭ №17
Сторона прямоугольника 20, диагональ 29. Найдите площадь прямоугольника.
РешениеВторая сторона 21, площадь 420.

Ответ: 420

6. Повторение (урок 11) Сила тока \(I = \frac{U}{R}\). Найдите \(R\) (в омах), если \(U = 220\) В, \(I = 8\) А.
Решение\(220 : 8 = 27{,}5\).

Ответ: 27,5

7. Повторение (урок 9) Найдите значение выражения \(\frac{x^2 - 49}{x^2 - 7x}\) при \(x = 14\).
Решение\(\frac{x + 7}{x} = \frac{21}{14} = 1{,}5\).

Ответ: 1,5

8. Повторение (урок 5) Цену повысили на 30%, потом снизили на 30%. На сколько процентов она изменилась? (Ответ со знаком минус, если уменьшилась.)
Решение\(1{,}3\cdot0{,}7 = 0{,}91\) → \(-9\%\).

Ответ: -9
