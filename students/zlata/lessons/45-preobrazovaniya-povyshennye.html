Для репетитора: план урока

Цель: третий тип №20 — сократить дробь, упростить выражение с корнями или степенями и найти значение. Нужно всё из уроков 6, 8, 9 на уровне «без ошибок».

  1. 5 мин — ДЗ урока 44.
  2. 5 мин — приёмы.
  3. 40 мин — практика 1–6.
  4. 10 мин — итог, ДЗ.

Шпаргалка

Степени: разложить основания на простые: \(\frac{12^n}{3^{n - 1}\cdot2^{2n + 1}} = \frac{2^{2n}3^n}{3^{n - 1}2^{2n + 1}} = \frac{3}{2}\).
Корни: \(\sqrt{a \pm 2\sqrt{b}}\) — ищем полный квадрат: \(7 - 4\sqrt{3} = (2 - \sqrt{3})^2\).
Дроби: разложить на множители всё, что можно, прежде чем складывать.

Практика на уроке

1. Прототип ОГЭ №20 (ФИПИ / Решу ОГЭ)
Сократите дробь \(\frac{20^n}{5^{n - 2}\cdot2^{2n + 1}}\).
Решение\(\frac{2^{2n}5^n}{5^{n - 2}2^{2n + 1}} = \frac{5^2}{2} = 12{,}5\).

Ответ: 12,5

2. Прототип ОГЭ №20 (ФИПИ / Решу ОГЭ)
Сократите дробь \(\frac{18^{n + 3}}{3^{2n + 5}\cdot2^{n - 2}}\).
Решение\(\frac{3^{2n + 6}2^{n + 3}}{3^{2n + 5}2^{n - 2}} = 3\cdot2^5 = 96\).

Ответ: 96

3. Прототип ОГЭ №20 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\sqrt{(2 - \sqrt{5})^2} + \sqrt{(3 - \sqrt{5})^2}\).
Решение\(\sqrt{5} - 2 + 3 - \sqrt{5} = 1\).

Ответ: 1

4. Прототип ОГЭ №20
Найдите значение выражения \(\sqrt{7 - 4\sqrt{3}} + \sqrt{3}\).
Решение\(|2 - \sqrt{3}| + \sqrt{3} = 2\).

Ответ: 2

5. Прототип ОГЭ №20 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{a^2 - 9}{a^2 + 6a + 9}\cdot\frac{a + 3}{a^2 - 3a} - \frac{1}{a}\) при любом допустимом \(a\).
Решение\(\frac{(a - 3)(a + 3)}{(a + 3)^2}\cdot\frac{a + 3}{a(a - 3)} - \frac{1}{a} = \frac{1}{a} - \frac{1}{a} = 0\).

Ответ: 0

6. Для «5»
Найдите значение выражения \(\frac{1}{\sqrt{2} + 1} + \frac{1}{\sqrt{3} + \sqrt{2}} + \frac{1}{2 + \sqrt{3}}\).
РешениеКаждая дробь: \(\frac{1}{\sqrt{k + 1} + \sqrt{k}} = \sqrt{k + 1} - \sqrt{k}\). Сумма «телескопическая»: \(2 - 1 = 1\).

Ответ: 1

Домашнее задание

1. Прототип ОГЭ №20
Сократите дробь \(\frac{45^n}{3^{2n - 1}\cdot5^{n - 2}}\).
Решение\(\frac{3^{2n}5^n}{3^{2n - 1}5^{n - 2}} = 3\cdot25 = 75\).

Ответ: 75

2. Прототип ОГЭ №20
Сократите дробь \(\frac{6^{n + 1}}{2^{n - 1}\cdot3^{n + 2}}\).
Решение\(\frac{2^{n + 1}3^{n + 1}}{2^{n - 1}3^{n + 2}} = \frac{4}{3}\).

Ответ: \(\frac{4}{3}\)

3. Прототип ОГЭ №20
Найдите значение \(\sqrt{(4 - \sqrt{17})^2} + \sqrt{(5 - \sqrt{17})^2}\).
Решение\(\sqrt{17} - 4 + 5 - \sqrt{17} = 1\).

Ответ: 1

4. Прототип ОГЭ №20
Найдите значение \(\sqrt{11 + 6\sqrt{2}} - \sqrt{2}\).
Решение\(11 + 6\sqrt{2} = (3 + \sqrt{2})^2\). Ответ 3.

Ответ: 3

5. Повторение (урок 44) Докажите, что диагонали ромба перпендикулярны.
Решение\(AB = AD\) (стороны ромба), \(BO = OD\) (диагонали параллелограмма делятся пополам) ⇒ \(AO\) — медиана равнобедренного треугольника \(ABD\) к основанию, значит, и высота: \(AC \perp BD\).

Ответ: доказательство

6. Повторение (урок 43) Первую половину пути велосипедист ехал со скоростью 12 км/ч, вторую — 18 км/ч. Найдите среднюю скорость.
Решение\(\frac{2}{\frac{1}{12} + \frac{1}{18}} = 14{,}4\).

Ответ: 14,4

7. Повторение (урок 41) Катеты 9 и 12. Найдите высоту, проведённую к гипотенузе.
Решение\(\frac{108}{15} = 7{,}2\).

Ответ: 7,2
