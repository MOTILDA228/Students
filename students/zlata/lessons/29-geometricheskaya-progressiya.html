Цель: формулы геометрической прогрессии и сюжеты №14 (бактерии, скидки, размножение), различать арифметическую и геометрическую по тексту.

  1. 5 мин — проверка ДЗ урока 28.
  2. 10 мин — формулы, «как узнать тип прогрессии».
  3. 35 мин — практика 1–7.
  4. 10 мин — итог, ДЗ.

Шпаргалка

\(b_n = b_1q^{n - 1}\) · \(S_n = \frac{b_1(q^n - 1)}{q - 1}\) (\(q \ne 1\))
Тип по тексту: «на столько-то больше» — арифметическая; «в столько-то раз» — геометрическая.
Знаки при отрицательном \(q\) чередуются: \(b_1 = 2\), \(q = -3\): \(2;\ -6;\ 18;\ -54\).

Практика на уроке

1. Прототип ОГЭ №14
\(b_1 = 3\), \(q = 2\). Найдите \(b_7\).
Решение\(3\cdot64 = 192\).

Ответ: 192

2. Прототип ОГЭ №14
\(b_1 = -64\), \(q = -\frac{1}{2}\). Найдите \(b_6\).
Решение\(-64\cdot\left(-\frac{1}{32}\right) = 2\).

Ответ: 2

3. Прототип ОГЭ №14
Найдите сумму первых 6 членов прогрессии \(1;\ 3;\ 9;\ \ldots\)
Решение\(\frac{3^6 - 1}{2} = 364\).

Ответ: 364

4. Прототип ОГЭ №14 (ФИПИ / Решу ОГЭ)
Колония бактерий удваивается каждые 20 минут. Сейчас в ней 500 бактерий. Сколько их будет через 2 часа?
Решение6 удвоений: \(500\cdot64 = 32\,000\).

Ответ: 32000

5. Прототип ОГЭ №14
В геометрической прогрессии \(b_2 = 6\), \(b_5 = 162\). Найдите \(b_1\).
Решение\(q^3 = 27\), \(q = 3\), \(b_1 = 2\).

Ответ: 2

6. Прототип ОГЭ №14 (ФИПИ / Решу ОГЭ)
Каждый месяц цена товара снижается на 10%. Изначально он стоил 10 000 руб. Сколько он будет стоить через 3 месяца?
Решение\(10\,000\cdot0{,}9^3 = 7290\).

Ответ: 7290

7. Для «5»
В геометрической прогрессии с положительными членами \(b_1 + b_2 = 12\), \(b_2 + b_3 = 36\). Найдите \(b_4\).
Решение\(q = \frac{36}{12} = 3\), \(b_1(1 + 3) = 12\), \(b_1 = 3\), \(b_4 = 81\).

Ответ: 81

4. Прототип ОГЭ №14
Вирусом в первый день заразились 3 компьютера, каждый день число новых заражённых утраивается. Сколько компьютеров заражено за 5 дней?
Решение\(3 + 9 + 27 + 81 + 243 = 363\).

Ответ: 363

5. Прототип ОГЭ №14
Врач прописал капли: в первый день 3 капли, каждый следующий — на 2 больше, до 21 капли в день. Сколько дней пьют капли по этой схеме?
РешениеАрифметическая: \(3 + 2(n - 1) = 21\), \(n = 10\).

Ответ: 10
