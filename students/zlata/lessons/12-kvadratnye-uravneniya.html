Цель: линейные уравнения Злата решает — быстро повторяем и уходим в квадратные: дискриминант, неполные, теорема Виета, уравнения, сводящиеся к квадратным.

  1. 5 мин — проверка ДЗ урока 11.
  2. 10 мин — шпаргалка: формула корней, неполные, Виета.
  3. 35 мин — практика 1–7.
  4. 10 мин — итог, ДЗ.

Типичные ошибки: в неполном \(x^2 = 5x\) делят на \(x\) и теряют корень 0; ошибаются в знаке \(-b\).

Шпаргалка

\(ax^2 + bx + c = 0\): \(D = b^2 - 4ac\); \(x = \frac{-b \pm \sqrt{D}}{2a}\). \(D < 0\) — корней нет, \(D = 0\) — один корень.
Виета (для \(x^2 + px + q = 0\)): \(x_1 + x_2 = -p\), \(x_1x_2 = q\). Удобно подбирать корни и проверять себя.
Неполные: \(ax^2 + bx = 0\) → \(x(ax + b) = 0\); \(ax^2 + c = 0\) → \(x^2 = -\frac{c}{a}\).
Никогда не делить обе части на выражение с \(x\) — теряются корни. Выносить за скобку!

Практика на уроке

1. Прототип ОГЭ №9 (ФИПИ / Решу ОГЭ)
Решите уравнение \(4(x - 3) - 2(2x + 1) = 5x - 9\).
Решение\(4x - 12 - 4x - 2 = 5x - 9\) → \(-14 = 5x - 9\) → \(x = -1\).

Ответ: -1

2. Прототип ОГЭ №9 (ФИПИ / Решу ОГЭ)
Решите уравнение \(x^2 - 11x + 24 = 0\). Если корней несколько, запишите меньший.
РешениеПо Виета: 3 и 8. Меньший 3.

Ответ: 3

3. Прототип ОГЭ №9 (ФИПИ / Решу ОГЭ)
Решите уравнение \(3x^2 = 12x\). Если корней несколько, запишите больший.
Решение\(3x(x - 4) = 0\): 0 и 4.

Ответ: 4

4. Прототип ОГЭ №9 (ФИПИ / Решу ОГЭ)
Решите уравнение \(5x^2 + 9x - 2 = 0\). Если корней несколько, запишите больший.
Решение\(D = 81 + 40 = 121\), \(x = \frac{-9 \pm 11}{10}\): \(0{,}2\) и \(-2\).

Ответ: 0,2

5. Прототип ОГЭ №9
Решите уравнение \((x + 4)^2 = (x - 6)^2\).
Решение\(8x + 16 = -12x + 36\) → \(20x = 20\), \(x = 1\).

Ответ: 1

6. Виета
Один из корней уравнения \(x^2 + px - 18 = 0\) равен 2. Найдите \(p\).
Решение\(x_1x_2 = -18\) → второй корень \(-9\). \(p = -(2 - 9) = 7\).

Ответ: 7

7. Прототип ОГЭ №20 (часть 2)
Решите уравнение \(x^4 - 7x^2 - 18 = 0\). В ответ запишите произведение корней.
Решение\(t = x^2 \ge 0\): \(t^2 - 7t - 18 = 0\), \(t = 9\) или \(t = -2\) (не подходит). \(x = \pm3\), произведение \(-9\).

Ответ: -9

4. Прототип ОГЭ №9
Решите уравнение \(6x^2 - x - 1 = 0\). Запишите больший корень.
Решение\(D = 25\), \(x = \frac{1 \pm 5}{12}\): \(0{,}5\) и \(-\frac{1}{3}\).

Ответ: 0,5

5. Прототип ОГЭ №20 (часть 2)
Решите уравнение \(x^4 - 13x^2 + 36 = 0\). Запишите сумму положительных корней.
Решение\(t = 4\) или \(t = 9\): \(x = \pm2, \pm3\). Сумма положительных 5.

Ответ: 5

6. Повторение (урок 10) В треугольнике \(ABC\) \(AB = BC\), \(\angle B = 46^\circ\). Найдите угол \(A\).
Решение\((180 - 46) : 2 = 67^\circ\).

Ответ: 67

7. Повторение (урок 8) Решите уравнение \(x^3 - 2x^2 - 25x + 50 = 0\). Запишите сумму корней.
Решение\((x - 2)(x^2 - 25)\): 2, 5, \(-5\). Сумма 2.

Ответ: 2
