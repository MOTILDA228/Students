Для репетитора: план урока

Цель: закрепить преобразования (уроки 5–9) в формате №8 и научиться работать с формулами №12: подставить и выразить нужную величину.

  1. 5 мин — проверка ДЗ урока 10.
  2. 5 мин — два правила №12: единицы измерения и «выразить, потом подставить».
  3. 40 мин — практика 1–7.
  4. 10 мин — итог, ДЗ.

Шпаргалка

№8 «упростите и найдите значение»: сначала упрости до конца, потом подставляй. Часто ответ не зависит от переменной или сокращается корень.
№12: подставь всё известное, получи линейное уравнение и реши его. Если нужно найти величину под корнем или в знаменателе — сначала выражай её.
\(v = \sqrt{2gh}\), \(v = 20\), \(g = 10\): \(400 = 20h\), \(h = 20\).
Проверь единицы: минуты ↔ часы, см ↔ м. В формулах №12 это частая ловушка.

Практика на уроке

1. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{a^{7}\cdot(a^{-2})^{3}}{a^{-4}}\) при \(a = \frac{1}{2}\).
Решение\(a^{7 - 6 + 4} = a^{5} = \frac{1}{32} = 0{,}03125\).

Ответ: 0,03125

2. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{\sqrt{12}\cdot\sqrt{a^{6}}}{\sqrt{3a^{4}}}\) при \(a = 4\).
Решение\(\sqrt{\frac{12a^6}{3a^4}} = \sqrt{4a^2} = 2a = 8\).

Ответ: 8

3. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{1}{3x} - \frac{3x + y}{3xy}\) при \(x = \sqrt{8}\), \(y = \frac{1}{8}\).
Решение\(\frac{y - 3x - y}{3xy} = -\frac{1}{y} = -8\).

Ответ: -8

4. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Площадь четырёхугольника \(S = \frac{d_1 d_2\sin\alpha}{2}\). Найдите \(d_2\), если \(d_1 = 16\), \(\sin\alpha = \frac{2}{5}\), \(S = 12{,}8\).
Решение\(12{,}8 = \frac{16\cdot d_2\cdot0{,}4}{2} = 3{,}2d_2\), \(d_2 = 4\).

Ответ: 4

5. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Центростремительное ускорение \(a = \omega^2 R\). Найдите \(R\) (в метрах), если \(\omega = 4\) с\(^{-1}\), \(a = 64\) м/с\(^2\).
Решение\(64 = 16R\), \(R = 4\).

Ответ: 4

6. Прототип ОГЭ №12 (ФИПИ / Решу ОГЭ)
Перевести температуру из Цельсия в Фаренгейты: \(t_F = 1{,}8t_C + 32\). Какой температуре по Цельсию соответствует \(-4^\circ\) по Фаренгейту?
Решение\(-36 = 1{,}8t_C\), \(t_C = -20\).

Ответ: -20

7. Прототип ОГЭ №12 (для «5»)
Период колебаний маятника \(T = 2\sqrt{l}\) (\(T\) в секундах, \(l\) в метрах). Найдите длину маятника, период которого 3 секунды.
Решение\(\sqrt{l} = 1{,}5\), \(l = 2{,}25\) м.

Ответ: 2,25

Домашнее задание

1. Прототип ОГЭ №8
Найдите значение выражения \(\frac{(b^{3})^{-2}\cdot b^{9}}{b^{2}}\) при \(b = -5\).
Решение\(b^{-6 + 9 - 2} = b = -5\).

Ответ: -5

2. Прототип ОГЭ №8
Найдите значение выражения \(\sqrt{\frac{18a^{8}}{2a^{6}}}\) при \(a = 7\).
Решение\(\sqrt{9a^2} = 3a = 21\).

Ответ: 21

3. Прототип ОГЭ №12
Мощность \(P = I^2 R\). Найдите \(R\) (в омах), если \(P = 150\) Вт, \(I = 5\) А.
Решение\(150 = 25R\), \(R = 6\).

Ответ: 6

4. Прототип ОГЭ №12
Стоимость поездки на такси \(C = 150 + 11(t - 5)\), \(t\) — длительность в минутах (\(t > 5\)). Сколько длилась поездка, стоившая 612 рублей?
Решение\(11(t - 5) = 462\), \(t - 5 = 42\), \(t = 47\).

Ответ: 47

5. Прототип ОГЭ №12
Кинетическая энергия \(E = \frac{mv^2}{2}\). Найдите скорость \(v\) (в м/с), если \(m = 8\) кг, \(E = 196\) Дж.
Решение\(v^2 = 49\), \(v = 7\).

Ответ: 7

6. Повторение (урок 9) Найдите значение выражения \(\frac{4}{x - 4} - \frac{32}{x^2 - 16}\) при \(x = 6\).
Решение\(\frac{4(x + 4) - 32}{x^2 - 16} = \frac{4}{x + 4} = 0{,}4\).

Ответ: 0,4

7. Повторение (урок 7) Один из смежных углов на \(64^\circ\) меньше другого. Найдите меньший угол.
Решение\(2x + 64 = 180\), \(x = 58^\circ\).

Ответ: 58

8. Повторение (урок 3) Найдите значение выражения \(\frac{\sqrt{75}}{\sqrt{3}} + \sqrt{0{,}81}\).
Решение\(5 + 0{,}9 = 5{,}9\).

Ответ: 5,9
