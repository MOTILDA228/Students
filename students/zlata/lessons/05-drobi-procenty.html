Цель: вычисления у Златы сильные, поэтому теорию не разжёвываем — сразу задачи уровня ОГЭ №6 и проценты «на увеличение/уменьшение», которые нужны в №1–5 и №21. Блок 1 со страницы «Этап 1» не повторяем, здесь новые задачи.

  1. 5 мин — разбор диагностики (урок 4): что решила, что пропустила.
  2. 5 мин — шпаргалка: три формулы процентов, стандартный вид.
  3. 40 мин — практика 1–7 (задачи 6–7 — уровень «на 5»).
  4. 10 мин — итог, ДЗ.

Типичные ошибки: «снизили на 20%, потом повысили на 20% — вернулись к исходному» (нет!); путают, от чего считать процент.

Шпаргалка

Проценты: \(p\%\) от \(a\) — это \(a\cdot\frac{p}{100}\). Увеличить на \(p\%\) — умножить на \(1 + \frac{p}{100}\); уменьшить — на \(1 - \frac{p}{100}\). Найти число по его части — разделить: \(x = b : \frac{p}{100}\).
Два изменения подряд перемножаются, а не складываются: \(+20\%\), затем \(-20\%\) — это \(1{,}2\cdot0{,}8 = 0{,}96\), то есть \(-4\%\).
Стандартный вид: \(a\cdot10^n\), где \(1 \le a < 10\). При умножении числа перемножаются, степени десяти складываются.
\(\frac{2{,}4\cdot10^{-3}}{8\cdot10^{-6}} = 0{,}3\cdot10^{3} = 300\).

Практика на уроке

1. Прототип ОГЭ №6 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{1}{\frac{1}{12} + \frac{1}{18}}\).
Решение\(\frac{3}{36} + \frac{2}{36} = \frac{5}{36}\); обратное — \(\frac{36}{5} = 7{,}2\).

Ответ: 7,2

2. Прототип ОГЭ №6 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{2{,}7 - 1{,}2}{0{,}5\cdot1{,}2}\).
Решение\(\frac{1{,}5}{0{,}6} = 2{,}5\).

Ответ: 2,5

3. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{3{,}6\cdot10^{5}}{1{,}2\cdot10^{2}}\).
Решение\(3\cdot10^{3} = 3000\).

Ответ: 3000

4. Прототип ОГЭ №1–5
Цена на телефон сначала выросла на 25%, а потом снизилась на 20%. На сколько процентов изменилась цена в итоге?
Решение\(1{,}25\cdot0{,}8 = 1\). Цена не изменилась: 0%.

Ответ: 0

5. Прототип ОГЭ №1–5
После скидки 15% куртка стоит 5100 рублей. Сколько стоила куртка до скидки?
Решение\(5100 : 0{,}85 = 6000\) руб.

Ответ: 6000

6. Прототип ОГЭ №21 (часть 2, для подготовки)
Свежие грибы содержат 90% воды, сушёные — 12%. Сколько килограммов сушёных грибов получится из 22 кг свежих?
РешениеСухое вещество не меняется: \(22\cdot0{,}1 = 2{,}2\) кг. В сушёных его 88%: \(2{,}2 : 0{,}88 = 2{,}5\) кг.

Ответ: 2,5

7. Прототип ОГЭ №6 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\left(2\frac{3}{5} - \frac{7}{15}\right) : \frac{8}{9}\).
Решение\(\frac{39}{15} - \frac{7}{15} = \frac{32}{15}\); \(\frac{32}{15}\cdot\frac{9}{8} = \frac{12}{5} = 2{,}4\).

Ответ: 2,4

Домашнее задание

1. Прототип ОГЭ №6
Найдите значение выражения \(\frac{1}{\frac{1}{10} - \frac{1}{15}}\).
Решение\(\frac{3}{30} - \frac{2}{30} = \frac{1}{30}\) → 30.

Ответ: 30

2. Прототип ОГЭ №6
Найдите значение выражения \(\frac{0{,}24\cdot1{,}5}{0{,}9 - 0{,}6}\).
Решение\(\frac{0{,}36}{0{,}3} = 1{,}2\).

Ответ: 1,2

3. Прототип ОГЭ №8
Найдите значение выражения \(\left(5\cdot10^{-3}\right)^2\cdot\left(4\cdot10^{7}\right)\).
Решение\(25\cdot10^{-6}\cdot4\cdot10^{7} = 100\cdot10 = 1000\).

Ответ: 1000

4. Прототип ОГЭ №1–5
Зарплату повысили на 10%, а через год ещё на 10%. На сколько процентов она выросла за два повышения?
Решение\(1{,}1\cdot1{,}1 = 1{,}21\) → 21%.

Ответ: 21

5. Прототип ОГЭ №21 (часть 2)
Смешали 3 л 20%-го раствора соли и 2 л 45%-го. Какова концентрация (в процентах) получившегося раствора?
РешениеСоли: \(0{,}6 + 0{,}9 = 1{,}5\) л из 5 л → 30%.

Ответ: 30

6. Повторение (урок 1) Найдите значение выражения \(\frac{(2^{3})^{4}}{2^{9}\cdot2^{-1}}\).
Решение\(2^{12 - 9 + 1} = 2^4 = 16\).

Ответ: 16

7. Повторение (урок 3) Найдите значение выражения \(\sqrt{2^{6}\cdot 5^{4}}\).
Решение\(2^3\cdot5^2 = 200\).

Ответ: 200
