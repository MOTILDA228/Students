Шпаргалка

ФункцияЧто читать с графика
\(y = kx + b\)\(k > 0\) — возрастает; \(b\) — точка пересечения с осью \(y\)
\(y = ax^2 + bx + c\)\(a > 0\) — ветви вверх; \(c\) — пересечение с осью \(y\); вершина \(x_0 = -\frac{b}{2a}\)

Практика на уроке

1. Прототип ОГЭ №11 (ФИПИ / Решу ОГЭ)
Установите соответствие между графиками и формулами. Формулы: 1) \(y = x^2 - 3\); 2) \(y = -\frac{3}{x}\); 3) \(y = 2x - 3\). Ответ — цифры для А, Б, В.
РешениеА — гипербола во II и IV → 2. Б — прямая → 3. В — парабола → 1.

Ответ: 231

2. Прототип ОГЭ №11 (ФИПИ / Решу ОГЭ)
На рисунке график \(y = kx + b\). Установите знаки: 1) \(k > 0, b > 0\); 2) \(k < 0, b > 0\); 3) \(k > 0, b < 0\); 4) \(k < 0, b < 0\).
РешениеУбывает — \(k < 0\); пересекает \(y\) ниже нуля — \(b < 0\). Вариант 4.

Ответ: 4

3. Прототип ОГЭ №11 (ФИПИ / Решу ОГЭ)
На рисунке парабола \(y = ax^2 + bx + c\). Какое утверждение верно: 1) \(a > 0, c > 0\); 2) \(a > 0, c < 0\); 3) \(a < 0, c > 0\); 4) \(a < 0, c < 0\)?
РешениеВетви вниз — \(a < 0\); пересечение с \(y\) в точке 2 — \(c > 0\). Вариант 3.

Ответ: 3

4. Прототип ОГЭ №11 (для «5»)
Установите соответствие. Формулы: 1) \(y = x^2 + 4x + 3\); 2) \(y = x^2 - 4x + 3\); 3) \(y = -x^2 + 4x - 3\).
РешениеА — ветви вверх, вершина при \(x = -2\) → 1. Б — ветви вниз → 3. В — ветви вверх, вершина при \(x = 2\) → 2.

Ответ: 132

5. Вершина параболы
Найдите ординату вершины параболы \(y = 2x^2 - 12x + 7\).
Решение\(x_0 = 3\), \(y_0 = 18 - 36 + 7 = -11\).

Ответ: -11

6. Для «5»: подготовка к №22
Прямая \(y = kx\) проходит через точку пересечения прямых \(y = 2x - 1\) и \(y = -x + 5\). Найдите \(k\).
Решение\(2x - 1 = -x + 5\): \(x = 2\), \(y = 3\). \(k = 1{,}5\).

Ответ: 1,5
