Цель: вторая часть №22: графики с модулем и задачи «при каких \(k\) прямая \(y = kx\) имеет с графиком одну общую точку».

  1. 5 мин — ДЗ урока 41.
  2. 15 мин — три приёма: раскрыть модуль, отразить, «вращать» прямую \(y = kx\).
  3. 30 мин — практика 1–5.
  4. 10 мин — итог, ДЗ.

Шпаргалка

Модуль: \(|x - a|\) раскрываем на двух промежутках: \(x \ge a\) и \(x < a\). График \(y = f(|x|)\) — правая часть и её отражение влево.
Прямая \(y = kx\) проходит через начало координат и «вращается» при изменении \(k\). Ищем «граничные» положения: через характерные точки графика или касание (дискриминант \(= 0\)).
\(y = |x^2 - 1|\): часть параболы ниже оси отражается вверх.

Практика на уроке

1. Прототип ОГЭ №22 (ФИПИ / Решу ОГЭ)
Постройте график \(y = |x - 2| + |x + 2|\). При каких \(m\) прямая \(y = m\) имеет с графиком бесконечно много общих точек?
РешениеПри \(-2 \le x \le 2\): \(y = 4\) (горизонтальный отрезок). Левее \(y = -2x\), правее \(y = 2x\). Бесконечно много точек при \(m = 4\).

Ответ: 4

2. Прототип ОГЭ №22 (ФИПИ / Решу ОГЭ)
Постройте график \(y = x|x| - 2x\). При каких \(m\) прямая \(y = m\) имеет ровно три общие точки? В ответ запишите наибольшее целое такое \(m\).
Решение\(x \ge 0\): \(y = x^2 - 2x\), вершина \((1;\ -1)\). \(x < 0\): \(y = -x^2 - 2x\), вершина \((-1;\ 1)\). Три точки при \(-1 < m < 1\). Наибольшее целое 0.

Ответ: 0

3. Прототип ОГЭ №22 (ФИПИ / Решу ОГЭ)
При каком положительном \(k\) прямая \(y = kx\) касается параболы \(y = x^2 + 4\)?
Решение\(x^2 - kx + 4 = 0\), \(D = k^2 - 16 = 0\), \(k = 4\).

Ответ: 4

4. Прототип ОГЭ №22 (ФИПИ / Решу ОГЭ)
Постройте график \(y = \begin{cases} x + 3, & x < -1 \\ -x + 1, & -1 \le x \le 1 \\ x - 1, & x > 1 \end{cases}\). При каких \(m\) прямая \(y = m\) имеет ровно две общие точки? В ответ запишите сумму всех таких целых \(m\).
РешениеТочки излома: \((-1;\ 2)\) и \((1;\ 0)\). Прямая \(y = m\): при \(m < 0\) — 1 точка; \(m = 0\) — 2; \(0 < m < 2\) — 3; \(m = 2\) — 2; \(m > 2\) — 1. Целые: 0 и 2, сумма 2.

Ответ: 2

5. Для «5»
При каких \(k\) прямая \(y = kx\) не имеет общих точек с графиком \(y = |x| + 1\)? В ответ запишите наибольшее такое \(k\).
Решение\(x > 0\): \(kx = x + 1\) → \(x = \frac{1}{k - 1}\) — есть при \(k > 1\). \(x < 0\): \(kx = -x + 1\) → \(x = \frac{1}{k + 1} < 0\) при \(k < -1\). Общих точек нет при \(-1 \le k \le 1\). Наибольшее \(k = 1\).

Ответ: 1

Домашнее задание

1. Прототип ОГЭ №22
Постройте график \(y = |x^2 - 4|\). При каких \(m\) прямая \(y = m\) имеет ровно три общие точки?
Решение«Горб» между \(-2\) и 2 достигает \(y(0) = 4\). Три точки при \(m = 4\).

Ответ: 4

2. Прототип ОГЭ №22
Постройте график \(y = |x + 1| - |x - 3|\). Найдите наибольшее значение функции.
РешениеПри \(x \ge 3\): \(y = 4\); при \(x \le -1\): \(y = -4\); между — \(2x - 2\). Наибольшее 4.

Ответ: 4

3. Прототип ОГЭ №22
При каком положительном \(k\) прямая \(y = kx\) касается параболы \(y = x^2 + 9\)?
Решение\(k^2 - 36 = 0\), \(k = 6\).

Ответ: 6

4. Прототип ОГЭ №22
Постройте график \(y = x|x| + 4x\). При каких \(m\) прямая \(y = m\) имеет одну общую точку? Сколько таких целых \(m\) на отрезке \([-5;\ 5]\)?
Решение\(x \ge 0\): \(x^2 + 4x\) (возрастает от 0); \(x < 0\): \(-x^2 + 4x\) (возрастает к 0). Функция возрастает на всей прямой ⇒ любая \(m\) — одна точка. На \([-5;\ 5]\) — 11 целых.

Ответ: 11

5. Повторение (урок 40) Решите уравнение \(x^3 - x^2 - 16x + 16 = 0\). Запишите сумму корней.
Решение\((x - 1)(x^2 - 16)\): 1, 4, \(-4\). Сумма 1.

Ответ: 1

Решение\(-2\).
