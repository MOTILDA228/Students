Для репетитора: план урока

Цель: №22 (2 балла): построить график (часто кусочный или после сокращения дроби с «выколотой» точкой) и найти, при каких \(m\) прямая \(y = m\) имеет с ним нужное число общих точек.

  1. 5 мин — ДЗ урока 38.
  2. 15 мин — алгоритм + образец оформления.
  3. 30 мин — практика 1–5 (строить графики в тетради на клетках!).
  4. 10 мин — итог, ДЗ.

Критерии №22: 2 балла — верный график и верный ответ; 1 балл — график верный, ответ неполный (например, потеряна выколотая точка).

Шпаргалка

Алгоритм: 1) область определения (знаменатель \(\ne 0\)); 2) упростить формулу; 3) построить (выколоть точки!); 4) провести горизонтальные прямые \(y = m\) и посчитать точки пересечения; 5) записать ответ.
\(y = \frac{x^2 - 4}{x - 2}\) → \(y = x + 2\), \(x \ne 2\): прямая с выколотой точкой \((2;\ 4)\). Прямая \(y = m\) не имеет общих точек только при \(m = 4\).
Кусочная функция: на каждом участке — своя формула; концы участков проверять подстановкой.

Практика на уроке

1. Прототип ОГЭ №22 (ФИПИ / Решу ОГЭ)
Постройте график функции \(y = \frac{x^2 + 3x}{x}\). При каком значении \(m\) прямая \(y = m\) не имеет с графиком общих точек?
Решение\(x \ne 0\), \(y = x + 3\). Выколота точка \((0;\ 3)\). Прямая \(y = 3\) проходит только через выколотую точку: \(m = 3\).

Ответ: 3

2. Прототип ОГЭ №22 (ФИПИ / Решу ОГЭ)
Постройте график \(y = \begin{cases} x^2 - 4x + 3, & x \ge 1 \\ x - 1, & x < 1 \end{cases}\). При каких \(m\) прямая \(y = m\) имеет с графиком ровно две общие точки? В ответ запишите наименьшее целое такое \(m\).
РешениеПри \(x < 1\) — прямая до точки \((1;\ 0)\) (выколота, но парабола в ней \(= 0\)). Парабола при \(x \ge 1\): вершина \((2;\ -1)\), идёт от 0 вниз до \(-1\) и вверх. Прямая \(y = m\): при \(m < -1\) — 1 точка (на луче); \(m = -1\) — 2 точки; \(-1 < m < 0\) — 3 точки; \(m = 0\) — 2 точки (\(x = 1\), \(x = 3\)); \(m > 0\) — 1 точка. Ответ: \(m = -1\) или \(m = 0\). Наименьшее \(-1\).

Ответ: -1

3. Прототип ОГЭ №22 (ФИПИ / Решу ОГЭ)
Постройте график \(y = \frac{(x - 1)(x^2 - 9)}{x - 3}\). При каких \(m\) прямая \(y = m\) имеет с графиком ровно одну общую точку? Запишите сумму всех таких \(m\).
Решение\(x \ne 3\): \(y = (x - 1)(x + 3) = x^2 + 2x - 3\), выколота \((3;\ 12)\). Вершина \((-1;\ -4)\). Одна точка: при \(m = -4\) (вершина) и при \(m = 12\) (вторая точка на этой высоте выколота, остаётся \(x = -5\)). Сумма \(8\).

Ответ: 8

4. Прототип ОГЭ №22
Постройте график \(y = x^2 - 2|x| - 3\). При каких \(m\) прямая \(y = m\) имеет ровно три общие точки?
РешениеЧётная функция: для \(x \ge 0\) парабола \(x^2 - 2x - 3\) (вершина \((1;\ -4)\)), отражаем. Три точки — через «ямку» посередине: \(y(0) = -3\), \(m = -3\).

Ответ: -3

5. Для «5»
Постройте график \(y = \frac{4}{x}\) при \(|x| \ge 1\) и \(y = 4x\) при \(|x| < 1\). При каких \(m\) прямая \(y = m\) имеет ровно одну общую точку? В ответ запишите наибольшее такое \(m\) по модулю.
РешениеГипербола при \(|x| \ge 1\) даёт значения \((0;\ 4]\) и \([-4;\ 0)\), отрезок прямой при \(|x| < 1\) — \((-4;\ 4)\). Две точки при \(0 < |m| < 4\), одна — при \(m = \pm4\) и \(m = 0\). Наибольшее по модулю 4.

Ответ: 4

Постройте график \(y = \frac{x^2 - 1}{x + 1}\). При каком \(m\) прямая \(y = m\) не имеет с графиком общих точек?
Решение\(y = x - 1\), \(x \ne -1\), выколота \((-1;\ -2)\). \(m = -2\).

Ответ: -2

2. Прототип ОГЭ №22
Постройте график \(y = \begin{cases} -x^2 + 2x + 3, & x \le 2 \\ 3, & x > 2 \end{cases}\). Найдите наибольшее значение функции.
РешениеВершина \((1;\ 4)\): наибольшее значение 4.

Ответ: 4

3. Прототип ОГЭ №22
Постройте график \(y = \frac{(x + 2)(x^2 - 1)}{x + 1}\). Запишите все \(m\), при которых прямая \(y = m\) имеет с графиком одну общую точку; в ответ — их сумму.
Решение\(y = (x + 2)(x - 1) = x^2 + x - 2\), \(x \ne -1\) (выколота \((-1;\ -2)\)). Вершина \((-0{,}5;\ -2{,}25)\). Одна точка: \(m = -2{,}25\) и \(m = -2\) (вторая точка \(x = 0\)). Сумма \(-4{,}25\).

Ответ: -4,25

4. Прототип ОГЭ №22

РешениеВершины \((\pm2;\ -1)\), \(y(0) = 3\). Две точки: \(m = -1\) или \(m > 3\). Наименьшее \(-1\).

Ответ: -1
