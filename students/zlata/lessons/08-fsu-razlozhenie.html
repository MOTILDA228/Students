Цель: ФСУ и разложение — за один урок (у Златы сильная база по подобным и скобкам). Главное — видеть формулу «в обе стороны» и применять её для вычислений и упрощений в №8, и как первый шаг в уравнениях №20.

  1. 5 мин — проверка ДЗ урока 7.
  2. 10 мин — шпаргалка: три формулы, четыре способа разложения.
  3. 35 мин — практика 1–7 (7 — уравнение части 2).
  4. 10 мин — итог, ДЗ.

Типичные ошибки: \((a - b)^2 = a^2 - b^2\); забывают удвоенное произведение; теряют знак при группировке.

Шпаргалка

\((a \pm b)^2 = a^2 \pm 2ab + b^2\)  ·  \(a^2 - b^2 = (a - b)(a + b)\)  ·  \(a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)\)
Разложение, по порядку: 1) вынести общий множитель; 2) узнать формулу; 3) группировка; 4) квадратный трёхчлен: \(ax^2 + bx + c = a(x - x_1)(x - x_2)\).
\(x^3 - 2x^2 - 9x + 18 = x^2(x - 2) - 9(x - 2) = (x - 2)(x - 3)(x + 3)\).
Разность квадратов — удобный инструмент для счёта: \(67^2 - 33^2 = 34\cdot100 = 3400\).

Практика на уроке

1. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{73^2 - 27^2}{46}\).
Решение\(\frac{46\cdot100}{46} = 100\).

Ответ: 100

2. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \((x - 4)^2 - x(x - 8)\) при \(x = \sqrt{7}\).
Решение\(x^2 - 8x + 16 - x^2 + 8x = 16\).

Ответ: 16

3. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(4a(a - 2) - (2a - 3)^2\) при \(a = -\frac{3}{4}\).
Решение\(4a^2 - 8a - 4a^2 + 12a - 9 = 4a - 9 = -3 - 9 = -12\).

Ответ: -12

4. Разложение на множители
Разложите на множители \(x^3 - 4x^2 - x + 4\). Найдите значение выражения при \(x = 5\) (удобнее — по разложению).
Решение\(x^2(x - 4) - (x - 4) = (x - 4)(x - 1)(x + 1)\). При \(x = 5\): \(1\cdot4\cdot6 = 24\).

Ответ: 24

5. Разложение на множители
Разложите на множители \(2x^2 - 5x - 3\). В ответ запишите сумму чисел \(p\) и \(q\), если разложение имеет вид \((2x + p)(x + q)\).
РешениеКорни: \(D = 25 + 24 = 49\), \(x = 3\) и \(x = -\frac{1}{2}\). \(2(x - 3)(x + \frac{1}{2}) = (2x + 1)(x - 3)\). \(p + q = 1 - 3 = -2\).

Ответ: -2

6. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{a^2 - 9b^2}{a - 3b} - a\) при \(a = 3{,}7\), \(b = 1{,}5\).
Решение\(\frac{(a - 3b)(a + 3b)}{a - 3b} - a = 3b = 4{,}5\).

Ответ: 4,5

7. Прототип ОГЭ №20 (часть 2)
Решите уравнение \(x^3 + 3x^2 - 4x - 12 = 0\). В ответ запишите сумму корней.
Решение\(x^2(x + 3) - 4(x + 3) = (x + 3)(x - 2)(x + 2) = 0\). Корни \(-3; -2; 2\), сумма \(-3\).

Оформление части 2: группировка → произведение равно нулю → каждый множитель → ответ.

Ответ: -3

Решение\(\frac{16\cdot100}{32} = 50\).

Ответ: 50

2. Прототип ОГЭ №8
Найдите значение выражения \((b + 5)^2 - b(b + 10)\) при \(b = -\frac{2}{9}\).
Решение\(25\).

Ответ: 25

3. Прототип ОГЭ №8
Найдите значение выражения \(\frac{16x^2 - y^2}{4x + y} + y\) при \(x = 1{,}25\).
Решение\(4x - y + y = 4x = 5\).

Ответ: 5

4. Разложение
Разложите \(3x^2 + 10x - 8\) на множители. Найдите значение при \(x = \frac{2}{3}\).
РешениеКорни: \(D = 100 + 96 = 196\), \(x = \frac{-10 \pm 14}{6}\): \(\frac{2}{3}\) и \(-4\). \((3x - 2)(x + 4)\), при \(x = \frac{2}{3}\) — 0.

Ответ: 0

5. Прототип ОГЭ №20 (часть 2)
Решите уравнение \(x^3 - 5x^2 - 9x + 45 = 0\). В ответ запишите произведение корней.
Решение\((x - 5)(x^2 - 9) = 0\): 5, 3, \(-3\). Произведение \(-45\).

Ответ: -45

6. Повторение (урок 6) Найдите значение выражения \((\sqrt{19} - 4)(\sqrt{19} + 4)\).
Решение\(19 - 16 = 3\).

Ответ: 3

7. Повторение (урок 4) Решите уравнение \(\frac{x + 1}{2} - \frac{x}{5} = 2\).
Решение\(5x + 5 - 2x = 20\), \(x = 5\).

Ответ: 5
