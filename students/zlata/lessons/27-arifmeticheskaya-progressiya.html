Для репетитора: план урока

Цель: формулы \(n\)-го члена и суммы, задачи №14 с сюжетом («каждый день на … больше»). Для «5» — найти \(n\) по условию и задачи из части 2.

  1. 5 мин — разбор контрольной №2.
  2. 10 мин — формулы.
  3. 35 мин — практика 1–7.
  4. 10 мин — итог, ДЗ.

Шпаргалка

\(a_n = a_1 + (n - 1)d\) · \(S_n = \frac{a_1 + a_n}{2}\cdot n = \frac{2a_1 + (n - 1)d}{2}\cdot n\)
Каждый член — среднее арифметическое соседей: \(a_n = \frac{a_{n - 1} + a_{n + 1}}{2}\). \(d = \frac{a_m - a_k}{m - k}\).
В сюжетных задачах внимательно: «в первый день» — это \(a_1\), «за 10 дней» — это \(S_{10}\), «на десятый день» — это \(a_{10}\).

Практика на уроке

1. Прототип ОГЭ №14 (ФИПИ / Решу ОГЭ)
Арифметическая прогрессия: \(a_1 = -4\), \(d = 3\). Найдите \(a_{21}\).
Решение\(-4 + 60 = 56\).

Ответ: 56

2. Прототип ОГЭ №14
В арифметической прогрессии \(a_5 = 17\), \(a_{12} = 45\). Найдите \(a_1\).
Решение\(d = \frac{28}{7} = 4\), \(a_1 = 17 - 16 = 1\).

Ответ: 1

3. Прототип ОГЭ №14
Найдите сумму первых 20 членов прогрессии \(3;\ 7;\ 11;\ \ldots\)
Решение\(S_{20} = \frac{6 + 19\cdot4}{2}\cdot20 = 820\).

Ответ: 820

4. Прототип ОГЭ №14 (ФИПИ / Решу ОГЭ)
Бегун в первый день пробежал 2 км, а каждый следующий — на 0,5 км больше. Сколько километров он пробежит за 12 дней?
Решение\(S_{12} = \frac{4 + 11\cdot0{,}5}{2}\cdot12 = 57\).

Ответ: 57

5. Прототип ОГЭ №14 (ФИПИ / Решу ОГЭ)
В амфитеатре 15 рядов. В первом ряду 18 мест, в каждом следующем на 2 больше. Сколько мест в последнем ряду?
Решение\(18 + 14\cdot2 = 46\).

Ответ: 46

6. Прототип ОГЭ №14
Сколько отрицательных членов в прогрессии \(-50;\ -46;\ -42;\ \ldots\)?
Решение\(-50 + 4(n - 1) < 0\) → \(n < 13{,}5\): 13 членов.

Ответ: 13

7. Для «5»
Сумма первых \(n\) членов прогрессии \(5;\ 9;\ 13;\ \ldots\) равна 275. Найдите \(n\).
Решение\(\frac{10 + 4(n - 1)}{2}n = 275\) → \((2n + 3)n = 275\) → \(2n^2 + 3n - 275 = 0\), \(n = 11\).

Ответ: 11

Домашнее задание

1. Прототип ОГЭ №14
\(a_1 = 12\), \(d = -2{,}5\). Найдите \(a_{9}\).
Решение\(12 - 20 = -8\).

Ответ: -8

2. Прототип ОГЭ №14
\(a_3 = 8\), \(a_7 = 20\). Найдите \(S_{10}\).
Решение\(d = 3\), \(a_1 = 2\), \(S_{10} = \frac{4 + 27}{2}\cdot10 = 155\).

Ответ: 155

3. Прототип ОГЭ №14
Улитка в первую минуту проползла 30 см, а каждую следующую — на 5 см больше. Сколько сантиметров она проползёт за 8 минут?
Решение\(\frac{60 + 35}{2}\cdot8 = 380\).

Ответ: 380

4. Прототип ОГЭ №14
Сколько положительных членов в прогрессии \(80;\ 73;\ 66;\ \ldots\)?
Решение\(80 - 7(n - 1) > 0\) → \(n < 12{,}4\): 12.

Ответ: 12
