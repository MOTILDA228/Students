Для репетитора: план урока

Цель: довести корни до уровня ОГЭ. Свойства Злата видела на уроках 2–3, теперь — вынесение/внесение множителя, сравнение чисел с корнями (№7) и сопряжённое выражение.

  1. 5 мин — проверка ДЗ урока 5.
  2. 10 мин — шпаргалка: \(\sqrt{a^2} = |a|\), вынесение, сопряжённое.
  3. 35 мин — практика 1–7.
  4. 10 мин — итог, ДЗ.

Типичные ошибки: \(\sqrt{a + b} = \sqrt{a} + \sqrt{b}\) (неверно!); \(\sqrt{(3 - \sqrt{10})^2} = 3 - \sqrt{10}\) (а число отрицательное).

Шпаргалка

\(\sqrt{ab} = \sqrt{a}\sqrt{b}\), \(\sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}\), \(\sqrt{a^2} = |a|\), \((\sqrt{a})^2 = a\) при \(a \ge 0\).
Вынести множитель: \(\sqrt{75} = \sqrt{25\cdot3} = 5\sqrt{3}\). Внести: \(3\sqrt{2} = \sqrt{18}\). Сравнить \(4\sqrt{3}\) и \(7\): \(\sqrt{48}\) и \(\sqrt{49}\) → \(4\sqrt{3} < 7\).
Сопряжённое: \((\sqrt{a} - \sqrt{b})(\sqrt{a} + \sqrt{b}) = a - b\). Им избавляются от корня в знаменателе.
\(\sqrt{9 + 16} = 5\), а \(\sqrt{9} + \sqrt{16} = 7\). Корень из суммы на слагаемые не разбивается.

Практика на уроке

1. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\sqrt{45}\cdot\sqrt{5} - \sqrt{2{,}25}\).
Решение\(\sqrt{225} - 1{,}5 = 15 - 1{,}5 = 13{,}5\).

Ответ: 13,5

2. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \((\sqrt{13} - 3)(\sqrt{13} + 3)\).
Решение\(13 - 9 = 4\).

Ответ: 4

3. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{(2\sqrt{6})^2}{16}\).
Решение\(\frac{4\cdot6}{16} = 1{,}5\).

Ответ: 1,5

4. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \((\sqrt{11} + 2)^2 - 4\sqrt{11}\).
Решение\(11 + 4\sqrt{11} + 4 - 4\sqrt{11} = 15\).

Ответ: 15

5. Прототип ОГЭ №7 (ФИПИ / Решу ОГЭ)
Какое из чисел больше всех: 1) \(3\sqrt{5}\); 2) \(2\sqrt{11}\); 3) \(\sqrt{43}\); 4) \(6{,}5\)? В ответ запишите номер.
РешениеВнесём под корень: \(\sqrt{45}\), \(\sqrt{44}\), \(\sqrt{43}\), \(\sqrt{42{,}25}\). Больше всех \(3\sqrt{5}\).

Ответ: 1

6. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{12}{\sqrt{7} - 1} - 2\sqrt{7}\).
РешениеДомножим на сопряжённое: \(\frac{12(\sqrt{7} + 1)}{7 - 1} = 2\sqrt{7} + 2\). Минус \(2\sqrt{7}\) → 2.

Ответ: 2

7. Прототип ОГЭ №8 (для «5»)
Найдите значение выражения \(\sqrt{(3 - \sqrt{10})^2} + \sqrt{(4 - \sqrt{10})^2}\).
Решение\(\sqrt{a^2} = |a|\). \(3 < \sqrt{10} < 4\), поэтому \(|3 - \sqrt{10}| = \sqrt{10} - 3\), \(|4 - \sqrt{10}| = 4 - \sqrt{10}\). Сумма: 1.

Ответ: 1

Домашнее задание

1. Прототип ОГЭ №8
Найдите значение выражения \(\sqrt{3}\cdot\sqrt{27} + \sqrt{1{,}69}\).
Решение\(9 + 1{,}3 = 10{,}3\).

Ответ: 10,3

2. Прототип ОГЭ №8
Найдите значение выражения \((\sqrt{17} - \sqrt{2})(\sqrt{17} + \sqrt{2})\).
Решение\(17 - 2 = 15\).

Ответ: 15

3. Прототип ОГЭ №8
Найдите значение выражения \((\sqrt{6} - 1)^2 + 2\sqrt{6}\).
Решение\(6 - 2\sqrt{6} + 1 + 2\sqrt{6} = 7\).

Ответ: 7

4. Прототип ОГЭ №7
Какое из чисел меньше всех: 1) \(2\sqrt{7}\); 2) \(3\sqrt{3}\); 3) \(\sqrt{29}\); 4) \(5{,}5\)?
Решение\(\sqrt{28}\), \(\sqrt{27}\), \(\sqrt{29}\), \(\sqrt{30{,}25}\). Меньше всех \(3\sqrt{3}\).

Ответ: 2

5. Прототип ОГЭ №8 (для «5»)
Найдите значение выражения \(\frac{6}{3 - \sqrt{3}} - \sqrt{3}\).
Решение\(\frac{6(3 + \sqrt{3})}{9 - 3} = 3 + \sqrt{3}\); минус \(\sqrt{3}\) → 3.

Ответ: 3

6. Повторение (урок 5) После повышения цены на 8% билет стоит 1350 рублей. Сколько он стоил до повышения?
Решение\(1350 : 1{,}08 = 1250\).

Ответ: 1250

7. Повторение (урок 2) Найдите значение выражения \(\sqrt{\frac{49}{64}}\cdot 16\).
Решение\(\frac{7}{8}\cdot16 = 14\).

Ответ: 14
