Цель: геометрия почти с нуля, но Злата быстро схватывает — за один урок проходим углы (смежные, вертикальные, биссектриса) и параллельные прямые с секущей. Это фундамент для всех задач №15–17.

  1. 5 мин — проверка ДЗ урока 6.
  2. 15 мин — теория с чертежами: каждый факт проговорить и показать на рисунке.
  3. 30 мин — практика 1–7.
  4. 10 мин — итог, ДЗ.

Важно: приучить в каждой задаче делать чертёж и подписывать на нём найденные углы.

Шпаргалка

1. Углы

Смежные углы (общая сторона, две другие — продолжение друг друга) в сумме дают \(180^\circ\). Вертикальные углы равны. Биссектриса делит угол пополам.

2. Параллельные прямые и секущая

Если \(a \parallel b\), то накрест лежащие углы равны, соответственные равны, односторонние в сумме \(180^\circ\). И наоборот: если, например, накрест лежащие равны, то прямые параллельны.
На рисунке \(\angle 1 = \angle 2\) (накрест лежащие), \(\angle 3 = \angle 1\) (вертикальные), значит, и \(\angle 3 = \angle 2\) (соответственные). Всё сводится к двум значениям: \(\alpha\) и \(180^\circ - \alpha\).
Равенство углов работает только для параллельных прямых. Если в условии не сказано «\(a \parallel b\)», это нужно доказать.

Практика на уроке

1. Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
Один из смежных углов на \(46^\circ\) больше другого. Найдите больший угол.
Решение\(x + x + 46 = 180\) → \(x = 67\). Больший: \(113^\circ\).

Ответ: 113

2. Прототип ОГЭ №15
Сумма двух вертикальных углов равна \(128^\circ\). Найдите угол, смежный с каждым из них.
РешениеКаждый вертикальный — \(64^\circ\), смежный: \(116^\circ\).

Ответ: 116

3. Прототип ОГЭ №15
Прямые \(a\) и \(b\) параллельны, секущая образует с \(a\) угол \(72^\circ\). Найдите односторонний с ним угол при прямой \(b\).
РешениеОдносторонние в сумме \(180^\circ\): \(108^\circ\).

Ответ: 108

4. Прототип ОГЭ №15
Угол \(AOB\) равен \(140^\circ\), \(OC\) — биссектриса. Луч \(OD\) — биссектриса угла \(AOC\). Найдите угол \(DOB\).
Решение\(\angle AOC = 70^\circ\), \(\angle AOD = 35^\circ\). \(\angle DOB = 140 - 35 = 105^\circ\).

Ответ: 105

5. Прототип ОГЭ №15
Прямые \(a \parallel b\). Секущая образует с ними углы \(1\) и \(2\) (накрест лежащие), причём \(\angle 1 = 3x + 10^\circ\), \(\angle 2 = 5x - 30^\circ\). Найдите \(\angle 1\).
РешениеНакрест лежащие равны: \(3x + 10 = 5x - 30\) → \(x = 20\). \(\angle 1 = 70^\circ\).

Ответ: 70

6. Прототип ОГЭ №15
Две параллельные прямые пересечены секущей. Один из восьми образовавшихся углов равен \(37^\circ\). Найдите сумму всех восьми углов, которые больше \(90^\circ\).
РешениеУглов по \(37^\circ\) — четыре, по \(143^\circ\) — четыре. \(4\cdot143 = 572^\circ\).

Ответ: 572

7. Прототип ОГЭ №19 (ФИПИ / Решу ОГЭ)
Какие из утверждений верны?
1) Вертикальные углы равны.
2) Если при пересечении двух прямых секущей односторонние углы равны, то прямые параллельны.
3) Сумма смежных углов равна \(180^\circ\).
Решение1 — верно. 2 — неверно: должны давать в сумме \(180^\circ\). 3 — верно.

Ответ: 13

Домашнее задание

1. Прототип ОГЭ №15
Один из смежных углов в 4 раза больше другого. Найдите меньший угол.
Решение\(5x = 180\), \(x = 36^\circ\).

Ответ: 36

2. Прототип ОГЭ №15
Прямые \(a \parallel b\), секущая образует с \(a\) угол \(49^\circ\). Найдите все различные углы, образованные при прямой \(b\). В ответ запишите больший.
РешениеУглы \(49^\circ\) и \(131^\circ\).

Ответ: 131

3. Прототип ОГЭ №15
Угол между биссектрисой угла и его стороной равен \(38^\circ\). Найдите угол, смежный с исходным.
РешениеИсходный — \(76^\circ\), смежный — \(104^\circ\).

Ответ: 104

4. Прототип ОГЭ №15
Прямые \(a \parallel b\), односторонние углы равны \(2x\) и \(3x - 20^\circ\). Найдите больший из них.
Решение\(5x - 20 = 180\) → \(x = 40\). Углы \(80^\circ\) и \(100^\circ\).

Ответ: 100

5. Прототип ОГЭ №19
Какие из утверждений верны? 1) Если угол равен \(47^\circ\), то смежный с ним равен \(153^\circ\). 2) Через точку, не лежащую на прямой, можно провести прямую, параллельную этой прямой. 3) Если при пересечении двух прямых секущей соответственные углы равны, то прямые параллельны.
Решение1 — неверно (\(133^\circ\)). 2 — верно. 3 — верно.

Ответ: 23

6. Повторение (урок 5) Найдите значение выражения \(\frac{1}{\frac{1}{6} + \frac{1}{10}}\).
Решение\(\frac{5}{30} + \frac{3}{30} = \frac{8}{30}\); обратное — \(3{,}75\).

Ответ: 3,75

7. Повторение (урок 3) Найдите значение выражения \(\frac{5^{-3}\cdot 25^{2}}{5}\).
Решение\(5^{-3+4-1} = 5^0 = 1\).

Ответ: 1
