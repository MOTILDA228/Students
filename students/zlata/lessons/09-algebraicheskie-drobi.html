Для репетитора: план урока

Цель: научиться быстро упрощать дробные выражения — это №8 в формате «упростите и найдите значение» и основа дробных уравнений (урок 14) и №20.

  1. 5 мин — проверка ДЗ урока 8.
  2. 10 мин — алгоритм: разложить → общий знаменатель → сократить.
  3. 35 мин — практика 1–7.
  4. 10 мин — итог, ДЗ.

Типичные ошибки: сокращают слагаемые, а не множители; теряют минус при \(a - b = -(b - a)\).

Шпаргалка

Алгоритм: 1) разложить числители и знаменатели на множители; 2) найти общий знаменатель (или перевернуть делитель); 3) сократить; 4) только потом подставлять число.
Сокращать можно только множители: \(\frac{x + 3}{x}\) не сокращается. И помни: \(\frac{a - b}{b - a} = -1\).
\(\frac{1}{x - 2} - \frac{4}{x^2 - 4} = \frac{x + 2 - 4}{(x - 2)(x + 2)} = \frac{1}{x + 2}\).

Практика на уроке

1. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{x^2 - 25}{x^2 - 5x}\) при \(x = -10\).
Решение\(\frac{(x - 5)(x + 5)}{x(x - 5)} = \frac{x + 5}{x} = \frac{-5}{-10} = 0{,}5\).

Ответ: 0,5

2. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{a^2 - 4ab + 4b^2}{a^2 - 4b^2}\) при \(a = 7\), \(b = 1{,}5\).
Решение\(\frac{(a - 2b)^2}{(a - 2b)(a + 2b)} = \frac{a - 2b}{a + 2b} = \frac{7 - 3}{7 + 3} = 0{,}4\).

Ответ: 0,4

3. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\left(\frac{1}{a} - \frac{1}{b}\right) : \frac{b - a}{ab}\) при \(a = \sqrt{3}\), \(b = 7\).
Решение\(\frac{b - a}{ab}\cdot\frac{ab}{b - a} = 1\).

Ответ: 1

4. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{3}{x - 3} - \frac{18}{x^2 - 9}\) при \(x = 2\).
Решение\(\frac{3(x + 3) - 18}{(x - 3)(x + 3)} = \frac{3(x - 3)}{(x - 3)(x + 3)} = \frac{3}{x + 3} = 0{,}6\).

Ответ: 0,6

5. Прототип ОГЭ №8 (ФИПИ / Решу ОГЭ)
Найдите значение выражения \(\frac{9x^2 - 1}{3x^2 + x}\cdot\frac{x}{3x - 1}\) при \(x = 12{,}7\).
Решение\(\frac{(3x - 1)(3x + 1)}{x(3x + 1)}\cdot\frac{x}{3x - 1} = 1\).

Ответ: 1

6. Прототип ОГЭ №8
Найдите значение выражения \(\frac{a - b}{a}\cdot\frac{a^2}{b^2 - a^2}\) при \(a = 2{,}4\), \(b = 0{,}6\).
Решение\(\frac{a - b}{a}\cdot\frac{a^2}{-(a - b)(a + b)} = -\frac{a}{a + b} = -\frac{2{,}4}{3} = -0{,}8\).

Ответ: -0,8

7. Для «5»: подготовка к №20
Упростите \(\frac{x}{x - 1} - \frac{2}{x + 1} - \frac{2x}{x^2 - 1}\) и найдите значение при \(x = 3\).
РешениеОбщий знаменатель \((x - 1)(x + 1)\): \(\frac{x(x + 1) - 2(x - 1) - 2x}{x^2 - 1} = \frac{x^2 - 3x + 2}{x^2 - 1} = \frac{(x - 1)(x - 2)}{(x - 1)(x + 1)} = \frac{x - 2}{x + 1}\). При \(x = 3\): \(0{,}25\).

Ответ: 0,25

Домашнее задание

1. Прототип ОГЭ №8
Найдите значение выражения \(\frac{x^2 - 36}{x^2 + 6x}\) при \(x = 12\).
Решение\(\frac{x - 6}{x} = 0{,}5\).

Ответ: 0,5

2. Прототип ОГЭ №8
Найдите значение выражения \(\left(\frac{1}{b} + \frac{1}{a}\right)\cdot\frac{ab}{a + b}\) при \(a = \sqrt{2}\), \(b = 5\).
Решение\(\frac{a + b}{ab}\cdot\frac{ab}{a + b} = 1\).

Ответ: 1

3. Прототип ОГЭ №8
Найдите значение выражения \(\frac{2}{x + 2} - \frac{8}{x^2 - 4}\) при \(x = -6\).
Решение\(\frac{2(x - 2) - 8}{x^2 - 4} = \frac{2(x - 6)}{(x-2)(x+2)}\). При \(x = -6\): \(\frac{-24}{32} = -0{,}75\).

Ответ: -0,75

4. Прототип ОГЭ №8
Найдите значение выражения \(\frac{a^2 - 6a + 9}{a^2 - 9}\cdot(a + 3)\) при \(a = 3{,}5\).
Решение\(\frac{(a - 3)^2}{(a - 3)(a + 3)}(a + 3) = a - 3 = 0{,}5\).

Ответ: 0,5

5. Для «5»
Упростите \(\frac{a}{a - b} + \frac{b}{b - a}\).
Решение\(\frac{a}{a - b} - \frac{b}{a - b} = 1\).

Ответ: 1

Ответ: 117

Ответ: 25

8. Повторение (урок 1) Найдите значение выражения \(\frac{a^{-5}\cdot a^{12}}{a^{4}}\) при \(a = -3\).

Ответ: -27
