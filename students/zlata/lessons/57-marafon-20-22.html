Марафон

1. ОГЭ №20
Решите уравнение \(x^3 + 2x^2 - 9x - 18 = 0\). Запишите сумму корней.
Решение\((x + 2)(x^2 - 9) = 0\): \(-2;\ \pm3\). Сумма \(-2\).

Ответ: -2

2. ОГЭ №20
Решите систему \(\begin{cases} x^2 - 3y = 1 \\ x + y = 3 \end{cases}\). Запишите сумму всех \(x\).
Решение\(y = 3 - x\): \(x^2 + 3x - 10 = 0\): \(x = 2\), \(x = -5\). Сумма \(-3\).

Ответ: -3

3. ОГЭ №21
Из A в B одновременно выехали два автомобиля. Первый проехал с постоянной скоростью весь путь. Второй проехал первую половину пути со скоростью 36 км/ч, а вторую — со скоростью на 54 км/ч большей скорости первого, и прибыл в B одновременно с первым. Найдите скорость первого автомобиля, если она больше 40 км/ч.
Решение\(\frac{1}{x} = \frac{1}{2\cdot36} + \frac{1}{2(x + 54)}\) → \(72(x + 54) = x(x + 54) + 36x\) → \(x^2 + 18x - 3888 = 0\), \(D = 324 + 15552 = 15876 = 126^2\), \(x = 54\).

Ответ: 54

4. ОГЭ №22
Постройте график \(y = \frac{x^4 - 13x^2 + 36}{(x - 3)(x + 2)}\). При каких \(m\) прямая \(y = m\) имеет с графиком ровно одну общую точку? Запишите сумму таких \(m\).
РешениеЧислитель \((x^2 - 4)(x^2 - 9) = (x - 2)(x + 2)(x - 3)(x + 3)\). При \(x \ne 3\), \(x \ne -2\): \(y = (x - 2)(x + 3) = x^2 + x - 6\). Выколоты \((3;\ 6)\) и \((-2;\ -4)\). Вершина \((-0{,}5;\ -6{,}25)\). Одна точка: \(m = -6{,}25\); \(m = 6\) (вторая точка \(x = -4\)); \(m = -4\) (вторая точка \(x = 1\)). Сумма \(-6{,}25 + 6 - 4 = -4{,}25\).

Ответ: -4,25

5. ОГЭ №21
Два оператора, работая вместе, набирают текст за 8 часов. Первый оператор, работая один, набрал бы его на 12 часов быстрее второго. За сколько часов наберёт текст первый оператор?
Решение\(\frac{1}{x} + \frac{1}{x + 12} = \frac{1}{8}\) → \(x^2 - 4x - 96 = 0\), \(x = 12\).

Ответ: 12

6. ОГЭ №22
При каких \(k\) прямая \(y = kx\) имеет с графиком \(y = x^2 + 1\) ровно одну общую точку? Запишите положительное значение \(k\).
Решение\(x^2 - kx + 1 = 0\), \(D = k^2 - 4 = 0\), \(k = \pm2\). Положительное 2.

Ответ: 2

Домашнее задание

1. ОГЭ №20
Решите неравенство \(\frac{-15}{(x + 2)^2 - 6} \ge 0\). Укажите количество целых решений.
РешениеЧислитель отрицателен, нужно \((x + 2)^2 - 6 < 0\): \(-2 - \sqrt{6} < x < -2 + \sqrt{6}\), то есть \((-4{,}45;\ 0{,}45)\). Целые: \(-4 \ldots 0\) — 5.

Ответ: 5

2. ОГЭ №21
Расстояние между пристанями 45 км. Лодка прошла туда и обратно за 8 часов, собственная скорость 12 км/ч. Найдите скорость течения.
Решение\(\frac{45}{12 + x} + \frac{45}{12 - x} = 8\) → \(1080 = 8(144 - x^2)\) → \(x^2 = 9\), \(x = 3\).

Ответ: 3

3. ОГЭ №22
Постройте график \(y = \frac{x^2 - 3x + 2}{x - 1}\). При каком \(k\) прямая \(y = kx\) проходит через выколотую точку графика?
Решение\(y = \frac{(x - 1)(x - 2)}{x - 1} = x - 2\), \(x \ne 1\). Выколота \((1;\ -1)\): \(k = -1\).

Ответ: -1

4. Повторение (урок 56) В треугольнике \(ABC\) \(AB = 8\), \(BC = 12\), \(AC = 15\), \(BD\) — биссектриса. Найдите \(AD\).
Решение\(15\cdot\frac{8}{20} = 6\).

Ответ: 6

5. Повторение (урок 55) Найдите значение \(\frac{b^{-2}(b^{3})^{2}}{b^{5}}\) при \(b = 0{,}2\).
Решение\(b^{-1} = 5\).

Ответ: 5
