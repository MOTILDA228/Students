Практика на уроке

1. Двойник №3
Сколько граммов весит пачка из 250 листов A3 плотностью 80 г/м²? Ответ округлите до целых.
РешениеA3: \(0{,}297\cdot0{,}42 = 0{,}12474\) м². \(0{,}12474\cdot250\cdot80 = 2494{,}8 \approx 2495\).

Ответ: 2495

2. Двойник №9
Решите уравнение \(\frac{x + 2}{4} - \frac{x}{3} = 1\).
Решение\(3x + 6 - 4x = 12\), \(x = -6\).

Ответ: -6

3. Двойник №16
Четырёхугольник \(ABCD\) вписан в окружность, \(\angle ABC = 104^\circ\), \(\angle CAD = 36^\circ\). Найдите \(\angle ABD\).
Решение\(\angle CBD = \angle CAD = 36^\circ\), \(\angle ABD = 104 - 36 = 68^\circ\).

Ответ: 68

4. Двойник №20
Решите уравнение \(x^3 - 6x^2 - x + 6 = 0\). Запишите сумму корней.
Решение\((x - 6)(x^2 - 1)\): 6, 1, \(-1\). Сумма 6.

Ответ: 6

5. Двойник №21
Моторная лодка прошла против течения 91 км и вернулась, затратив на обратный путь на 6 часов меньше. Скорость течения 3 км/ч. Найдите скорость лодки в неподвижной воде.
Решение\(\frac{91}{x - 3} - \frac{91}{x + 3} = 6\) → \(546 = 6(x^2 - 9)\) → \(x^2 = 100\), \(x = 10\).

Ответ: 10

6. Двойник №22
Постройте график \(y = \frac{(x^2 + 1)(x + 2)}{-2 - x}\). При каких \(k\) прямая \(y = kx\) имеет с графиком ровно одну общую точку? В ответ запишите сумму всех таких \(k\).
Решение\(y = -x^2 - 1\), \(x \ne -2\), выколота \((-2;\ -5)\). \(x^2 + kx + 1 = 0\): \(D = 0\) при \(k = \pm2\); корень \(x = -2\): \(4 - 2k + 1 = 0\), \(k = 2{,}5\). Сумма \(2 - 2 + 2{,}5 = 2{,}5\).

Ответ: 2,5

7. Двойник №23
Катеты прямоугольного треугольника 7 и 24. Найдите высоту, проведённую к гипотенузе.
Решение\(\frac{168}{25} = 6{,}72\).

Ответ: 6,72

Домашнее задание

1. Двойник №25
Основания трапеции 4 и 10, площадь треугольника \(AOD\) (при большем основании) равна 25. Найдите площадь трапеции.
Решение\(k = 2{,}5\): \(S_{BOC} = 4\), боковые — по \(\sqrt{100} = 10\). \(S = 49\).

Ответ: 49

2. Двойник №24
В параллелограмме \(ABCD\) точки \(E\) и \(F\) лежат на диагонали \(AC\), \(AE = CF\). Докажите, что \(BE = DF\).
Решение\(\triangle ABE = \triangle CDF\): \(AB = CD\), \(AE = CF\), \(\angle BAE = \angle DCF\) (накрест лежащие при \(AB \parallel CD\)). Значит, \(BE = DF\).

Ответ: доказательство

3. Двойник №14
Бригада в первый день заасфальтировала 30 м дороги, а каждый следующий — на 5 м больше. За сколько дней она заасфальтирует 525 м?
Решение\(\frac{60 + 5(n - 1)}{2}\cdot n = 525\) → \(5n^2 + 55n - 1050 = 0\) → \(n^2 + 11n - 210 = 0\), \(D = 961\), \(n = \frac{-11 + 31}{2} = 10\).

Ответ: 10

4. Повторение (урок 49) Сколько баллов из 2 заслуживает решение: «\(x^2 = 5x\), делим на \(x\): \(x = 5\). Ответ: 5»?
РешениеПотерян корень 0 — ответ неверный: 0 баллов.

Ответ: 0

Решение1760.

Ответ: 1760
