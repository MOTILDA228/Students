# Students

Индивидуальные планы подготовки учеников, теория, задания и журнал прогресса.

- `STATUS.md` — что сделано и что дальше
- `students/` — папки учеников (профиль, план, уроки с ДЗ, прогресс)
- `tools/` — сборщик уроков: `python3 tools/build_lessons.py`
- `materials/` — общий банк теории, задач и проверочных
- `CLAUDE.md` — инструкция для ИИ-агентов, продолжающих работу

## Как скачать себе на компьютер
Windows (PowerShell) или macOS (Терминал):
```
cd ~/Desktop
git clone -b claude/compassionate-heisenberg-5ahgle https://github.com/MOTILDA228/Students.git Students
```
Обновить потом: `cd ~/Desktop/Students` и `git pull`.
Уроки открываются двойным щелчком. Начните с оглавления: `students/<имя>/lessons/00-index.html`.

В каждом уроке сверху кнопки: «Раскрыть/свернуть все решения», «Режим ученика» (прячет решения и план
для репетитора — удобно показывать с экрана) и «Печать для ученика» (печатает без решений).
Обычная печать (Ctrl+P) печатает версию для репетитора — с решениями.
