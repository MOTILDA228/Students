# Students

Индивидуальные планы подготовки учеников, теория, задания и журнал прогресса.

- `STATUS.md` — что сделано и что дальше
- `students/` — папки учеников (профиль, план, уроки, ДЗ, прогресс)
- `materials/` — общий банк теории, задач и проверочных
- `CLAUDE.md` — инструкция для ИИ-агентов, продолжающих работу

## Как скачать себе на компьютер
Windows (PowerShell) или macOS (Терминал):
```
cd ~/Desktop
git clone -b claude/compassionate-heisenberg-5ahgle https://github.com/MOTILDA228/Students.git Students
```
Обновить потом: `cd ~/Desktop/Students` и `git pull`.
Уроки открываются двойным щелчком: `students/<имя>/lessons/NN-*.html`.
