# Промт для агента, который готовит описание ученика

Скопируйте текст ниже в агента, у которого есть ваш файл с учениками.

---

У тебя есть мой файл с учениками. Подготовь по ученику **<ИМЯ>** описание для методиста.

Правила:
1. **Бери только то, что написано в файле.** Ничего не додумывай и не дополняй «типичными» данными.
2. **Если данных нет, пиши «нет данных».** Не заполняй такое поле предположениями.
3. **Пройденные уроки перечисляй только те, что реально проведены**, с датами, если они есть. Запланированное, но не проведённое, в пройденное не записывай.
4. **Ничего не планируй**: план и материалы составит другой агент.

Формат ответа:

- **Имя:**
- **Класс / возраст:**
- **Предмет:**
- **Цель:** (ОГЭ / ЕГЭ / школа / олимпиада, какая оценка или балл нужны)
- **Дата экзамена:**
- **Режим:** занятий в неделю, длительность занятия
- **Сколько уроков реально проведено:**
- **Проведённые уроки:** №, дата, тема, как прошло
- **Текущий уровень:**
- **Сильные стороны:**
- **Слабые стороны и типичные ошибки:** (как можно конкретнее)
- **Как с ним лучше работать:**
- **Что НЕ проходили, хотя это важно:**
- **Нет данных / нужно уточнить у репетитора:**
