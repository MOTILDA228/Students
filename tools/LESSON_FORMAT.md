# Формат урока `.lesson`

Исходник урока — текстовый файл `students/<ученик>/lessons/_src/NN-<тема>.lesson`.
Сборка: `python3 tools/build_lessons.py` → готовая страница `students/<ученик>/lessons/NN-<тема>.html`
и оглавление `00-index.html` (строится по таблице из `plan.md`).
Подпись под заголовком берётся из `_src/_student.txt`.

## Команды (всегда с начала строки)

| Команда | Что делает |
|---|---|
| `@title Урок 8. Тема` | заголовок |
| `@tags ОГЭ №15 \| ОГЭ №19 \| геометрия` | метки в шапке |
| `@teacher` | свёрнутый блок «Для репетитора: план урока» (скрыт в режиме ученика) |
| `@theory [Заголовок]` | карточка с HTML (по умолчанию «Шпаргалка») |
| `@card Заголовок` | произвольная карточка с HTML |
| `@practice` / `@hw` | задачи урока / домашнее задание (нумерация автоматическая) |
| `@tasks Заголовок` | раздел задач с любым заголовком (контрольные, пробники) |
| `@task` | новая задача; дальше идёт условие (HTML) |
| `@src Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)` | пометка источника |
| `@rep 5` | пометка «Повторение (урок 5)» |
| `@sol` | дальше — полное решение (HTML) |
| `@ans 2,75` | ответ (можно `\(\frac{3}{4}\)`, `\(-2\); 3`, `а) 9; б) 0,7`) |
| `@check (F(11,12)+F(11,20))*F(15,8)` | выражение на Python, которое **заново считает** ответ из условия |

Сборщик сверяет каждый `@check` с `@ans` и падает с кодом 1 при расхождении.
Задачи без числового ответа (номера верных утверждений, выбор варианта) пишутся без `@check`,
их нужно проверить вручную. В `@check` доступны: `F` (дробь), `sqrt`, `roots(a,b,c)`,
`hyp(a,b)`, `leg(c,a)`, `sind/cosd/tand`, `ap/aps`, `gp/gps`, `comb`, `pi`,
`which(истина, вариант1, вариант2, ...)` — номер варианта для №13 (варианты — лямбды от x);
`match([графики А, Б, В], [формулы 1, 2, 3])` — ответ №11 строкой цифр, например «312».

Готовые классы оформления: `ls-rule` (правило-шпаргалка), `ls-warn` (типичная ошибка),
`ls-example` (разобранный пример), `ls-steps` (нумерованный алгоритм), `ls-table` (таблица),
`ls-opts` (варианты ответа в строку), `ls-figs` (несколько рисунков рядом), `ls-mono` (столбик).
Все классы начинаются с `ls-`.

## Рисунки

Блок рисунка можно вставить в теорию, условие или решение. Координаты — обычные
математические (ось y вверх), масштаб подбирается сам.

```
@fig [scale=40] [grid=8x6] [margin=26]
P A 0 0 [pos=sw] [dot] [hide] [label=A_1]   точка (подпись ставится сама, от центра фигуры)
poly A B C [fill] [dash]                    многоугольник (можно координатами: poly 1,1 5,1 3,4)
seg A B [dash] [thick]                      отрезок
line A B [ext=1]                            прямая (отрезок, продлённый в обе стороны)
circle O 3 | circle O A                     окружность по радиусу или через точку
angle A B C [label=40°] [n=2] [r=20] [flip] дуга угла ABC (при вершине B)
right A B C                                 значок прямого угла при вершине B
ticks A B 2                                 чёрточки равенства на отрезке
len A B 5 см                                подпись длины у середины отрезка
text 3 2 любой текст                        подпись в точке (3; 2)
@end

@numline -3 5 [width=340]
int (-inf; 2]  U  (3; +inf)                 штриховка; [ ] — закрашенный конец, ( ) — выколотый
int [1.41:√2; 4)                            «значение:подпись» — подпись вместо числа
pt 2.7 A                                    точка с подписью сверху
mark 0 0                                    штрих с подписью снизу
@end

@plot -5 5 -4 6 [scale=24] [nogrid] [nounit]
f x**2 - 2*x - 3 | y = x² − 2x − 3 | 3      график; после | — подпись и x, где её поставить
pt 1 2 A                                    точка
seg 0 0 2 4 dash                            отрезок
text 2 3 подпись
@end
```

## Пример задачи

```
@task
@src Прототип ОГЭ №15 (ФИПИ / Решу ОГЭ)
В треугольнике \(ABC\) известно, что \(AB = BC\), \(\angle ABC = 108^\circ\). Найдите угол \(BCA\).
@fig
P A 0 0
P B 3 1.2
P C 6 0
poly A B C
ticks A B 1
ticks B C 1
angle A B C label=108°
@end
@sol
Треугольник равнобедренный, углы при основании равны: \((180 - 108) : 2 = 36^\circ\).
@ans 36
@check (180-108)/2
```
