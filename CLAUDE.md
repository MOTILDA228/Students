# Инструкция для агента (читать первым)

Это рабочий репозиторий репетитора. Здесь хранятся профили учеников, их
индивидуальные планы подготовки (на 6–12 месяцев), теория, задания,
контрольные и журнал прогресса. Работа ведётся на русском языке.

## Перед началом работы
1. Прочитай `STATUS.md`: там написано, что уже сделано и что делать дальше.
2. Прочитай `sources.md`: это сайты, откуда репетитор разрешил брать задания.
3. Если работаешь с конкретным учеником, прочитай его папку `students/<имя>/`:
   `profile.md` → `plan.md` → `progress.md`.

## Структура
```
STATUS.md                 — общий журнал передачи работы между агентами
sources.md                — сайты-источники заданий
materials/                — общий банк материалов (переиспользуется разными учениками)
  theory/<тема>.md        — теория по теме
  practice/<тема>.md      — задачи по теме (с ответами/решениями в конце)
  tests/<тема>.md         — проверочные работы
students/_template/       — шаблон папки ученика (копировать при добавлении нового)
students/<имя>/
  profile.md              — кто ученик: уровень, сильные/слабые стороны, цель
  plan.md                 — индивидуальный план по неделям/месяцам
  progress.md             — журнал: что пройдено, результаты, корректировки плана
  lessons/NN-<тема>.md    — материал к конкретному занятию (теория + практика)
  homework/NN-<тема>.md   — домашние задания с ответами в конце
```

## Правила
- Имя папки ученика: латиницей, строчными, через дефис (`ivan-petrov`).
- Нумерация занятий и ДЗ: двузначная (`01`, `02`, …), совпадает с номером недели/занятия в плане.
- Общая теория — в `materials/`, в уроках ученика ссылайся на неё и добавляй
  только то, что специфично для ученика. Не дублируй.
- В каждом файле с задачами: ответы (и решения для сложных) — в конце файла,
  в разделе «Ответы», чтобы файл можно было отдать ученику без последней части.
- Если задание взято с сайта — укажи источник (ссылку / номер задачи).
- Задания составляй с учётом уровня и слабых мест из `profile.md`.
- После каждого значимого шага: обнови `progress.md` ученика и `STATUS.md`,
  затем закоммить и запушь. Незапушенная работа теряется.
- Не удаляй и не переписывай записи в `progress.md` — только дописывай.

## Уроки в HTML
- Один урок — один самодостаточный HTML-файл (MathJax 3 с CDN, стили встроены).
- Исходник писать в `students/<имя>/lessons/_src/NN-<тема>.html`. Первая строка:
  `<!-- title: Урок N. Тема -->`. Содержимое — только тело урока.
- Собрать готовые файлы: `python3 tools/build_lessons.py`. Готовые уроки появятся в
  `students/<имя>/lessons/NN-<тема>.html`. Оболочка со стилями: `tools/lesson_shell.html`.
- Образец структуры: `students/dima/lessons/_src/03-drobi-zakreplenie.html`. В уроке:
  шапка с номерами ОГЭ → навигация → шпаргалка (`ls-rule`, `ls-warn`, `ls-example`) →
  практика (5–7 задач) → ДЗ (5–8 задач, из них 2–4 «Повторение (урок N)»).
  У каждой задачи есть `<details>` с полным решением. Прототипы помечены номером ОГЭ.
- Дроби писать только через `\frac`, десятичную запятую — как `{,}`.
- Все CSS-классы начинаются с префикса `ls-`.
- Каждый ответ пересчитать перед коммитом.
