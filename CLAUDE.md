# Инструкция для агента (читать первым)

Это рабочий репозиторий репетитора. Здесь хранятся профили учеников, их
индивидуальные планы подготовки (на 6–12 месяцев), теория, задания,
контрольные и журнал прогресса. Работа ведётся на русском языке.

## Перед началом работы
1. Прочитай `STATUS.md`: там написано, что уже сделано и что делать дальше.
2. Прочитай `sources.md`: это сайты, откуда репетитор разрешил брать задания.
3. Если работаешь с конкретным учеником, прочитай его папку `students/<имя>/`:
   `profile.md` → `plan.md` → `progress.md`.

## Структура
```
STATUS.md                 — общий журнал передачи работы между агентами
sources.md                — сайты-источники заданий
PROMPT_student_intake.md  — промт, которым репетитор собирает данные об ученике из другого чата
tools/                    — сборщик уроков, рисунки, автопроверка ответов (см. tools/LESSON_FORMAT.md)
dashboard/journal.html    — главная страница «Журнал учеников» (tools/build_dashboard.py, ссылка в STATUS.md)
materials/                — общий банк материалов (переиспользуется разными учениками)
students/_template/       — шаблон папки ученика (копировать при добавлении нового)
students/<имя>/
  profile.md              — кто ученик: уровень, сильные/слабые стороны, цель
  plan.md                 — план уроков таблицей | № | Тема | ОГЭ | Тип | Когда | (по ней строится оглавление)
  progress.md             — журнал: что пройдено, результаты, корректировки плана
  lessons/_src/_student.txt       — подпись под заголовком каждого урока
  lessons/_src/NN-<тема>.lesson   — исходник урока (теория + практика + ДЗ с решениями)
  lessons/NN-<тема>.html          — готовый урок (собирается автоматически, руками не править)
  lessons/00-index.html           — оглавление всех уроков
```

## Правила
- Имя папки ученика: латиницей, строчными, через дефис (`ivan-petrov`).
- Нумерация уроков двузначная (`03`, `04`, …) и совпадает с номером в `plan.md`.
- Домашнее задание — внутри урока (раздел `@hw`), отдельных файлов ДЗ нет.
- Решения спрятаны под «Решение»; ученику урок показывают в «Режиме ученика» или печатают
  кнопкой «Печать для ученика» — тогда решений не видно.
- Если задание взято с сайта — укажи источник (`@src`).
- Задания составляй с учётом уровня и слабых мест из `profile.md`.
- После каждого значимого шага: обнови `progress.md` ученика и `STATUS.md`,
  затем закоммить и запушь. Незапушенная работа теряется.
- Не удаляй и не переписывай записи в `progress.md` — только дописывай.

## Новый ученик
1. Репетитор присылает описание (промт — `PROMPT_student_intake.md`).
2. Скопируй `students/_template/` в `students/<имя>/`, заполни `profile.md`.
3. Составь `plan.md` таблицей (формат как у `students/dima/plan.md`), покажи репетитору до написания уроков.
4. Создай `lessons/_src/_student.txt` и уроки в формате `.lesson`, собери, проверь, закоммить.

## Уроки в HTML
- Один урок — один самодостаточный HTML-файл (MathJax 3 с CDN, стили встроены).
- Исходник — `students/<имя>/lessons/_src/NN-<тема>.lesson`. Формат, команды и рисунки
  (чертежи, клетчатая бумага, числовые прямые, графики) описаны в `tools/LESSON_FORMAT.md`.
- Сборка: `python3 tools/build_lessons.py` (или `... dima` для одного ученика). Готовые страницы
  появляются в `students/<имя>/lessons/`, там же оглавление `00-index.html` по таблице `plan.md`.
- **Каждая задача с числовым ответом должна иметь `@check`** — выражение, которое заново считает
  ответ из условия. Сборщик сверяет его с `@ans` и завершается с ошибкой при расхождении.
  Коммитить можно только после сборки без строк «ОШИБКА».
- Образец урока: `students/dima/lessons/_src/08-geom-treugolniki.lesson`. В уроке:
  `@teacher` (план на 60 минут) → `@theory` (шпаргалка: `ls-rule`, `ls-warn`, `ls-example`) →
  `@practice` (5–7 задач от простых к прототипам ОГЭ) → `@hw` (5–8 задач, из них 2–4 с `@rep`).
- Повторение в ДЗ: темы уроков N−2, N−4, N−8 (если это контрольная — соседний урок).
- Дроби писать только через `\frac`, десятичную запятую — как `{,}`.
- Все CSS-классы начинаются с префикса `ls-`.
- Облачная среда не может загрузить MathJax с CDN — это нормально, у пользователя формулы отрисуются.
